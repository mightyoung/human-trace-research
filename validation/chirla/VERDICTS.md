# 公开数据验证判定（CHIRLA）

- 图库 158 条（有身份 158）｜查询 52 条｜配置 35 个
- A_baseline：K=27 θ=1.4 接受 2 C=1 W=1 U=0

| 假设 | 指标 | 实测 | 判定门槛 | 结论 |
|---|---|---|---|---|
| H1a | Spearman(逐条C, 继承精度·严格) | -0.804 | ρ ≤ −0.3 | 无法判定 |
| H1b | 继承精度最高配置的 ΔC | -1（D_split0.15） | ΔC < 0 | 无法判定 |
| H1c | A_baseline 继承精度 vs 逐条精度 | 0.000 vs 0.500 | 继承 < 逐条 | 无法判定 |
| H2a | AUC(d_max → 混人簇) | 0.707 | AUC ≥ 0.80 | 无法判定 |
| H2b | AUC(d_max → 有害簇) [95%CI] | nan | CI 含 0.5 或 AUC ≤ 0.65 | 无法判定 |
| H2c | ΔC(C_dmax0.30 − A_baseline) 与 McNemar p | +0, p=1 | ΔC < 0 且 p < 0.05 | 无法判定 |
| H3 | 未答 vs 答错 | 57 vs 1 | 未答 > 答错 | 无法判定 |

> ⚠ 前置条件不满足：接受 2 条（<30）或覆盖 0.034（<0.10），除 H3 外一律无法判定

## 口径与偏离

- CHIRLA 30 FPS，按每 12 帧取 1 → 2.5 FPS（现场 25 FPS 每 10 帧取 1）
- seq_001/002 的 camera_5/6/7 标注为空，只跑 camera_1..4（查询侧实际 4 机位）
- 特征口径沿用历史 BGR，与冻结基线一致，未开 --rgb
- 轨迹真值为自动 IoU 匹配（非人工标注），purity/matched_frac 阈值见 gt_match
- self-cal 在本数据上无可行工作点：θ=1.40（网格下界）时覆盖仅 0.034、可评估共现对 3 个 → 按 min_eval=100/26 全部落空；改按 --min-eval 0 跑满 35/42 个配置，A_baseline 只接受 2/52 条 → 判定为「无法判定」而非硬判成立/不成立
- 查询与图库相隔约 50 分钟（seq_000 11:14 vs seq_001 12:03 / seq_002 12:09），同人余弦从跨机位同场 0.758 掉到跨场 0.662，异人稳定在 0.57–0.59 → 可分间距被削掉约一半，这是覆盖塌到 3% 的根因（非校准/聚类参数问题）
