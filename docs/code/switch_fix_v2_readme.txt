**风险**
- `-OLD` 我推测是 `1012_final`，但不确定那是不是生成台账的文件。评估脚本会打印"旧 jsonl 与台账帧数一致率"，低于 90% 说明路径指错了。
- 外观否决阈值和你们 OSNet x1_0 模型的余弦分布有关，云端数值不能照搬，要以网格结果为准。
- v2 的召回比原版低约 1.5~2 个点（MOT17 上实测），这是收紧阈值的代价。
- 跟踪前去重 0.9 在 MOT17 这种密集人群里每帧删掉约 3.7 个框，在你们的办公场景要看 `UNMATCHED` 和误切率确认有没有误删真人。
