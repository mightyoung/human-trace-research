## 1. 任务定义

### 任务一：身份选择器（无监督聚类 → 分类）
训练集上运行现有算法（检测+跟踪+清洗+cradio 嵌入）得到全部人物目标向量 → 无监督聚类形成身份分类模型（簇原型库）
→ 测试集输入向量即可输出身份分类（或 unknown）。用途：跨时段身份选择的可复用判别器，为全局 PersonGallery 提供底座。

### 任务二：轨迹运动意图预测器（BERT 架构）
训练集轨迹 → "历史窗 → 未来运动"样本；BERT 范式 Transformer（token 投影 + CLS + 位置编码 + 分类头）；
预测 5 类意图：**继续前行 / 停下 / 折返 / 左转 / 右转**。

## 4. 任务一：身份选择器

### 4.1 方法
- 训练集每条轨迹编码为两份（前/后半 `_a`/`_b`），V=均值向量（768d）；
- 无监督聚类三方案对比：**mutual-kNN 图连通分量 / K-means / average-linkage 层次**；
- **选择标准 = 共现负对 F1**：正对=同轨迹 a/b 分片；负对=同帧共现 ≥5 帧的轨迹对（同时在场 = 确凿不同人）；
  （开发期合成数据验证：随机负对 F1 会系统偏向碎划分、压制完美解——已弃用；共现负对 F1 方向正确：完美解=1.000、过度合并被 precision 惩罚）
- 簇原型库 = 各簇归一化均值向量（min-cluster=2 过滤小簇）→ `IdentitySelector`（输入向量 → 最近原型 → 簇 ID / unknown）；
- thr_unknown 由训练集校准：分片正对 p5 与共现负对 p99 的中点。

### 4.2 训练结果（train 4 段，1395 轨）

| 指标 | 数值 |
|---|---|
| 分片判别力（前半 vs 后半 cos） | pos 0.9848 / neg 0.8275 / **AUC 0.9942** |
| 共现负对（min_common=5） | **7,945 对** |
| thr 校准 | pos_p5=0.955 / cooc_p99=0.976 → thr_unknown=**0.965** ⚠（两分布重叠，见 4.4） |

**三方案对比（top，选择标准=共现负对 F1）：**

| 方法 | 参数 | 簇数 | F1 | P | R | same | coll |
|---|---|---|---|---|---|---|---|
| **mutual-kNN** | k=5（任意 thr） | **269** | **0.846** | 0.900 | 0.797 | 0.797 | **0.011** |
| kmeans | K=60 | 60 | 0.812 | 0.735 | 0.908 | 0.908 | 0.024 |
| mutual-kNN | k=8 | 130 | 0.779 | 0.755 | 0.806 | 0.806 | 0.028 |

→ 最佳 **mutual-kNN (k=5)**：269 簇；去小簇 144 个（<2 轨）→ **原型库 125**。产物 `analysis/selector_1012/selector.npz`（+ `sim_dist.png` 分布图）。

### 4.3 测试集评估（4 个 test 段，348 轨；跨时段）

**主口径（thr=0.965，known-restricted）**：

| 指标 | 数值 | 说明 |
|---|---|---|
| coverage（敢判定率） | **0.503** | 两侧分片都非 unknown |
| **same_known** | **0.857** | 敢判定时，同人两半同簇率 |
| **collision_known** | **0.033** | 随机对（都敢判定时）误判同簇率 |
| both_unknown | 0.408 | 两次都拒识 |
| （全口径 same / coll） | 0.839 / 0.216 | 含 unknown 碰撞，仅诊断参考 |

**thr 诊断曲线**（coverage 与一致性的权衡；工作点选择建议在 train/val 上复核）：

| thr | coverage | same_known | collision_known |
|---|---|---|---|
| 0.88 | 1.000 | 0.764 | 0.025 |
| 0.90 | 0.980 | 0.774 | 0.025 |
| 0.92 | 0.911 | 0.785 | 0.026 |
| 0.95 | 0.681 | 0.819 | 0.027 |
| **0.965（默认）** | 0.503 | **0.857** | 0.033 |
| 0.98 | 0.230 | 0.863 | 0.044 |

→ **误纳率在 0.88-0.97 区间稳定（2.5%-3.4%）**；一致性随阈值缓升。典型工作点：
**高覆盖档 thr≈0.90（识别 98% 轨迹、一致率 77%、误纳 2.5%）** vs **高置信档 0.965（识别 50%、一致率 86%、误纳 3.3%）**。

### 4.4 跨段身份保持检验（train 原型 → test 推理）

| 指标 | 数值 |
|---|---|
| 互最近邻跨段配对（test↔train） | 107 对（sim p50=0.984） |
| 可判定对（两侧 known） | 73 对 |
| **同簇（身份保持）** | **65 对 → 89.0%** |
| test 段 unknow（thr=0.965） | 41.7%；用到 52 个簇 |

→ "上午学习身份 → 下午识别同一人"机制有效（**89.0%**）。107 对互 NN 对应常驻/重复出现者；其余 test 轨迹为"未见过的面孔"或碎片轨迹。

### 4.5 附加实验：聚类伪标签 → MLP 分类头

| 方法 | test same | test coll（全判定） |
|---|---|---|
| 簇原型匹配（开集，thr=0.965） | 0.857（known） | 0.033（known） |
| MLP 分类头（125 类伪标签训练） | 0.753 | 0.044 |

→ MLP **无拒识**（永远给类），误纳 4.4% 仍可控；与原型开集匹配互补（候选组合策略：原型为主 + MLP 兜底，留作下一步）。

### 4.6 关键发现与解读

1. **分布重叠现象**：训练集上同人分片对 p5（0.955）**低于**共现负对 p99（0.976）——单阈值无法同时保正排负；
   这解释了"中点校准"（0.965）保守性 → 更合理做法是**按下游需求选工作点**（本报告两条曲线均已给出）。
2. **跨时段不衰减**：test 段（下午）与 train 段（上午）间隔 4-7 小时，AUC/一致率未见明显下降；
3. **AUC 0.9942 与碰撞率 3%**：1012 数据上 cradio 分辨性质优；主要误差来自碎片轨迹（同一人多次进出被切碎）与相似衣着难例。

## 5. 任务二：轨迹意图预测

### 5.1 数据（1012 全部 12 段）

- 每样本：7 维 token × 12 步（历史 2.4s）→ 预测未来 1s（5 步）行为；
- **运动过滤**：仅保留检查时刻 v_in ≥ 0.01/s 的样本（办公区大量静止坐姿目标，不过滤会退化为常数预测）；
- 标签规则：stop（v_fut<0.01/s）/ backward（|θ|≥140°）/ turn（40°-140° 分左右）/ forward；

| 段 | 轨迹 | 使用 | 样本 | 静态剔除 |
|---|---|---|---|---|
| 320_train_514 | 102 | 42 | 182 | 1839 |
| 318_train_525 | 461 | 201 | 1223 | 10680 |
| 323_train_510 | 471 | 200 | 3455 | 5899 |
| 305_train_529 | 810 | 353 | 1830 | 49405 |
| val 4 段合计 | 309 | 133 | 1079 | 19283 |
| test 4 段合计 | 472 | 194 | 1294 | 21790 |
| **合计** | **2625** | **1123** | **9063** | **108,896** |

类别分布：**forward 3830 (42.3%) / stop 3070 (33.9%) / backward 962 (10.6%) / turn_left 616 (6.8%) / turn_right 585 (6.5%)**。
切分：段级（train 段样本训练、val 段早停、test 段报告——天然跨时段防泄漏）。

### 5.2 模型
BERT 范式：token 投影 → [CLS]+位置编码 → TransformerEncoder（4 层 / d=256 / 4 头 / FFN 1024 / norm_first）
→ CLS 分类头。类别权重（inverse-freq sqrt）、AdamW + cosine 退火、早停（val macro-F1）。训练 ~35 秒（GPU L20）。

### 5.3 结果

**1012 正式（test 1294 样本）**：

|---|---|---|---|---|
| stop | 0.670 | 0.752 | 0.708 | 512 |
| **forward** | **0.885** | 0.811 | **0.847** | 493 |
| backward | 0.306 | 0.260 | 0.281 | 169 |
| turn_left | 0.338 | 0.357 | 0.347 | 70 |
| turn_right | 0.204 | 0.200 | 0.202 | 50 |
| **总体** | | | acc **0.668** / macro-F1 **0.477** | 1294 |

**与 long35 开发期对照**（跨数据集一致性）：

| | 1012（正式） | long35（开发） |
|---|---|---|
| acc | 0.668 | 0.694 |
| macro-F1 | 0.477 | 0.469 |

轨迹可视化（25 样本：蓝=历史 2.4s、彩=未来 1s 实际、红标题=误判）：`analysis/intent/model_1012/traj_viz_test.jpg`。

### 5.4 分析

1. **可预判性层次**：forward（F1 0.85，速度外推在直行时非常可靠）≫ stop（0.71，减速可察）> turn（0.20-0.35）> backward（0.28）；
2. **折返混淆机制**：backward 样本 65%（111/169）被预测为 stop——折返者未来 1s 净位移极小，与"停下"在运动学上不可分；需要更长历史或双向（前后）上下文才能区分；
3. **转向难**：40°-140° 的转向在中段历史里没有稳定预兆且样本少（turn 合计 120 样本）；可考虑分层任务（先"动/停"再分类方向）或降低转向粒度；
4. **跨集一致**：两个数据集（long35 / 1012）的宏观结论完全一致——方法稳健。

## 7. 结论与下一步

**任务一 ✅**：无监督聚类选择器可运行、可评估、跨时段有效（89.0% 身份保持；86% 一致率 @50% 覆盖，或 77% @98%）。
**任务二 ✅**：BERT 轨迹意图模型可用；forward/stop 可靠（F1 0.85/0.71），backward/turn 受运动学本质限制。

**下一步建议**：
1. 选择器工作点的 train 校准脚本化（避免 test 侧调参争议；本报告曲线仅作诊断）；
2. 组合策略：原型开集（高置信）+ MLP 兜底（无拒识）的级联；跨段伪标签迭代自训练（用 89% 保持率扩原型）；
3. 意图模型：引入双向上下文（未来窗不可见，但可用"双向历史+邻域人员"），或改多任务分层（动/停 → 方向）；
4. 与全局 ReID store（MRL 两级）对接：选择器原型库并入 `store_long35` 体系，服务化（embed_server 已就绪）。
