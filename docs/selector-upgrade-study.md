## 一、实验设计

基座固定为**可复现的 mutual-knn 聚类**（k=5, thr=0.3, 269 簇→过滤小簇 125 簇；kmeans 对初始化/环境敏感，上轮已确认其不可复现，本实验不采用）。

8 个变体（同一基聚类，只改"原型库表示 + 判定统计量"）：

| 变体 | 原型库 | 簇级统计量 |
|---|---|---|
| single | 每簇 1 均值原型（现状基线） | max |
| multi2/4/8/16 | 每簇 ≤M 子原型（簇内 kmeans 分裂） | max |
| soft3/soft5 | 全部训练向量 | 簇内 top-3/5 均值（N-ULC 软标签） |
| multi8t3 | multi8 子原型 | 簇内 top-3 均值（软聚合对照） |

评估（test 348 轨，known-restricted 口径，与上轮完全一致）：
- **曲线口径（金标准）**：统一 thr 扫描 → 固定 coverage（0.2/0.4/0.6/0.8）下 same-known / coll-known；
- **工作点**：legacy 中点 thr（v1/F 口径）/ selfcal 中点 thr（变体自身统计量校准），per-cam 与全局；
- **公平子集**：全部变体共同 known 的子集上 same；
- **跨段保持**：mutual-NN 配对（107 对）的簇一致率；公共可判对（51 对）对照。

复现：`python tools/selector_upgrade_study.py`（本地 envs/default；产物 `output_crosscam/analysis/selector_1012/upgrade/`）。

### 2.5 N-ULC 一致性权重（margin 拒识）

multi8 + selfcal-percam thr 上叠加 "top1−top2 簇分差 ≥ δ"：

| δ | coverage | same-known | coll-known |
|---|---|---|---|
| 0（无拒识） | 0.391 | 0.897 | 0.032 |
| 0.002 | 0.287 | 0.960 | 0.033 |
| **0.005** | 0.227 | **0.987** | 0.035 |
| 0.010 | 0.178 | 1.000 | 0.051 |

**核心发现**：δ=0.005 的 (0.227, 0.987) 显著高于 thr 曲线在 cov≈0.23 的 same（≈0.91~0.92）——margin 是独立于 thr 的第二维拒识信号，两者正交（thr=绝对分、margin=竞争差）。

**per-camera 分位校准（2026-10-14 追加落地，建议要点②）**：
- 中点法不适用于 margin（pos/neg 分布不分离：同人 min-margin p5≈0.001 vs 异人 p99≈0.09，中点 δ≈0.045 会拒掉 97% 样本）→ 改用**保留分位率**校准：δ_c = p30(同人分片 min-margin) ≈ 目标保留 70%；
- 各摄像头差异大（这正是需 per-cam 的证据）：0.005 的等效保留率 = 305:65% / 318:87% / 320:91% / 323:69%；
- per-cam 分位值（ret=0.7）：**305:0.0039 / 318:0.0114 / 320:0.0228 / 323:0.0050**；
- test 验证：per-cam(ret=0.7) 达 cov 0.230 / same 0.988 / coll 0.039 ≈ 全局 0.005（0.227/0.987/0.035）——**同效果、语义更清晰（保留率可解释、按摄像头适配）**。

## 三、per-camera 诊断（诚实边界）

| cam | n | single WP | multi8 WP | 曲线方向 |
|---|---|---|---|---|
| 305 | 130 | 0.867 | **0.958 (+9pp)** | 大升 |
| 318 | 128 | 0.825 | 0.839 (+1.4pp) | 全面略优 |
| 320 | 28 | cov=0（无判定） | cov=0.107, same=1.0 | 覆盖恢复，样本太少 |
| 323 | 62 | 0.872 | 0.806 (**-6.6pp**) | test 曲线低（-2~9pp）；**val 独立时段反占优（见下）** |

### 3.1 323 独立时段复核（2026-10-14 追加，建议要点①）

用 **1012 val 段（午间，独立于建库 train 与评估 test）** 复核：

| 时段 | 口径 | single | multi8 | 判定 |
|---|---|---|---|---|
| test（下午 15min, 62 轨） | WP same | 0.872 | 0.806 | multi8 低 |
| **val（午间 15min, 63 轨）** | WP same | 0.780 | 0.786（cov 0.444 vs 0.651） | 持平（覆盖换精度） |
| **val 曲线（统一 thr 扫描）** | cov 0.2/0.3/0.4/0.5 | 0.68/0.71/0.76/0.77 | **0.76/0.79/0.82/0.81** | **multi8 全程占优（+5~9pp）** |

**修正结论**：323 的 test 退化**不是系统性缺陷**，而是**小样本时段波动**（两个独立时段方向相反，n≈60/段）。残余风险 = "小样本摄像头上的时段不稳定"，列入监控项（需要时按 323 单独评估）。

总体池化指标（348 轨）由 305/318/320 的增益主导，净为正。

## 五、文献借鉴映射

| 文献机制 | 本文转译 | 结果 |
|---|---|---|
| PCLHD 多原型（簇表达能力、补 hard 原型） | 簇内 kmeans 分裂 → 多子原型 → 簇级 max | ✅ 显著有效（multi4/8/16） |
| N-ULC 近邻软标签 | 簇内 top-k 均值聚合（soft3/5） | ⚠️ 有效但弱于多原型；软聚合（multi8t3）有害 |
| N-ULC 一致性权重 | margin 拒识（top1−top2 差） | ✅ 开辟新高精度前沿（正交于 thr） |

## 六、建议与遗留（2026-10-14 更新：遗留①②已闭环）

1. **部署**（selector_v2.npz，三档）：
   - **默认保守档**：`predict(v, cams)` → cov 0.391 / same 0.897 / 跨段 0.972；
   - **覆盖档**：`predict(v, cams, loose=True)` → cov 0.621 / same 0.880 / 跨段 0.977；
   - **精确档**：`predict(v, cams, margin="prec")` → cov 0.230 / same 0.988 / **跨段 1.000**；按用途在部署侧声明档位（见 `docs/selector-v2-guide.md`）。
2. **闭环记录**：① 323 已用 val 独立时段复核 → 时段波动（非系统缺陷）；② margin 已改为 **per-camera 分位校准**（ret=0.7，δ_c 入库，`margin="prec"` 主用；全局 0.005 保留兼容）；③ soft 与多原型混合未做——当前证据边际收益低，不做。
3. **新遗留**：① 323 等小样本摄像头需要时单独评估（时段不稳定监控项）；② margin 的时序漂移未测（跨日/跨时段），若长时间部署建议周期性重校准（沿用 `build_selector_v2.py` 的对齐+回归流程）。
4. **工程提醒**：基聚类固定 mutual-knn（kmeans 不可复现）；原型库重建走 `build_selector_v2.py`（对齐旧库 + 回归自检内建）。
