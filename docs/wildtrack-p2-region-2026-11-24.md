# WILDTRACK 区域共视 vs 跨镜外观判别力（P2 直接实验）

日期：2026-11-24　脚本：`tmp/wt/wt_{zip,crops,embed,auc,auc2,geo,geo2,region}.py`
数据：`tmp/wt/data/Wildtrack_dataset`（标注 400 帧 / 图像 140 张 / 标定 14 个 XML）

## 0. 结论

**在 WILDTRACK 上，「两台相机共视」不能预测跨镜外观能不能用。**

- 21 个视角对的共视率从 **0.00 到 0.89**，跨时刻 AUC 从 **0.350 到 0.901**（中位 0.755）；
  按共视分档后三档中位几乎重合（0.739 / 0.817 / 0.755）。
- 用等量身份重采样（每对 15 个身份 × 200 次）消除身份构成偏差后：
  **共视 vs AUC：r = +0.179，ρ = +0.161**；几何重叠：r = +0.051，ρ = −0.072。
- **区域级 A/B 同样为负**：把配对限制在两台相机共同可见的地面区域内，
  AUC 变化中位 **+0.042**，17 对里 11 对为正、6 对为负（范围 −0.183…+0.371），符号不一致。
- 标定几何（光轴夹角、基线、几何重叠）与像素预算都不解释残差（|r| ≤ 0.18）。
- **像素预算扫描（§3.6）进一步否掉"人太小"这一通解**：把同一批人裁到 16 px 高，
  AUC 仍有 **0.671**（native 0.795）→ 身体外观在 16–320 px 区间几乎不敏感，
  本站点身体外观失败不能归因于像素。**

因此论文 §P2 的原命题——「共享区域意味着 L1 可用」——在这个公开基准上**不成立**。
P2 能证明的是**同时可见**（存在可建立时间锚、可人工裁定的区域），不是**可匹配**。

## 1. 为什么换 WILDTRACK

先用本地 CHIRLA（seq_000/001/002，7 视角 + 逐帧框）做，当时的判断是「标注的 `id` 是每视角内的轨迹号」：
seq_001 七视角 id 交集只有 1，seq_000 的 1–10 也只是编号巧合。用它做跨视角配对，
「同人对」大部分是错配。第一版得 r = −0.012，**作废**，不再引用。

> **2026-11-25 更正（这条判断本身是错的）**：CHIRLA 官方说明与项目更早的记录
> （`docs/p2-temporal-constraints-2026-11-09.md` §「CHIRLA 七路同步、逐帧 bbox、**跨机位全局 id**」）
> 都表明 `id` 是**跨机位全局**的。七视角交集小，只说明同一个人很少同时出现在全部 7 个视角，
> 不能推出编号是局部编号。当时的推理把「交集小」误当成「编号不共享」。
> 因此 CHIRLA 的适用性**不应由这条理由否决**；是否重做它的跨视角配对，
> 改由「P2 已在 WILDTRACK 上被否证、再做一次只是旁证」来决定，而不是由编号问题决定。
> `chirla_p2.py` 的第一版结果仍作废——作废原因是配对逻辑按 per-view 序号取同 id，而不是编号本身。

WILDTRACK 的 `annotations_positions` 有**全局 personID**，且每人的 `views` 明确指出
哪些视角可见（不可见为 −1），正好是 P2 的定义。

## 2. 口径

| 项 | 设定 |
|---|---|
| 共视率 | Σ(两视角同时可见的人帧) / Σ(任一可见的人帧)，**全部 400 帧** |
| 裁剪 | 每视角 20 帧，共 **1 855** 个框，外扩 8%，缩放到 160×320 |
| 编码器 | OSNet-x1.0（MSMT17），CPU，512 维，L2 归一化，**250 ms/crop** |
| 正例 | 同一 personID、**不同时刻**（跨时刻）或**同一帧**（同时刻）的两视角裁剪 |
| 负例 | 不同 personID 的随机配对，数量与正例相等 |
| 指标 | Mann-Whitney AUC；置信区间按身份 bootstrap 1000 次 |

## 3. 结果

### 3.1 对级：共视不解释 AUC

| 视角对 | 共视 | 共享身份 | AUC 跨时刻 | 95% CI |
|---|---|---|---|---|
| C1–C6 | 0.89 | 228 | 0.711 | [0.61, 0.81] |
| C3–C6 | 0.65 | 165 | 0.702 | [0.63, 0.77] |
| C5–C7 | 0.60 | 43 | **0.901** | [0.86, 0.94] |
| C1–C3 | 0.60 | 156 | 0.765 | [0.65, 0.87] |
| C3–C5 | 0.55 | 84 | 0.739 | [0.66, 0.82] |
| … | | | | |
| C1–C4 | 0.15 | 35 | **0.893** | [0.80, 0.99] |
| C4–C5 | 0.12 | 17 | 0.552 | [0.32, 0.91] |
| C2–C4 | 0.00 | 6 | 0.350 | [0.21, 0.88] |

共视最高的两对是 0.711 / 0.702，共视 0.15 的一对是 0.893——**排序与共视无关**。

### 3.2 身份构成是混杂项（重要方法学问题）

原始估计里 **共享身份数与 AUC 强负相关**：228 个 → 0.711，43 个 → 0.901。
原因是选择效应：能在相距 20–30 m 的两台相机里都出现的人，往往是画面里显眼、
衣着有辨识度的人；共享集越大，越会纳入普通衣着的人。

等量重采样（固定 15 个身份 × 200 次）后，这一负相关**消失**（ρ 从强负降到 −0.153），
而共视与 AUC 的相关仍然接近零（r = +0.179）。这说明：

**任何按机位对比较 AUC 的结论，必须先控制「共享身份集」，否则比的是身份构成，不是机位难度。**

### 3.3 区域级 A/B：论文原命题的直接检验

用内外参把每个框的落脚点反投影到地面 z = 0，再用地面网格（60 cm）算出两台相机的
共同可见区域，只保留**两个框都落在共同区域内**的配对：

| 对 | AUC（区域内） | n | AUC（区域外） | n | Δ |
|---|---|---|---|---|---|
| C4–C7 | **0.984** | 174 | 0.614 | 272 | **+0.371** |
| C2–C5 | 0.890 | 8 | 0.592 | 55 | +0.299 |
| C1–C4 | 0.893 | 453 | 0.705 | 14 | +0.188 |
| C3–C5 | 0.740 | 1 242 | 0.647 | 57 | +0.093 |
| C3–C6 | 0.714 | 1 542 | 0.657 | 128 | +0.056 |
| C1–C6 | 0.701 | 1 519 | **0.884** | 102 | **−0.183** |
| C5–C7 | 0.731 | 11 | **0.905** | 1 234 | **−0.174** |
| C4–C6 | 0.619 | 38 | 0.772 | 506 | −0.154 |
| C3–C4 | 0.788 | 471 | 0.911 | 272 | −0.123 |

**ΔAUC 中位 +0.042，11/17 为正，范围 −0.183…+0.371。** 按样本量加权后同样是混合符号。
区域内没有系统性优势。

### 3.4 几何与像素都不是解释项

| 预测变量 | vs AUC(等量) | 结论 |
|---|---|---|
| 共视率 | r +0.179 / ρ +0.161 | 无 |
| 几何重叠（标定） | r +0.051 / ρ −0.072 | 无 |
| 光轴夹角 | r −0.08 / ρ −0.08 | 无 |
| 相机基线 | r +0.03 / ρ −0.03 | 无 |
| 框高中位（min） | r −0.07 / ρ +0.09 | 无（全部 141–341 px，已在阈值以上，无方差可解释；合成降质见 §3.6） |

只保留共享身份 ≥30 的对时，共视与 AUC 的相关进一步降到 **r = −0.05**。

### 3.6 像素预算扫描（合成降质，8 档）

§3.4 的像素项只是「机位之间高度不同」，没有真正跨越像素阈值。为了测出 P1 的拐点，
把同一批裁剪按目标人物高度降采样再升回（`INTER_AREA` → `INTER_CUBIC`），
还原到模型输入尺寸后重新编码；每档仍是 15 身份 × 200 次等量重采样。
编码在远端 L20 上完成（8 档共 7 440 crop，3 分钟含打分）。

| 目标高度 | 有效像素中位 | AUC 中位 | 范围 |
|---|---|---|---|
| 320（native） | 230 | **0.795** | 0.661–0.916 |
| 160 | 160 | 0.791 | 0.651–0.914 |
| 112 | 112 | 0.786 | 0.657–0.909 |
| 80 | 80 | 0.778 | 0.649–0.899 |
| 56 | 56 | 0.768 | 0.661–0.905 |
| 40 | 40 | **0.733** | 0.632–0.893 |
| 24 | 24 | 0.706 | 0.565–0.857 |
| 16 | 16 | **0.671** | 0.483–0.826 |

**结论：身体外观在这个区间几乎不受像素预算约束。** 从 230 px 降到 16 px（缩小 93%），
AUC 只从 0.795 掉到 0.671，**始终高于随机**；单对最大跌幅 −0.331，仍有 0.48 以上。

- 这意味着**本站点跨机位外观失败（AUC 0.45–0.62）不能归因于「人太小」**：
  WILDTRACK 上 16 px 的人仍可被区分，而本站点的人在 200–300 px 量级却接近随机。
- 因此 **P1（人脸像素）只能约束人脸通道**（本站点人脸中位 52 px，低于 60 px 分割），
  **不能**用来解释身体外观的跨机位失败；后者更可能来自 P3（衣着重复）与室内成像。
- 交互检验：ΔAUC(16px − native) 与共视率 r = +0.445、ρ = +0.347（n=16，符号与
  40 px 档的 r = −0.225 相反）→ **无稳定的 P1×P2 交互**，不应据此下判断。

**这一档的口径限制**：合成降质只做重采样，缺少真实低分辨捕获中的传感器噪声、
运动模糊与压缩失真，因此 **0.671 是乐观上界**；真实 16 px 捕获会更差。


### 3.5 相机编号映射（必须交代）

`C1..C7` 与设备名（CVLab1–4 / IDIAP1–3）的官方对应未随包提供。用「地面网格预测重叠 vs
实测共视」做 7! 枚举反推，最优映射 ρ = +0.639：

```
C1=IDIAP2  C2=IDIAP1  C3=CVLab1  C4=CVLab3  C5=IDIAP3  C6=CVLab2  C7=CVLab4
```

该映射下 CVLab1 与 CVLab4 相距 **0.2 m**（近乎同址双机，光轴差 30°），与实测
cov(C3,C7)=0.48 相容；若按「C1–C4=CVLab1–4」的直觉映射，会得到「同址双机共视 0.15」的
自相矛盾结果。次优映射 ρ=0.604（仅交换 C1/C6），说明映射并非唯一确定，
但它只影响几何类结论；**3.1–3.3 的共视结论不依赖映射**。

## 4. 局限

1. **单站点、单编码器**：WILDTRACK 一个广场、7 机位、OSNet 一个模型。
2. AUC 只用 20 帧/视角；区域内正例在部分对上只有 8–11 个（C2–C5、C5–C7），
   这几对的 Δ 不应当作证据。
3. 落脚点反投影假设人直立、脚在 z=0 平面，远处与遮挡会使落点偏移。
4. **本实验无法排除「WILDTRACK 所有对都足够好」这一解释**：AUC 全域 0.56–0.89、
   中位 0.78，方差太小；而在我们自己的办公站点，AUC 全域 0.45–0.62，方差同样小
   但落在另一端。**两个站点各占一个极端，都没有「中间地带」可供校准。**
5. 共视是行为统计量（有人同时出现在两画面），不是纯几何量；用几何重叠替代后结论不变。

## 5. 对论文的影响（建议改动）

1. **§P2 的断言降级**：从「共视 → L1 可用」改为
   「共视 → 同时可见 → 存在时间锚与人工裁定入口；**不构成外观可匹配的条件**」。
   现文第 209 行「P2 predicts that L1 is available there」应删除或改写。
2. **318–320（AUC 0.904）的归因要收回**：它是全站唯一共视对，但共视与 AUC 在本实验里
   无关，因此不能把 0.904 归因于共视。可改为「该对同时在视角几何上最接近（同侧、
   近距），两种因素在本站点无法分离」。
3. **补一条方法学提醒**（可放 Limitations 或 Supplement）：
   按机位对比较 AUC 必须控制共享身份集，否则比的是身份构成。
4. **~~P1 的地位相对上升~~ —— 该判断已被 §3.6 推翻，改为此表述**：
   像素预算**只约束人脸通道**（本站点人脸中位 52 px < 60 px 分割），
   **不解释身体外观的跨站点差异**（WILDTRACK 16 px 仍有 AUC 0.671）。
   现文若把"人太小"当作跨机位失败的通解，需要收回；应改为「失败来自衣着重复与
   室内成像条件，像素预算只对人脸通道生效」。
5. **P1×P2 交互不成立**（§3.6 末）：16 px 档 ΔAUC 与共视 r=+0.445、40 px 档 r=−0.225，
   符号相反 → 不要写"低像素下共视更重要"这类推测。
6. **建议的下一处实验**（若要继续补外推）：在 WILDTRACK 上做**真实退化**而非合成退化
   （先降采样再 JPEG 重压 + 加噪声 + 运动模糊），或直接找一个人物中位 60–100 px 的
   公开多机位集。合成降质给出的 0.671 是乐观上界。

## 9. AUC 实现缺修正（2026-11-25）

**缺陷**：`wt_auc.py / wt_auc2.py / wt_region.py / wt_sweep.py / wt_sweep_gpu.py` 里的
`auc_of()` 用 `argsort().argsort()` 得到 **0 起秩**，却代入曼-惠特尼的 **1 起**公式，
且未处理并列分数。后果是 AUC 恒低 `1/n_neg`：

- 8 正 8 负完全分离 → 返回 **0.875**（应为 1.0）；
- 80 正 20 负完全分离 → 0.950（偏差恰为 1/20）。

**修正**：秩从 1 起算，并列取平均秩（向量化实现）。五个脚本已就地改，
新增 `tmp/wt/recheck_sweep.py`（用落盘的 `sweep_*.npz` 离线重算，不重编码）。
