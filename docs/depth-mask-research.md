# 带深度的掩膜：可行性研究与实测（2026-10-12）

**问题**：静态 2D 手工区域掩膜意义有限（用户判断）——是否存在"带深度"的掩膜方案？
**结论先行**：
1. 文献中"带深度的镜面/反射掩膜"存在三类，其中两类依赖硬件（RGB-D 传感器）或重模型（MirrorMamba）；
2. 与我们"单目 RGB、固定机位、无传感器"匹配的可行形态是**逐检测动态深度判定**（不是画区域，而是 per-detection 的深度一致性门）；
3. 今日用 **29 倒影 / 28 真人 / 5 墙镜** 轨迹实测 6 个深度特征：**单目深度无法辨别"地板倒影"**（AUC≤0.65）；**脚点残差**继续有效地区分**墙玻璃镜像**（1.24 vs 0.2，延续 P1 的 AUC 0.931）；
4. 根因已被数据+文献双重证实：**深度模型在非朗伯面产生"幻觉"**——把倒影当真人并抄其深度。

## 一、文献：三类"带深度的掩膜"

### 1.1 RGB-D 传感器类（依赖深度相机；且传感器在反光面本身失效）
- **PDNet《Depth-Aware Mirror Segmentation》CVPR 2021**：ToF 深度在镜面处返回"反射光程总长"而非表面深度 → 镜面边界出现显著深度不连续 → 用于镜面分割；构建首个大规模 RGB-D 镜面数据集（3049 图，IoU 77.8%）。**适用条件：必须有 ToF/RGB-D 传感器**——我们无此硬件。
- **MDPI Sensors 2026《RGB-D Mirror Segmentation with Reliability-Guided Residual Correction》**：SATNet + 深度分支 + **双深度证据**（传感器深度 + Depth Anything v2 单目深度；编码跨深度差异 / 有效性 / 局部深度不稳定）→ 83.57 IoU。**关键认知：传感器深度在镜面附近缺失/噪声/几何不一致，直接用有害，需"可靠性引导"。**
- **ICRA 2024《Reliability-Guided Depth Fusion for Glare-Resilient Navigation Costmaps》**：反光表面眩光使 RGB-D 产生空洞与虚假尖峰 → 提出 **Depth Reliability Map（逐像素置信度）**，不可靠测量降权/剔除。**理念：反光治理 = 可信度问题**，而非硬掩膜。

### 1.2 单目深度引导的镜面分割（重模型路线）
- **MirrorMamba**（arXiv:2511.06716，2025-11）：**感知深度（MiDaS）+ 对应关系 + 光流** 三线索融合 + Mamba 架构，视频镜面分割 SOTA（VMD-D IoU 0.646 / MMD 0.793）。→ 深度是镜面判定的有效线索**之一**，但**单独用深度不够**（多线索融合是共识）；且它处理的是"镜面"而非"地板倒影"。
- 同领域：UTLNet / SATNet 等（MDPI 论文对比指出它们在镜面区易过分割或漏检）。

### 1.3 反射假阳性过滤（语义/实例融合，无深度）
- **arXiv:1904.13273《Detecting Reflections by Combining Semantic and Instance Segmentation》**：健身房监控（大量镜面）场景，instance + semantic 融合自动识别"反射假阳性"，真实监控数据的直接先例。

### 1.4 与"地板反光"最相关的两条（本次新发现）
- **IJCV 2023《Indoor Obstacle Discovery on Reflective Ground via Monocular Camera》**（附录实测）：**反光地面使深度相机失效**——structured light 大片空洞、stereo 错误匹配；"反光纹理比地面强 → 被当主体"；普通反光去除算法不能直接用于反光地面；**只有 3D LiDAR 不受影响**。
- **NTIRE 2025 / ECCVW 2024 / GIFT 2025**：**深度基础模型在非朗伯面（透明/镜面）产生"深度幻觉"**（估计"反射内容"的深度而非物理表面）；GIFT 用几何不变性微调抑制幻觉。→ 这正是我们下面实测现象的学术名称。

## 二、我们的实测（新增：`tools/depth_gate_test.py`）

**数据**：spread 集经"兄弟轨迹审计"的 **29 条倒影轨迹 / 28 条源（真人）轨迹** + 5 条用户确认墙玻璃镜像（对照）；每轨迹采样 5 帧；MiDaS-small（本机 CPU）。

**特征对比（轨迹级中值）**：

| 特征 | AUC | 倒影 med | 真人 med | 墙镜 med |
|---|---|---|---|---|
| r2 下半/上半深度比 | 0.645 | 1.026 | 0.995 | 0.981 |
| r3 下1/3 / 上1/3 | 0.636 | 1.038 | 1.010 | 0.975 |
| slope_n 框内竖直梯度 | 0.641 | 0.059 | 0.020 | −0.041 |
| r_h 同排两侧对照比 | 0.397 | 0.316 | 0.343 | 0.608 |
| **foot_resid 脚点地板残差** | **0.485** | 0.302 | 0.205 | **1.241** |
| d_med 框内深度 | 0.350 | 102 | 114 | 226 |

→ **6 个特征全部无法分离"地板倒影 vs 真人"**（AUC 0.35~0.65，分布完全重叠，见 `fig_depth_gate.png`）；脚点残差继续有效地区分**墙镜**（1.24 vs 0.2 —— 延续 P1 结论）。

**根因实证**（f=5780，323#97 真人 / 323#101 倒影）：

- MiDaS 给真人框深度 **169.5**；给其正下方的倒影框 **179.4**（≈ 抄了真人深度，框内近乎平坦）；
- 而倒影正下方**真实地板**深度为 **211.3**（明显更近）。
- 可视化 `depth_map_of_reflection.png`：深度图上"人框"与"倒影框"几乎同亮度（=同深度），都不是地板的深度。
→ **深度模型把倒影"语义补全"成一个人**（非朗伯面幻觉），而不是渲染它所在的地板几何 → **任何"基于框内深度几何"的特征都必然失效**。

## 三、设计定案：以"深度门"代替"掩膜"

**判废两种静态掩膜**：
- 2D 手画区域掩膜：需人工、不可迁移、粒度粗（已由用户判断否定）；
- **按深度区间筛选同样无效**——实测倒影与真人在**同一深度量级**（179 vs 170），且同场景多人在不同深度，任何深度区间都会误伤真人。

**可用形态 = 逐检测动态判定（"掩膜即判定"）**：

```
时间门（候选生成）
  → 门A  dt 快慢分流（快 = 镜像嫌疑）          [crosscam_mirror_rule.py]
  → 门B  深度脚点地板残差（墙镜/幻影）          [AUC 0.931 —— "带深度"的核心]
  → 门C  几何兄弟轨迹检测（地板倒影）           [深度无解后的几何补充，已验证]
  → 人工终审
```

- 门 B/C 均为**逐检测、逐帧**执行，**无需人工画区域**，可解释、可审计；
- 门 B 是"带深度"的直接实现；门 C 是本次实测证明"单目深度补不上"后的必要补充；
- 若未来升级：① 单目深度模型微调（GIFT 思路，修"幻觉"）；② 引入 RGB-D → 可靠性地图（ICRA24 思路）；③ 重模型（EBLNet / MirrorMamba）——留作 P3 备选。

**与用户判断的对齐**：认同"不带深度的掩膜意义不大"——但修正一半：**不是把深度拿来画区域，而是把深度拿来做判定**；同时本次实测也证明"带深度的判定"有明确边界（**地板倒影对单目深度免疫**）。

## 四、局限（如实说明）

- 倒影/真人标签来自兄弟几何审计（启发式）+ 目视抽检，非像素级 GT；若个别标签有误，会稀释特征差异——但 3 个目视验证案例（323#101 等）均独立支持"幻觉"结论；
- 仅测 MiDaS-small 一个模型；更强深度模型（Depth Anything V2 / 度量深度模型）未测（可作为后续 1 次实验）；
- 每轨迹 5 帧采样；倒影轨迹普遍极短（碎片化），噪声大。
