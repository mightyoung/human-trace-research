# 掩膜重编码终局评估：掩膜能否替代/净化框裁剪

日期：2026-10-18
脚本：`tools/encode_mask_reid.py`（主）、`tools/eval_mask_variants.py`、`tools/mask_shift_analysis.py`、`tools/mask_diag.py`、`tools/osnet_device_control.py`
产物：`output_crosscam_local/1012_osnet_emb_mask{fill,bbox}/`、`output_crosscam_local/1012_osnet_crops_mask/`、`output_crosscam_local/selector_osnet_1012/eval_mask_variants.json`

## 结论

**两种掩膜重编码均不如原框裁剪，上一份报告预期的"掩膜收益"被证伪。**

1. 同轨迹口径（1080 条轨迹交集，`common`）下：基线 **0.472** / maskfill **0.316**（−15.6pp）/ maskbbox **0.446**（−2.6pp）覆盖率。掩膜没有带来任何覆盖或误合并上的收益。
2. maskfill（原框+掩膜置黑）出现**身份簇塌缩**：训练集身份簇 K 从 132 → 105（full）、116 → 85（common），说明不同人被编码得更像了。
3. maskbbox（裁剪到掩膜外接框）表面上 full 口径 +2.3pp，但那是因为它**丢掉了 27 条小目标轨迹**（220 → 193 条测试轨迹）；在这同一批轨迹上基线是 0.472，仍然高于它。
4. 原因是编码器层面的：同裁剪只做掩膜置黑，cosine 只有 **0.61–0.79**（92–100% 的裁剪 <0.99），掩膜占比 0.2–0.4 的裁剪更低到 **0.49–0.53**。这不是"去掉噪声"的微扰，而是把输入移到了分布外（自然背景 → 纯黑），OSNet 依赖的构图/尺度线索被一并删除。
5. 真正可用的是掩膜的**副产品**：约 40–50% 的 DINO 轨迹在 8 个采样帧里找不到任何 YOLO 人体（目检为空椅子/桌面），掩膜命中率可直接当**误检过滤器**。门控后（≥50% 帧命中）误合并 1.96% → 1.18%（8/408 → 5/423），但 **Fisher p=0.41，不显著**，只能记为方向性观察。

## 方法（口径）

| 项 | 设置 |
|---|---|
| 基准框 | `output_crosscam_local/1012_ab/{seg}_{a,b}.jsonl`（DINO 1333×750 / box_thr 0.30 / containment-NMS 0.85 / ByteTrack 后，每 5 帧一条） |
| 采样 | 与基线完全一致：每条轨迹 `np.linspace` 8 点 |
| 掩膜 | `yolo26s-seg.pt`，imgsz 1280，conf 0.10，classes=[0]，`retina_masks=True` |
| 匹配 | 同帧一对一贪心，IoU ≥ 0.3（取掩膜用，非召回评估） |
| 变体 V1 `maskfill` | 裁剪仍用 DINO 框，掩膜外像素置黑 |
| 变体 V2 `maskbbox` | 裁剪改为掩膜外接框（扩边 4%），掩膜外置黑 |
| 兜底 | 无掩膜时不改像素，回退原裁剪并记 `used=0` |
| 编码 | OSNet x1_0（msmt17 combineall），L2 归一后按轨迹求均值；**CPU** |
| 评估 | `eval_two_encodings` 同一管线：会话对齐 + 每身份 z 校准 + self-cal（a/b 一致率 ≥0.90）最大化覆盖 |

**设备对照（排除混淆）**：同一批 121 张裁剪在 CPU 与 DirectML 上编码，cosine = **1.000000**（rel-L2 2.4e-6），所以本次 CPU 编码与 10-17 的 DML 基线可直接比较。

基线 `full` 口径复现 **0.423 / 0.903 / 1.96%**，与 10-17、10-18 的历次结果完全一致，评估器可信。

## 主结果（覆盖 / 稳定率 / 共现误合并）

| 口径 | 基线 | maskfill | maskbbox |
|---|---|---|---|
| `full` 各自全集 | 0.423 / 0.903 / 1.96%<br>te=220, K=132 | 0.421 / 0.903 / **1.48%**<br>te=221, K=105 | **0.446** / 0.907 / 1.86%<br>te=193, K=85 |
| `common` 轨迹交集 | **0.472** / 0.901 / 2.07%<br>te=193, K=116 | 0.316 / 0.902 / 2.04%<br>K=85 | 0.446 / 0.907 / 1.86%<br>K=85 |
| `gate` 掩膜门控（仅基线） | 0.405 / 0.901 / **1.18%**<br>te=200, K=117 | — | — |

读法：
- **`full` 不可直接横比**：maskbbox 少了 27 条测试轨迹（小目标被最小尺寸门槛挡掉），它的 +2.3pp 是"少做了难题"。
- **`common` 是唯一公平口径**：三者同 193 条测试轨迹、同 812 对共现。基线 0.472 最高，maskfill 塌到 0.316，maskbbox 0.446。
- 稳定率（a/b 一致率）三者都是 0.90 左右，说明差异不是判定抖动造成的。
- 误合并绝对数都只有个位数（5–8 对），任何两点间差异都在噪声内。

## 机制：掩膜把表征推到了分布外

同裁剪、同权重、只差"掩膜置黑"的逐裁 cosine（`shift_analysis.json`）：

| 段 | maskfill 均值 | p10 | cos<0.99 占比 | maskbbox 均值 |
|---|---|---|---|---|
| 305_train_529 | 0.673 | 0.452 | 92% | 0.614 |
| 318_train_525 | 0.677 | 0.433 | 99% | 0.680 |
| 320_train_514 | 0.793 | 0.600 | 92% | 0.696 |
| 323_train_510 | 0.659 | 0.437 | 97% | 0.617 |
| 305_test_544 | 0.671 | 0.469 | 96% | 0.635 |
| 323_test_527 | 0.661 | 0.503 | 98% | 0.610 |

按框内人体占比分桶（305_train，maskfill）：

| 人体占比 | n | cosine |
|---|---|---|
| 无掩膜（回退原图） | 970 | 0.981 |
| 0.2–0.4 | 1231 | **0.511** |
| 0.4–0.6 | 1911 | 0.655 |
| 0.6–1.0 | 876 | 0.722 |

**恰恰是"最该被修"的那批（人只占框的 1/3，剩下是桌椅）偏移最大**——说明掩膜确实去掉了桌椅，但编码器不认这种输入。OSNet 是在自然裁剪上训练的，纯黑背景 + 归一化后属于域外样本；同时所有被置黑的裁剪共享同一片黑场，身份间相似度上升，于是 K 塌缩、覆盖下降。

这与 10-18 早些时候 A 方案（几何收紧）的结论同向：**这个表征依赖整框构图（尺度 + 上下文），"只留人"与"保表征"是冲突的**。

## 掩膜作为误检过滤器（唯一有信号的用法）

`mask_diag.py` 对 320_train_514 抽 24 帧：26 个 DINO 框里 **12 个（46.2%）** 落在空椅子上，YOLO 在 conf 0.05 也没有框（`320_train_514_diag_miss.jpg`，红框=未匹配，绿框=YOLO）；323_test_527 为 8/28（28.6%），多为玻璃后远人与画面边缘。

门控（轨迹的 8 个采样帧中 ≥50% 能找到 YOLO 人体才保留）：

| | 轨迹 | 覆盖率 | 稳定率 | 误合并 |
|---|---|---|---|---|
| 基线全集 | 1252（test 220） | 0.423 | 0.903 | 1.96%（8/408） |
| 门控后 | 1129（test 214） | 0.405 | 0.901 | 1.18%（5/423） |

- 覆盖率 −1.8pp：被剔的轨迹里也有少量真人（玻璃后远人、遮挡只露头顶），这是代价。
- 误合并相对下降 40%，但 Fisher 精确检验 **p=0.41**，**不显著**（事件数只有 5 vs 8）。
- 因此只能写成：**方向有利、成本为零（在已有 YOLO 的前提下）、待更大评测集确认**，不可当收益宣传。

## 目检证据

- `323_test_527_check.jpg` / `305_test_544_check.jpg`（三联：原图 / maskfill / maskbbox）：掩膜边界贴合人体轮廓，桌椅确实被压掉；坐姿场景会连带少量椅背/扶手（COCO person 分割在低分辨率坐姿上的已知问题）。
- `323_test_527_diag_mask.jpg`（绿色=掩膜轮廓）：多数掩膜干净，个别把椅背算进人体。
- `320_train_514_diag_miss.jpg`（蓝=DINO 匹配、红=DINO 未匹配、绿=YOLO）：**未匹配框集中在空椅子/显示器**，与"证据图是空椅子"的旧观察互为印证。
- `320_train_514_f900_zoom.jpg`：该帧 DINO 1 框、YOLO 0 框，框中心是空椅。

## 速度（本次实测）

- 掩膜重编码全量 8 段 20425 帧：三进程并行（各 5 线程）**1h40m**，单进程 1.1–1.3 帧/s（YOLO CPU @1280）。
- 若只做门控（每轨迹 8 帧抽样、复用已有轨迹），成本约为上述的 1/8，但仍高于"不做"。

## 风险与未验证

1. 无人工真值：门控的"真人/空椅"判定来自目检抽样（320 的 26 框、323 的 28 框），未做全量标注。
2. 掩膜门控的收益（误合并 −0.78pp）不显著，样本量（423 对 / 5 次误合并）不足以支撑上线决策。
3. maskbbox 丢轨迹是"最小尺寸门槛 24×48"造成的，属实现选择而非方法本身；但这也说明它对小目标不友好。
4. 只测了"置黑"一种背景处理。域外问题可能由填充方式引起，未测：局部均值填充、模糊背景、原图去饱和后保留背景等。
5. 掩膜来自 `yolo26s-seg`（非用户指定的 YOLO11s-seg），掩膜质量差异未量化。
6. `shift_analysis` 的 join 有一处口径差：基线 `1012_osnet_crops` 的 `k` 是"成功裁剪计数器"，本次是"采样序号"，个别轨迹在裁剪失败时会错位。因此"无掩膜回退"桶的 cosine 是 **0.981** 而非 1.000——这是 eid 对齐噪声，不影响"置黑使 cosine 降到 0.5–0.7"的主结论（该效应量比错位噪声大一个数量级）。

## 建议

1. **不采用掩膜重编码**。维持"原框裁剪 + OSNet"，把这次结论记入负结果，避免重复投入。
2. **掩膜只用于检测级用途**：误检过滤（门控）、掩膜面积做质量分、可视化抠图。不要用它改像素再编码。
3. 若一定要清洗"空椅轨迹"，建议放在**检测阶段**做交叉验证（轨迹抽样 8 帧，YOLO 命中率 <50% 判为幽灵轨迹），并默认只记录不删除，先积累一个月的人工复核样本。
4. 若仍想在表征上吃掩膜的收益，正确路线是**保住域内统计**：把掩膜外区域用裁剪内中值色/强模糊填充，而不是置黑；或直接把掩膜作为训练期数据增强。这是一次编码即可验证的小实验，优先级低于检测器切换。
5. 检测器切换（YOLO26s-seg，conf 0.10）仍是当前收益最大的一步——它同时解决漏检、幽灵轨迹与速度问题，掩膜只是它的副产品。
