# 跨摄像头"责任目标转移"现状盘点（2026-10-14）

盘点对象：目标离开 A 机位画面后，其**身份/跟踪责任被 B 机位接续**（handoff / 跨机接力）的实现与验证现状。
数据基础：multi-cemra 6 路 10min 同步（305 办公1 / 316 走廊 / 318 办公2 / 320 球机 / 323 茶水间 / 343 电梯间）。

## 结论先行

1. **"离线机制链"已基本建成**：事件提取 → 门发现 → 候选生成 → 外观打分 → 筛选+全局唯一化 → 接力链 → 覆盖度量，全链有代码有产物（2618 候选 → **47 条确认边 / 32 链**）。
2. **"验证闭环"只完成一半**：仅 **318×320（真重叠）有独立真值**（8 对，recall 1.0 / precision 1.0）；343×316 的人工判定**进行中（19/241）**；其余 13 对**无真值**。
3. **"运行时与更新"未实现**：无在线交接系统（全部离线批处理）；图边状态机（candidate→active→…）**设计就绪、未运行**；H2 对照未做。
4. **交接强弱的实测排序**（接力边数）：316↔318(14) > 316↔343(10) > 318↔323(7) > 316↔323(4) > 305 系(3×3) > 343↔323 / 318↔343(2)；**5 对零边**（320 系与跨区远端）。
5. **出口"静默率"暴露最大缺口**：全局 move 实体 136 个离开门控，仅 41 个被接力覆盖（**exit continuity 0.301**）；其中 **305 的出门覆盖 = 0.000**（20 个出门全部无接力），是最优先修复项。

## 一、口径与数据

- **责任转移（handoff）判定** = 时间门（统一 OSD 时间轴）→ 外观门（末碎片⇄首碎片 cos ≥ 0.943）→ 全局 mutual-best 唯一化（出/入度 ≤1）。
- **三类关系不得混淆**（TG-02）：视觉重叠（仅 318×320 为真）≠ 门户转移（接力边的语义）≠ 物理可达（走廊星型为**先验假设**）。
- 验证数据两条线：① **318×320 重叠对**（人工确认 8 对，C0-A 支路）；② **343×316 门户事件表**（107 事件 / 241 配对候选，人工判定 19/241 进行中，C0-B 支路）。

### 2.1 343×316 判定中间结论（19/241 样本，**漏接根因已定位**）

对已判定的 19 对做与 relay-v5 47 边的对账——**漏接 5 对**（人工判同人但无边），根因三类：

| 漏接对 | cos | 根因 | 说明 |
|---|---|---|---|
| E042↔E046 / E042↔E048 | 0.954 / 0.953 | **mutual-best 排他竞争误排除**（3 对之一类） | 同一 343 事件（E042）与多个 316 事件同人（一人多次通行），被 cos 更高的 E053(0.966) 独占 → 一对一唯一化与"一人多次通行"不匹配 |
| E038↔E043 | 0.948 | 同上（排他竞争） | — |
| E010↔E014 | 0.958 | **候选生成漏** | 不在 2618 候选集内（dt/窗参数问题） |
| E011↔E013 | 0.954 | **被 0.0006 之差排挤** | 与竞争边分数差过小被 unique 排 |

**改进方向（来自本轮判定分析）**：多对多匹配（一个人多次通行的边集）+ entry/exit 类型与 dt 先验 + 高 cos 强制入围（cos ≥ 0.95 不参与排他淘汰，改人工/二次确认）。
**待裁决冲突**：E010、E042 存在"一个 343 事件被判与多个 316 事件同人"的多判互斥（需施加双向唯一性/最小代价匹配后出最终 TP/FP）。
