# 按摄像头分组的聚类/选择器方案：可行性与效果评估

> 研究日期：2026-10-14 ｜ 数据：1012 切分（train 1395 轨 / test 348 轨，cradio v5 768d 嵌入）
> 实验脚本：`tools/camgroup_study.py` ｜ 运行日志：`output_crosscam/analysis/camgroup_study/run_log.txt` ｜ 数据：`study.json`
> 纪律说明：本报告区分【实测】（本机可复现的运行结果）、【文献】（外部工作，注明阅读深度）、【推断】（由前两者推导）。

---

## 0. 结论（先行）

**1）可行性：可以跑通，聚类纯度指标确实上升；但作为"每摄像头一个独立选择器"的最终形态，它是有结构性缺陷的——不推荐直接采用。**

**2）关键实测发现**：

- 聚类层（共现负对 F1，同摄像头子集对照）：分组方案 **全摄像头上升**——305 +0.012、318 +0.019、320 **+0.094**、323 +0.035；
- 选择器层（test 跨段身份保持，公平子集 n=72）：**全局 0.931 vs 分组 0.875——分组反而更低**；
- **跨摄像头对在分组方案下不可通约**（不同选择器的 ID 空间不相通，跨机对"是否同簇"无定义；物理拼接后跨机保持率恒为 0）——而跨机身份贯通是本项目的核心目标之一；
- **净收益归因**：分组的主要收益来自"阈值/尺度不适配"（320 球机在全局阈值下覆盖率 0%），而非"身份空间真的需要隔离"。

**3）推荐方案（已实验验证）：不做物理隔离，做"全局聚类 + 按摄像头校准阈值"（方案 F）。**
它拿走了分组收益的大头（320 覆盖率 0% → 0.464，323 同簇率 0.750 → 1.000），同时身份保持率与全局完全持平（0.941 vs 0.941，n=68 共同子集）、保持全局 ID 可通约、模型只有一个。

**4）文献佐证**：学界的 camera-aware 方法（CAP、CBN、Intra-Inter 等）**全部是"用相机结构改进统一空间"**，没有主流工作采用"隔离的每相机独立身份空间"；MTMC 工程范式（ReidTrack 等）虽为"单机聚类→跨机关联"两阶段，但**跨机关联阶段不可省略**，且其目标仍是全局一致 ID。我们的实验结论与文献方向一致。

## 1. 研究问题与实验设计

**用户设想**：为向量打上摄像头标签 → 按摄像头分组 → 各组分别无监督聚类（=每摄像头一个选择器）→ 测试时输入向量输出分类。

**方案定义**（本文档口径）：
- **方案 G（Global，现有基线）**：全部摄像头轨迹一起聚类 → 单一原型库（125 原型）+ 单一开集阈值；
- **方案 C（Camera-grouped）**：按摄像头分成 4 组独立聚类 → 4 个原型库 + 4 个阈值；
- **方案 F（折中，本研究新增）**：全局聚类不变，仅"开集阈值"按摄像头分别校准。

**实验设计（计划先于实测）**：A 摄像头信号量化 → B 聚类层对照（同子集）→ C 选择器层对照 + C2 初始化稳健性 + C3 同参数对照 → D 跨段身份保持（含公平子集）→ E 组间原型诊断 → F 折中方案。全部复用 `train_selector_cluster.py` 的聚类/评估代码路径（同一网格、同一选择标准 = 共现负对 F1）保证可比。

**数据**：train = 305(616 轨)/318(341)/320(74)/323(364)；test = 305(130)/318(128)/320(28)/323(62)。共现负对总数 7945（全局）。

## 2. 实验结果（全部【实测】）

### A. 摄像头信号：存在但温和

| 指标 | 数值 |
|---|---|
| 摄像头分类（test 轨 → train 各摄像头质心，4 类） | acc = **0.681**（随机基线 0.25） |
| 同摄像头随机对 cos 均值 | **0.847** |
| 跨摄像头随机对 cos 均值 | **0.827** |
| 差值 | **+0.020** |

解读：嵌入中携带摄像头信号（分类 68%），但**远未达到"线性可分"程度**；同机/跨机相似度的系统性差距只有 0.02。**这与 CAP(AAAI'21) 论文报告的"一个 ID 的同机图像明显比跨机更聚集"的强现象相比是温和的**——cradio v5 + 同楼宇场景使得域偏移本身不剧烈。（局限：随机对以异人对为主，见 §6。）

### B. 聚类层对照（per-camera 子集，cooc-F1；同子集直接对比）

| 摄像头 | 全局方案 | 分组方案（各自最优） | 差值 | 分组最优方法 |
|---|---|---|---|---|
| 305 | 0.853 | **0.865** | +0.012 | kmeans K=60 |
| 318 | 0.897 | **0.916** | +0.019 | kmeans K=60 |
| **320** | 0.846 | **0.940** | **+0.094** | kmeans K=20 |
| 323 | 0.741 | **0.776** | +0.035 | kmeans K=60 |

- **分组在每一条摄像头上都提升了聚类纯度**，320（球机）幅度最大；
- 全局最佳（本轮重跑）：kmeans K60 F1=0.8496（全库）；已交付版 mutual-knn k5 F1=0.8456（注：kmeans 对初始化敏感，见 C2；mutual-knn 完全可复现）。

### C. 选择器层对照（test，known-restricted）

| 摄像头 | 方案 | 覆盖率 | 双侧 known 对数 | 同簇率(same) | 碰撞率(coll) |
|---|---|---|---|---|---|
| 全体 | 全局 | 0.468 | — | 0.920 | 0.044 |
| 305 | 全局 | 0.685 | 89 | 0.966 | 0.084 |
| 305 | 分组 | **0.831** | 108 | 0.852 | 0.059 |
| 318 | 全局 | 0.250 | 32 | 0.906 | 0.082 |
| 318 | 分组 | **0.461** | 59 | 0.797 | 0.060 |
| **320** | 全局 | **0.000** | 0 | — | — |
| **320** | 分组 | **0.393** | 11 | 1.000 | 0.246* |
| 323 | 全局 | 0.677 | 42 | 0.833 | 0.205 |
| 323 | 分组 | 0.516 | 32 | 0.750 | 0.119 |

\* 320 test 仅 28 轨，11 对 known，统计噪声大。

**模式**：分组方案**覆盖率系统性上升**（阈值贴合各自尺度），但**同簇率下降**（更松的判定把更多边缘对纳入后出现分歧）；碰撞率升降不一。

### C2. kmeans 初始化稳健性（5 个随机种子，F1 波动）

| 对象 | seeds F1 | mean | std |
|---|---|---|---|
| 全局 K=60 | 0.782 / 0.812 / 0.850 / 0.819 / 0.838 | 0.820 | 0.023 |
| 305 K=60 | 0.885 / 0.846 / 0.908 / 0.853 / 0.863 | 0.871 | 0.023 |
| 318 K=60 | 0.938 / 0.926 / 0.916 / 0.930 / 0.936 | 0.929 | 0.008 |
| 320 K=20 | 0.945 / 0.960 / 0.947 / 0.973 / 0.940 | 0.953 | 0.012 |
| 323 K=60 | 0.791 / 0.780 / 0.779 / 0.801 / 0.796 | 0.789 | 0.009 |

**重要**：全局方案的"最佳值 0.850"是一次幸运初始化；按均值（0.820）比较，**mutual-knn 的 0.846 才是更稳的全局配置**。分组方案在 seed 平均口径下仍领先（除 305 与 mkn 持平外），且组内波动并未因为样本变小而恶化（std 0.008–0.023 与全局相当）。

### C3. 同参数对照（mutual-knn k5 thr0.3，只改"分组/不分组"）

| 摄像头 | 全局-mkn | 分组-mkn | 结论 |
|---|---|---|---|
| 305 | **0.876** | 0.872 | 全局略胜 |
| 318 | **0.888** | 0.866 | 全局胜 |
| 320 | 0.889 | **0.929** | 分组胜 |
| 323 | 0.754 | **0.757** | 基本持平 |

**这组对照说明：分组的收益并不来自"分组"本身，而是来自"分组后 kmeans 在小组上表现更好"**——即收益来源是"参数/方法适配性"而非"身份空间隔离"。

### D. 跨段身份保持（mutual-NN 对，train↔test）

| 方案 | 同摄像头 keep 率 | 跨摄像头 keep 率 |
|---|---|---|
| 全局 | **0.931**（n=72） | 1.000（n=3） |
| 分组（各自选择器） | 0.889（n=90） | **不可定义**（ID 空间不相通，n=7） |
| 物理拼接（4 组 ID + 组偏移） | 0.889（n=90） | **0.000**（n=7，数学必然） |
| **公平子集（n=72，两者均可判）** | 全局 **0.931** vs 分组 **0.875** | — |

**这是对"分组方案"最不利、也是最重要的一组数字**：在完全同口径的 72 对上，分组把身份保持率从 93.1% 拉低到 87.5%（-5.6pp），同时跨机对彻底不可比。107 对 mutual-NN 中跨机对本来就只有 3–7 对（1012 四点位不重叠，跨机同人事件少），分组方案直接把它们全部丢掉了。

### E. 组间原型诊断

- 4 组原型共 180 个；组内最近邻 cos 均值 **0.976**，跨组最近邻 cos 均值 **0.963**（p95=0.989）。
- 解读【推断】：跨组原型的"最近邻"非常接近（p95 达 0.989），意味着**若要合并组间 ID，需要一个区分"同人跨机 vs 相似不同人"的跨域判别器**——而这恰恰就是全局方案本来要解决的问题。分组没有简化问题，只是把它推迟到"组间合并"环节。

### F. 折中方案：全局聚类 + 按摄像头校准阈值（本研究推荐）

按摄像头分别校准开集阈值（组内 pos_p5 与 cooc_p99 中点）：305→0.9585、318→0.9608、**320→0.9331**、323→0.9751（全局原阈值 0.9651）。

| 摄像头 | 全局(固定阈值) | **F(按机校准)** | 对比 |
|---|---|---|---|
| 305 | cov 0.685 / same 0.966 | cov **0.746** / same 0.959 / coll 0.077 | 覆盖↑，一致率几乎不变 |
| 318 | cov 0.250 / same 0.906 | cov **0.320** / same 0.878 / coll 0.078 | 覆盖↑ |
| **320** | cov **0.000** / — | cov **0.464** / same 0.923 / coll 0.217 | **从完全失效到可用** |
| 323 | cov 0.677 / same 0.833 | cov 0.306 / same **1.000** / coll 0.258 | 阈值被 323 负例尾部(0.995)推高→保守高纯 |

**F2 身份保持（n=68 四方共同子集）**：全局 **0.941** ｜ 分组 0.882 ｜ **F 0.941**。

**F 方案特点**：拿走分组收益的大头（320 恢复、323 高纯），**身份保持零损失、ID 空间全局可通约、单模型**；代价是 323 的覆盖率比全局固定阈值低（0.306 vs 0.677）——即"按机校准"是双向的：对 320 放松、对 323 收紧。

## 3. 潜在问题与适用条件（综合【实测】+【推断】）

### 3.1 潜在问题清单

| # | 问题 | 证据 |
|---|---|---|
| P1 | **跨摄像头身份不可通约**（致命，对跨机任务） | D：跨机对不可定义；拼接后 keep=0；本项目核心含接力链/跨机检索 |
| P2 | **同机身份保持反降** | D 公平子集：0.931→0.875 |
| P3 | **收益来源并非"分组"本身** | C3：同参数下 305/318 反输；收益主要来自小组上 kmeans 更易调 |
| P4 | **参数/初始化方差**：组内参数（簇数 K、阈值）每摄像头一套，4 倍调参面 | C2：kmeans F1 随 seed 波动 ±0.02–0.04 |
| P5 | **数据稀释**：320 组仅 74 训练轨，簇/阈值统计不稳（320 test 仅 28 轨、11 对 known） | C 表 |
| P6 | **维护成本 ×4**：4 套模型/阈值/版本，新增点位再 +1 | 【推断】工程视角 |
| P7 | **组校准对"组内负例尾部异常"敏感**：323 的 cooc_p99=0.995（疑似反光/玻璃残留）把阈值推高，覆盖率受损 | F 表 |

### 3.2 适用条件（分组方案在什么情况下才值得）

1. **任务边界 = 单摄像头内部**（单机跨时段检索/去重/徘徊检测），不含跨机贯通；
2. **摄像头间域偏移剧烈**（如 320 球机这种"分数尺度完全不同"：全局阈值直接失效）；本数据上恰好 320 满足，而 305/318 不满足；
3. **每个摄像头有充足训练数据**（≥ 数百轨；74 轨已见统计不稳）；
4. 且接受"每人每机一个局部 ID"的产品语义（或另配第二阶段跨机关联）。

**反之，本项目的主任务（跨机接力、全局检索、选择器统一服务）不满足条件 1，因此不建议采用隔离分组形态。**

### 4.1 与"按摄像头分组"直接相关的相机感知方法

| 工作 | 做法 | 与我们的关系 / 借鉴点 | 阅读深度 |
|---|---|---|---|
| **CAP: Camera-aware Proxies** (AAAI 2021) | 全局聚类 → **簇内按相机切分 proxy**（不隔离）；intra- + inter-camera 对比学习 | 最关键近邻：证明"相机结构"应当作**簇内精炼**而非空间隔离；同机子簇观察与我们 A 实验同向 | 正文（PDF 摘录含方法/实验） |
| **O2CAP** (arXiv 2201.05820, 2022) | CAP 扩展；offline/online proxy 关联 | 其 ablation 明确报告"**intra-camera learning 不必要甚至有害**（当组内伪标签有噪声）"——与我们 P2（分组 keep 反降）同向 | 正文片段 |
| **CBN** (Camera-based BN, "Disassembling the Dataset") | 每相机独立 BN 统计，**把各相机分布对齐到同一子空间** | 方向与"折中方案"同源（对齐≠隔离）；若未来特征层面优化，优先 CBN 式归一化 | 正文解读（方法细节完整） |
| **Intra-Inter Domain Similarity** (TPAMI 2022/2024) | 相似度分解为 intra-domain + inter-domain 两阶段；ICSN 归一化 | 最接近用户设想的学术形态，但**最终仍是统一模型/空间**（分类分数作跨域特征） | 摘要 + 正文片段 |
| **TAUDL / DAL / UGA** | intra-camera → inter-camera 两阶段学习 | "先组内后跨机"思想先例——但均服务于统一模型训练 | 经 O2CAP 转述（未读原文） |
| **MGH: Metadata Guided Hypergraph** (arXiv 2110.05886) | 超图融合三类超边："Global Clustering"+"**Intra-camera Clustering**"+"Global KNN" | **"分组聚类"作为多源结构之一的直接先例**——分组是原料，融合成统一图才是本体；可借鉴其"多源超边融合" | 正文片段 |

### 4.2 近邻方法本身的可借鉴做法

| 方法 | 出处 | 可借鉴点 | 阅读深度 |
|---|---|---|---|
| **k-reciprocal 重排** | Zhong et al., CVPR 2017 | 邻域互惠编码 + Jaccard 重排；我们 mutual-kNN 的文献根；可用于选择器检索阶段的重排 | 摘要 + 方法（成熟共识） |
| **近邻软标签 + 一致性权重** | N-ULC, arXiv 2412.12220 | 用"kNN 集与簇的重叠度"做软标签、用近邻一致性给样本加权——**近似"局部近邻版选择器"**；可增强我们的 unknown 判定 | 解读页（注：其 SOTA 声明有争议，只借鉴机制） |
| **kNN 图 + GCN 精炼** | GLC, arXiv 2022 | 把聚类重述为图上的链路预测，早期停止防过拟合；可用于簇边界精修 | 解读页 |
| **多原型（hard/dynamic）** | PCLHD, arXiv 2402.19026 | 除均值原型外加入"hard 原型（离质心最远样本）"提升判别（理论：信息熵更高）——**对我们的原型库设计是直接可用的升级** | 正文片段 |
| **UReID 系统综述** | arXiv 2109.06057 | 伪标签四路线（聚类/图/软标签/渐进）全景；"互惠最近邻 + 动态标签图"是重要分支 | 摘要 |
| **单机→跨机两阶段（MTMC 范式）** | ReidTrack (CVPRW 2023)；Glance-MCMT (arXiv 2507.10115) | 工程标准架构：**每相机独立聚类/跟踪（正是"分组"）→ 跨机关联（不可省略）**；"只在没有足够相似匹配时才引入新全局 ID" | 正文 |

### 4.3 文献—实验交叉结论（【推断】）

1. 学界使用相机标签的方式**无一例外是"结构辅助"而非"空间隔离"**：把相机信息用于 proxy 切分（CAP）、分布对齐（CBN）、相似度分解（Intra-Inter）、多源图（MGH）——最终都回到统一空间。我们实验测得"隔离会破坏身份保持"，与此互相印证；
2. "每相机独立聚类"在文献中真实存在的位置是：**MTMC 的第一阶段（局部 ID）**——但文献共识是它必须配上第二阶段跨机关联，且局部 ID 只是中间产物；用户设想若用于单机任务成立，用于跨机任务则缺失必要环节；
3. 我们推荐的方案 F（全局 + 按机校准）本质上是"**用相机标签做校准，而不是做分区**"——与文献主流的利用方式一致，且实测零损失。

## 5. 结论与建议

### 结论

- **可行性**：技术上一次跑通无障碍（≈45 行核心改动），聚类纯度指标确实上升（+0.01～+0.09）；
- **效果**：但对"身份选择器"的核心使命（跨段/跨机身份一致性），**分组方案在公平口径下更差（0.875 vs 0.931）且丧失跨机可通约性**；增益实际来自"参数/尺度适配套"而非"隔离"；
- **适用边界**：仅"单摄像头内部 + 强域偏移 + 数据充足"三者同时成立时才值得考虑。

### 建议（按优先级）

1. **【直接落地】采用方案 F：全局聚类保持，开集阈值按摄像头校准。** 320 覆盖率 0%→46.4%，身份保持零损失；实现成本：`selector.npz` 增加 `thr_unknown_per_cam` 字段 + `predict(v, cam)` 支持（半天内可完成并回归）。
2. **【中期增强】借鉴 PCLHD 多原型**：为高价值簇补充 hard 原型，提升相似人区分度（与现有共现负对评估兼容，可 A/B）。
3. **【若坚持分组形态】必须补跨机关联阶段**（MTMC 式两阶段）：组内选择器只产出局部 ID，跨机合并用独立判别器/时空门限承接——工作量远大于方案 F，且收益未证明超过 F。

### 局限与未验证项

- 1012 四点位**无重叠视野**，跨机同人对极少（3–7 对），跨机结论的统计强度有限；跨机身份质量需在 multi-cemra（318×320 有真 GT）上补充验证；
