# TOP-2：语义门户发现（WP2，小样本探针）报告

日期：2026-10-14 ｜ 性质：真实计算（两轮远程探针 + 对照 C0 v7 门坐标）｜ 结论：**辅助可行、替代为时尚早**

## 0. 结论速览

1. **开放词表"门"检测在本场面部分可行、且对提示词/阈值高度敏感**：
   - 第一轮（prompt=`door. doorway. opening. entrance.`，thr=0.25）：**3/6 机位零检出**（305/318/320）；
   - 第二轮（305/318/320，prompt=`door. glass door. sliding door. door frame.`，thr=0.18）：**全部检出**（305 7 门 / 318 8 门 / 320 5 门）。
2. **语义门 vs C0 v7 动态门：部分对齐、互有出入**（v7 由轨迹动力学得到，非 GT）：

| 机位 | 唯一语义门 | 命中 v7 门 | v7 门被语义覆盖 |
|---|---|---|---|
| 316 | 6 | 5/6 | 2/5 |
| 323 | 7 | 4/7 | 2/5 |
| 343 | 9 | 1/9 | 1/1 |
| 305 | 7（二轮） | 3/7 | 1/5 |
| 318 | 8（二轮） | 2/8 | 1/2 |
| 320 | 5（二轮） | 4/5 | 1/2 |

3. **过检机制已定位（目视实锤）**：GDINO 把**整面玻璃隔断/门框**都检为 doorway——316 标注图上玻璃墙成排命中（0.26–0.32 分）→ 解释了 343（9 门）、316 的高计数。玻璃密集场景是本项目已知难点（S6 墙镜），语义检门同样受其影响。
4. **判定**：作为**门区辅助维护证据（G2 级）可用**；替代动态门（G3 融合/G4 融合+几何）**为时尚早**——需要：多提示词×多帧聚合 + **轨迹穿越验证**（动态侧提供交叉约束）。

## 1. 方法与产物

- 探针：复用 GroundingDINO（与检测同模型目录），两轮 × 六路 × 8 帧（覆盖 10min）；
- 对照：门框底边中点/中心 → 0.05 网格跨帧聚类 → 与 v7 门中心距离 ≤0.12 判匹配；
- 产物：`analysis/top2/door_probe.json`（一轮）、`door_probe_pass2.json`（二轮）+ 两份 `*_compare.json`；标注样例 `det_exp/top2_doors_316.jpg`（目视用）；
- 脚本：`tools/top2_door_probe.py`（远程）、`top2_door_compare.py`（本地）。

## 2. G1–G4 下一步设计（对齐总方案）

- **G1 纯轨迹**：现状（v7 门 + 覆盖 0.626/0.624）＝基线；
- **G2 纯语义**：多提示词（door/玻璃门/开口/楼梯口）× 多帧（≥30 帧/机位）聚合 + 过检抑制（玻璃纹理筛除）→ 产出语义门清单；
- **G3 融合**：语义门 × 轨迹穿越（出/入画点落在语义门区域内 → 确认；无语义门的轨迹门 → 候选漏检）；
- **G4 融合+几何**：318×320 局部几何（已有映射 M）交叉校验；
- 验收沿用计划：与 v7 分母对照（召回/精确）+ 融合增量（新增有效门户数对 196 边解释率）。

## 3. 局限

- 8 帧/机位为探针规模（非全量统计）；阈值/提示词经两轮调整（非预注册），仅作可行性判断；
- 对照的"命中率"双向含义不同（语义→v7 含真门+误检；v7→语义含真门+漏检）；未做人工逐门核验。
