# 意图预测器的摄像头分组与聚类结合：实验评估报告

> 研究日期：2026-10-14 ｜ 数据：1012 意图数据集（9063 样本：train 6690 / val 1079 / test 1294）
> 脚本：`tools/intent_model_cc.py`（训练/评估）、`tools/intent_cluster_link.py`（聚类关联）、`tools/intent_cc_summarize.py`（汇总）
> 产物：`output_crosscam/analysis/intent/cc/`（22 个模型 metrics_full.json + summary.json + 图）｜ 远程：`~/human-count/intent_cc/`
> 纪律：区分【实测】（可复现运行结果）、【文献】（注明阅读深度）、【推断】。

---

## 0. 结论（先行）

**1）按摄像头分组训练意图预测器：无系统增益，不推荐。**
- 对角线口径（各模型在自家摄像头 test 子集的 acc）：305 组 **-0.12**、320 组 **-0.32～-0.49**（灾难性）明显劣于全局；318 组 **+0.03**、323 组 **+0.04** 小幅稳定胜出（三 seed 逐一验证）。
- **收益出现在"数据量适中（94-146 轨）+ 类别均衡"的摄像头；一旦样本再少（320 组 182 样本/20 轨），分组直接从劣化走向崩溃**（160 epochs "训练充分版"反而更差：0.130，过拟合确认）。

**2）与向量聚类结合（身份簇 token 条件化）：无稳定增益，不推荐。**
- 5 个配置（全局+4 组）proto token 配对：1 胜 3 负 1 微胜（305 +0.076 / 318 -0.010 / 320 +0.016 / 323 -0.029 / 全局 **-0.025**）；且 305 的正向增在 seed 重复下波动极大（σ=0.028）。
- 分层诊断：known 身份样本确实比 unknown 更准（+0.06~0.24，各模型一致），但**身份 token 并没有让 known 子集变得更准**——聚类信息在此任务中是"诊断信号"而非"提升杠杆"。

**3）对本项目的增益判定：两个方向均**不构成**对现有全局意图预测器的替换理由。**
- 现有全局模型（acc≈0.676±0.013）仍是唯一稳健选择；
- 实验的真正价值：①划清了"分组收益"的边界条件（与选择器实验一起形成项目级结论——**硬隔离无益，局部校准有益**）；②筛出了两个更有希望的方向（社交邻域上下文 / 行为聚类条件化，均有文献支撑，见 §4）。

## 1. 数据与实验设计

**数据**（1012 意图数据集，meta 列 = [seg, cam, tid, frame]；本次新增聚类关联）：

| 摄像头 | train 样本/轨 | test 样本 | 类别分布（train） |
|---|---|---|---|
| 305（办公区1） | 1830 / 153 | 221 | stop 50%，forward 22%（静坐为主） |
| 318（办公区2） | 1223 / 94 | 336 | forward 46%（通行流线） |
| 320（球机） | **182 / 20** | 92 | forward 40%，量小 |
| 323（茶水间） | 3455 / 146 | 645 | forward 55%（穿行） |

**聚类关联**（`intent_cluster_link.py`）：对全部 413/87/79 条轨迹用已交付选择器（125 原型，thr=0.9651）分配身份簇 id（pid）——
train known=**51.0%**、val 40.3%、test **65.6%**（unknown = sim 低于阈值；train 的 known 比例低源于选择器对"小簇/碎片轨迹"的保守性）。无缺失嵌入。

**模型矩阵（22 次训练 = 10 + 12）**：

| 族 | 配置 | 说明 |
|---|---|---|
| v1 主矩阵（10） | global × {none, proto}；cam{305,318,320,323} × {none, proto} | 默认 40 epochs / seed 42 |
| v2 补充（12） | 4 组 none 的"训练充分版"（160 epochs，320 用 batch 64）；global/cam318/cam323/cam305-proto 各 +2 seeds | 训练充分性公平机会 + 关键结论的方差验证 |

- 模型：IntentBERT + 可选身份 token（[CLS] 后插入 pid 的 embedding；-1→unknown 槽）；参数 3.2M；GPU 训练。
- 评估：test 全量 + per-camera 拆分 + known/unknown(pid) 分层；**对角线口径**（分组模型评自家子集）为主对比。

## 2. 实验结果（全部【实测】）

### 2.1 对角线主表：分组 vs 全局（自家 test 子集 acc）

| 摄像头 | 全局 | 分组(40ep) | 分组+proto | 分组(160ep) | 判定 |
|---|---|---|---|---|---|
| 305 | **0.652** | 0.525 | 0.579 | 0.529 | 全局大胜（-0.12） |
| 318 | 0.646 | 0.676 | 0.685 | **0.714** | **分组稳定小胜（+0.03~0.07）** |
| 320 | **0.620** | 0.304 | 0.228 | 0.130 | 全局碾压（分组崩溃） |
| 323 | 0.744 | **0.758** | 0.741 | 0.730 | 分组微胜（+0.01） |

（图：`cc/diag_compare.png`）

### 2.2 seed 重复（关键澄清：哪些差异是真实的）

| 对象 | 对角线三 seed | mean ± σ | 全局同子集三 seed | mean ± σ |
|---|---|---|---|---|
| 318 子集 | 0.658 / 0.676 / 0.682 | **0.672 ± 0.010** | 0.649 / 0.646 / 0.628 | 0.641 ± 0.009 |
| 323 子集 | 0.769 / 0.758 / 0.761 | **0.763 ± 0.005** | 0.684 / 0.744 / 0.741 | 0.723 ± 0.028 |

→ 318/323 的"分组小胜"**是真实的**（三 seed 全部 ≥ 全局），幅度 +0.03~0.04；
→ 全局模型本身波动 ±0.013（overall acc [0.662, 0.694, 0.672]），单次运行比较易被噪声干扰，本报告所有关键结论均以 3-seed 口径为准。

### 2.3 训练充分性对照（v2）

- 318 组：160ep（0.714）> 40ep（0.676）——**充分训练有实质收益**（318 是"数据适中+分布均衡"的最大受益者）；
- 320 组：160ep（0.130）**<<** 40ep（0.304）——样本 182、参数 3.2M，训练越久过拟合越深；**320 组的失败是数据量问题，无法通过训练配方补救**；
- 305/323 组：160ep 无增益（0.529/0.730 ≈ 40ep），说明其瓶颈也不在训练步数。

### 2.4 proto（身份 token）配对消融（seed 42）

| 对象 | none | proto | diff |
|---|---|---|---|
| 全局 | 0.6940 | 0.6692 | **-0.0247** |
| 305 | 0.3957 | 0.4714 | +0.0757* |
| 318 | 0.5386 | 0.5286 | -0.0100 |
| 320 | 0.3725 | 0.3879 | +0.0155 |
| 323 | 0.5325 | 0.5031 | -0.0294 |

\* 305_proto 三 seed（0.597/0.579/0.475）均值 0.55、波动大，且仍远低于全局 0.652——**非可用增益**。

### 2.5 known / unknown 分层诊断（"差异化表现"的检验）

| 模型 | known 子集 acc | unknown 子集 acc | 差 |
|---|---|---|---|
| 全局 none | 0.726 | 0.634 | +0.092 |
| 全局 proto | 0.714 | 0.584 | +0.130 |
| cam318 none | 0.556 | 0.506 | +0.050 |
| cam323 none | 0.614 | 0.378 | +0.236 |

两个事实：①**所有模型在 known 身份样本上更准**（聚类信息对"分层诊断"有价值——unknown 样本应被视为低置信区间）；②**proto token 未改善 known 子集**（全局 proto 的 known 0.714 < none 0.726）——身份条件化的信息没有被模型转化为预测增益。

## 3. 机制分析：为什么没有增益（与选择器实验对照）【推断】

1. **任务形态不同**：身份选择器是"边界型"任务（最近原型匹配，域偏移直接干扰判定边界）→ 分组/校准有效；意图预测是"序列运动学建模"（输入 token 已是归一化的相对量 u,v,Δu,Δv），**域偏移影响本来就小**→ 分组失去主要作用面。
2. **信息相关性**：运动意图主要由"瞬时运动状态"（当前速度/方向）决定，**身份与意图弱相关**（个体步态/习惯的贡献是二阶量）；而选择器任务中"摄像头"是最强混杂因子。
3. **数据稀释**：意图模式需要大样本覆盖（分组把 6690 切到 182~3455）。318/323（94/146 轨）恰好还在"够用"的临界之上，305（153 轨）输在**类别分布**（stop 50% 的局部先验使模型偏向静坐），320（20 轨）是纯数据灾难。
4. **文献同构**【文献】：轨迹预测领域有效的"聚类条件化"是**行为/运动模式聚类**（BP-SGCN 行为伪标签；PCCSNet/FEND 行为模态 K-means），而非身份/外观聚类；"相机条件化预测"在文献中**没有直接先例**（轨迹预测基准 ETH/UCY 均为固定镜头）。

## 4. 近邻方法调研（文献）

| 工作 | 做法 | 与本任务关系 / 借鉴点 | 阅读深度 |
|---|---|---|---|
| **Social LSTM** (CVPR 2016) | 每行人一个 LSTM，**Social pooling** 汇聚邻域行人隐状态 | "近邻"在轨迹预测中的经典形态；**我们的数据有现成共现关系（同帧多人）——社交上下文是下一步最可用的增量信号** | 正文（含公式） |
| **CoMoGCN** (Neurocomputing'23) | "**coherent motion**"：人群常以组移动；coherent filtering+DBSCAN 聚类**运动群体**，双 GCN（组内/组间） | "组"的正确聚类对象=**运动群组**而非身份；直接可迁移到我们场景（多人结伴通行） | 正文解读 |
| **BP-SGCN** (arXiv 2502.14676) | **行为伪标签**：对轨迹隐表示做深度无监督聚类（DEC），one-hot 拼入预测网络端到端微调 | **与"聚类条件化预测"最接近的先例**：证明"行为聚类→条件化"有效；且其综述指出 K-means/DBSCAN/GMM 行为模态聚类的既有实践 | 正文片段 |
| PCCSNet / FEND（经 BP-SGCN 转述） | BiLSTM+K-means 行为模态 / 长尾轨迹聚类 | 行为聚类谱系 | 转述 |
| MDA (CVPR 2012) | 混合动态行人代理无监督聚类→集体行为分类与预测 | 早期"聚类+预测"先例 | 摘要 |
| Motion Patterns (2013) | 出入口点 CURE 聚类→轨迹分组→统计运动模式 | "按结构分组"变体 | 摘要 |
| 跨机跟踪融合 (MDPI 2023) | TransReID 外观 + 隐社交模型轨迹预测，融合特征多轮聚类做**跨机关联** | 预测与识别的**融合使用**（识别侧）；反向（识别→预测）关系 | 摘要 |
| CTF-reID (2015) / 轨迹预测辅助 reID (2022) | 用轨迹预测**提升 re-ID**（预测→识别方向） | 说明"预测↔识别"文献多为预测辅助识别，**识别条件化预测并非主流**——与我们负结果互证 | 摘要 |

**调研结论**：轨迹预测中"条件化"的主流对象是 **行为/运动模式**（聚类对象是轨迹的运动特征）与**社交邻域**（对象是周围行人），而**不是身份外观**、更不是"按摄像头隔离模型"（无先例）。我们建议的下一步方向与文献主路径一致。

## 5. 结论与建议

### 对用户三个设想的逐项判定

| 设想 | 判定 | 依据 |
|---|---|---|
| ①按摄像头分组训练多个预测器 | **不成立**（3 胜 1 负且幅度不对称） | 对角线 + 3-seed：318/323 微胜（+0.03/+0.04），305/320 大败；小样本摄像头直接崩溃 |
| ②与向量聚类结合（身份条件化） | **不成立**（无稳定增益） | proto 配对 1 胜 3 负 1 微胜；known 子集未受益 |
| ③"面向不同聚类情况差异化表现" | **部分成立（作为诊断层）** | known/unknown 分层一致显著（unknown 应标注为低置信）——可用作运行时的置信度分层，而非模型增益 |

### 建议（按优先级）

1. **保持全局意图预测器为唯一主模型**（acc 0.676±0.013）；
2. 【中期】**社交邻域上下文**（Social LSTM 式）：同帧其他人的运动 token 作为额外输入——数据现成（`1012_final/*.jsonl` 的共现关系），实现路径与现有 BERT 架构兼容（邻域 token 拼接），是低成本、有文献支撑的增量方向；
3. 【中期】**行为聚类条件化**（BP-SGCN 式）：把"proto token 机制"从"身份聚类"换成"运动模式聚类"（对轨迹速度/转角序列嵌入做 K-means/GMM）——机制同构、只需替换聚类对象与 token 表，直接复用现有代码；
4. 【如坚持分组】准入条件：每摄像头 ≥ 数百样本、类别均衡、独立调参（本次仅 318/323 达标）；并接受"4 套模型 4 份维护"的成本。
5. 与选择器实验合并的项目级结论：**"硬隔离（分组）无系统收益；局部（摄像头级）校准/条件化是正确的使用方式"**——选择器侧已验证"全局聚类+按机校准"零损失回收收益；意图侧不存在同等收益面（域偏移影响小），保持全局即可。

### 局限

- 320 test 仅 92 样本（8 轨），其结论受小样本限制（但"训练数据不足"的诊断本身是确定的）；
- proto 的 known 分布在 train（51%）与 test（65.6%）间有偏移（选择器 in-sample 效应），未做 pid-dropout 增广（实验设计选择，如实报告）；
- seed 重复覆盖 4 个关键配置（其余为单次运行，报告已区分口径）；
- 文献：Social LSTM/BP-SGCN/CoMoGCN 读到正文（含方法细节），MDA/CTF 等为摘要级；未做多数据集交叉验证（long35 数据集可作后续复核）。
