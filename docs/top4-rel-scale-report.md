# TOP-4：简易空间模型 Step-1（相对尺度，人体身高路线）报告

日期：2026-10-14 ｜ 性质：真实计算（**含一处口径修正与一个有边界的结论**）｜ 工具：`tools/top4_rel_scale.py`
产物：`output_crosscam/analysis/top4/rel_scale.json`

## 0. 结论速览

1. **单标量"相对尺度"只在重叠对（318×320）可测量**：同人**同时刻**高度比 = **h320/h318 ≈ 1.13**（8 对，每对中位 1.00–1.42，跨对 IQR 0.227）。
2. **但位置依赖性明显**：同一人移动过程中，瞬时比值 IQR 中位 0.45（约 ±22%）→ 单标量只能做**±30–40% 的粗尺度门**，不能当距离先验。
3. **非重叠机位不可测**（无共视人）：六路"典型人体框高"表给出的是**各机位自身尺度描述**（318 中位 67px / 316 256px / 343 491px…），**不能**用于跨机位距离换算。
4. **判定（诚实）**：Step-1"身高→相对尺度→距离先验"的低成本路线在本项目**收益有限**——重叠对已有更强工具（时空映射 M，AUC 0.994）；非重叠对无法自标定。建议：Step-2（局部几何升级）作为主攻方向；Step-3（地面平面/BEV）维持"条件路线"。

## 1. 口径修正记录（重要）

- 初版用"整轨高度中位数之比"：8 对 med=2.046、IQR=**1.319**（看似不可用）；
- 修正为**同时刻逐帧比**（T0 对齐，±0.5s 匹配）：med=**1.127**、IQR=0.227（可用作粗门）；
- 差异来源：整轨中位数混合了不同位置/时段，口径错误；已在工具中固化正确口径（同时刻比）。

## 3. 与 Step-2/3 的衔接

- Step-2（局部几何升级）：现有映射 M（多项式，LOO 防自证）已是 318×320 的原型；可试 pose-guided 类免标定以重投影误差/AUC 0.994 为对照线；
- Step-3（地面平面→2.5D/BEV）：**仅在有真实需求时启动**（当前拓扑链路不依赖它）；
- 纪律符合：本轮**没有为"完整三维"拼图**，只确证了"哪些可测/不可测"。

## 4. 局限

- 8 对为既有 match30 正对（来自判读集），样本小；同人无同步重叠时刻的对无法算；
- 高度用检测框高（含姿态/遮挡噪声），未做脚-头顶校正；
- 非重叠对的"不可测"是数据条件结论（无共视人），非否定身高路线本身。
