## 3. 算法：把「逐轨规则」升级为「全局指派」

```
① 候选：同机位共现 ≥4 帧的轨迹对（倒影只有与真人同时可见时才存在）
② 镜像几何（复用 mirror_kinematics.pair_metrics，物理关系：地板平面镜像）
     倒影中心 ≈ 源脚点关于触地线的镜像： v_R_center ≈ 2·v_S_bot − v_S_center
     判据： |Δu| < 0.06  ∧  pred_err ≤ 0.10  ∧  0.35 ≤ offset_ratio ≤ 0.60
③ 新增两道门（本轮）
     尺度门： 0.60 ≤ hr(倒影高/源高) ≤ 1.10      ← 地板倒影是镜像，尺度应≈1
     静止对： max(v_s, v_r) ≥ v_min（默认禁用，见 §6）
④ ★ 全局指派（真人 ← 倒影），三轮约束：
     · 唯一性：一个观测至多 1 个源
     · 时间不重叠：同一源在同一时刻至多解释 1 个倒影段
     · ★ 切断倒影链：已被判为倒影的观测**永不作源**
     · ★ 分两轮：第 1 轮只用「自身不被任何观测解释」的节点作源（物理上必为真人），第 2 轮放开
⑤ 保守兜底：没有任何源能解释的观测一律判为**真人**
```

**为什么"分两轮"是必需的（实测反例）**：若纯按 `pred_err` 升序贪心，`323#212→194`（perr 0.021）会压过 `194→193`（perr 0.048），把**真正的倒影 194 误判成真人**（源被"污染"）。分两轮后，193（无任何"作为倒影"的边 → 必为真人）先当源，194 被正确判定，`212→194` 因"194 已是倒影"被切断 —— **切链机制真正生效（`323` 切链 1 例）**。

## 5. 倒影链歧义（唯一需要人工终审的结构）

`323#193 / #194 / #212` 构成一条**垂直堆叠链**（逐帧证据）：

```
f=12525 (500s)： 193 y[197,372]  ← 真人（最上）
                 194 y[371,536]  ← 193 正下方 = 193 的倒影   （193 的可见段 500.0–521.8s）
f=13125 (525s)： 194 y[157,307]  ← 「后期 194」
                 212 y[310,447]  ← 194 正下方 = 194 的倒影   （212 的可见段 525.0–527.2s）
```
- 关键事实：**193 与 212 时间不重叠**（193 在 500–521.8s 已消失，212 在 525–527.2s）→ 不存在"倒影的倒影"；最可能是 ByteTrack 把**倒影 + 后续真人**串成了一条 194。
- 而 `323#193→167` 这条"源边"被**尺度门 hr=2.08 自动排除**，其理由与 v2 审计**逐字吻合**：
  > "#193 为完整真人行走轨迹（**其自身倒影另有 #194/#207/#208 等轨**）" —— `audit_full_2026-10-13.json`
- **算法选择**：切断链 → 194 判倒影、212 判真人（**保守方向：宁可漏标，不把真人降权**）。该结构已写入产物的 `ambiguity` 清单（316 有 10 组、323 有 15 组"同一观测多个候选源"）。

## 6. 与掩膜的关系（为什么不是"替换"，而是"互补"）

| | 掩膜（glass_mask） | S5 几何指派 |
|---|---|---|
| 针对伪影 | **墙玻璃镜像**（竖直面镜像，u 轴反相）+ 玻璃遮挡 | **地板倒影**（水平面镜像，v 轴镜像） |
| 命中（316/323） | 62 / 72 条 | 18 / 28 条 |
| **交集** | **0** | **0** |
| 误删真人 | 有（v2 审计 `restored_fp` 恢复 7 条） | 已标注真人 **0 条** |
| 副作用 | 逐帧删框 → **打断轨迹**（历史实测缺嵌入 1181 条） | **不删框**，只打 flag → 轨迹完整 |

**结论**：两者几何机制不同、**完全互补**。用户否掉掩膜后，**地板倒影**这一半已由 S5 用"关系型指派"无掩膜解决；**墙玻璃镜像/玻璃遮挡**这一半仍需另找判据（EBLNet 类语义分割，或设计文档 §2.4 的"上下文型"融合判据）。
