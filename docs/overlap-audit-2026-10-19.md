## 3. 目检：残留重叠是两类，不能用同一个阈值处理

抽 6 例（305/318/323 各 2，IoU 0.29–0.47）逐帧看：

| 帧 | 情形 | 判定 |
|---|---|---|
| 305 f=1225 | 绿=头/上身，红=同一人+椅背 | **同一人重复** |
| 305 f=0 | 红=后景坐者全身，绿=**前景另一个人的头** | **两个真人** |
| 318 f=11365 | 红=全身，绿=同一人的头（隔板后） | **同一人重复** |
| 318 f=1325 | 绿=显示器后的人，红=拿手机的人 | 存疑 |
| 323 f=4510 | 红=红衣人，绿=另一名深色衣服的人 | **两个真人** |
| 323 f=4225 | 红=全身，绿=同一人头/上身 | **同一人重复** |

→ **把去重阈值从 0.5 降到 0.3 会把第 2、5 例这种两个真人并掉**，正是我们花了一天在消除的误合并。
所以阈值不能再降。

## 4. 可用判据：掩膜包含率（分割模型本来就给了掩膜，此前没用）

前景人的掩膜不含后景人的像素，掩膜互斥。

## 6. 风险与未做

- **样本仍小**：30 帧 / 40 个删除框，只覆盖 305_test 开场 2.5 分钟；318/323 上未逐例目检。
- **未做全量**：没有重跑 8 段、没有重编码、没有重评估。当前生产配置与指标**未变**。
- 掩膜判据只能删「小框几乎完全落在另一框掩膜内」这一类；「两框掩膜部分重叠」（如 ID 切换）删不掉。
- 删除头像框会改变 OSNet 的输入裁剪（全身代替头部），embedding 会变——这既可能是收益（头像裁图信息少），
  也可能是风险（同一人的向量分布移动），只能靠实测判断。

## 10. 重复框的成因核查：是不是人脸模型重复标框？

用户提问后逐项核查，结论：**不是。检测链路里没有任何人脸模型，重复框是同一个 person 模型给的两次假设。**

### 10.1 链路里没有人脸模型（代码级）

| 检查 | 结果 |
|---|---|
| `yolo_track_det.py` / `make_ab_jsonl.py` / `encode_1012_osnet_seq.py` / `session_selector_v1.py` / `eval_det_switch.py` 中 `face|scrfd|gil_` 命中数 | **全部 0** |
| 检测输出字段 | `frame` / `track_ids` / `boxes` / `scores` 四个字段，没有类别、没有来源、没有第二套框 |
| 检测调用 | 单次 `model.track(..., classes=[0])`，class 0 = person，没有第二个模型参与 |
| 身份编码 | OSNet（`osnet_x1_0_msmt17...`）对**框裁剪**提特征，不涉及人脸 |
| 仓库里的 `gil_face_*` 与人脸探针 | 独立的 gil 分析线（`models/face/scrfd_2.5g_bnkps.onnx`），不被 1012 主链路任何脚本引用 |

### 10.2 重复框的几何：是「头+肩」，不是「脸」

对 305 的持续嵌套框对（4000 帧次样本）实测：

| 量 | 305_test | 305_train | 人脸框应有的值 |
|---|---|---|---|
| 小框高 / 大框高 | **0.47**（p10–p90 0.27–0.51） | **0.41** | 0.12–0.15 |
| 小框宽高比 w/h | **1.45** | **1.55** | 0.7–0.9 |
| 小框中心纵向位置（0=大框顶） | 0.25 | 0.21 | 贴近顶部 |
| 高占比 <0.2（脸大小）的框对 | 0.9% | 0.0% | — |

小框是**宽大于高**的头肩区域（w/h≈1.5），高度接近大框的一半；人脸框则是**高大于宽**、只占身高 13% 左右。
量级差 3–4 倍，可以排除「人脸框」这个解释。

### 10.3 掩膜证据：同一人的两条假设

305_test f=25，红=小框（1566,331,1676,435），绿=大框：

- 红框掩膜 = **她的头和肩**（图中棕色），绿框掩膜 = **她 + 椅子 + 搭在椅背的外套**
- 掩膜包含率 **0.99**、掩膜 IoU **0.84** → 同一人的两个实例假设，只是范围不同
- 这正是掩膜规则要删的那一类：删掉头肩框，保留范围更大的那个

### 10.4 反例：框重叠不等于重复

同一段 f=695，红框（1013,465,1153,549，头肩大小）落在绿框（1027,349,1228,551，站立者全身）内部，
但两者掩膜**交集只有 4 像素、包含率 0.00**——红框是前景坐着的人，绿框是后面站着的人，两个真人。
这类重叠占残留重叠的 70%，正是不能把框 IoU 阈值降到 0.3 的原因。

### 10.5 成因结论

- **直接成因**：同一个 YOLO26s-seg 对「坐在桌前、被显示器/椅背截断的人」输出了两个尺度不同的 person 假设
  （一个框到头肩，一个框到椅子），两者框 IoU 只有 0.2–0.5，NMS（0.5）压不掉。
- **机制推断（未验证）**：训练标签里被遮挡的人存在两种标注口径（只标可见部分 / 标到推断的全身），
  模型把两种都学了下来。要证实需要查训练集的标注分布，本仓库没有该数据集。
- **可操作的判据**：只有掩膜包含率能区分这两类（§4），框几何和置信度都分不开（小框置信度 0.34–0.44，大框 0.43–0.44，基本重合）。
