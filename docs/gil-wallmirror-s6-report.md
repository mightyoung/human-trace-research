## 2. 几何模型：两类伪影，两套镜像

| | 地板倒影（S5） | **墙玻璃镜像（S6）** |
|---|---|---|
| 镜面 | 水平面（地板） | **竖直面（玻璃墙）** |
| 图像表现 | v 轴镜像：`v_R ≈ 2·v_S_bot − v_S_center`，`|Δu|≈0` | **u 轴反相**：`u_R ≈ 2·u_axis − u_S`，`v_R ≈ v_S` |
| 逐帧锁步 | `corr(Δv_R,Δv_S) ≈ +1` | `corr(Δu_R,Δu_S) ≈ −1`，`corr(Δv_R,Δv_S) ≈ +1` |
| 尺度 | `hr ≈ 1` | `hr ≈ 1` |
| 掩膜能否拦 | **不能**（落脚点不在地板玻璃区） | 能，但**逐帧删框**且**位置依赖手工标定** |
| 本报告 | 已由 S5 解决 | **本节解决** |

★ 关键副产品：**镜面位置 `u_axis` 是未知参数，但可自监督估计** —— 因为镜像对的 `(u_R+u_S)/2` 恒等于镜面位置。多条对的估计一旦聚集，就"发现"了一堵玻璃墙。

## 3. 自监督镜面发现（含目视确认）

| 机位 | 自监督 `u_axis` | 时间稳定性 `std(u_axis)` | 判定镜像 | 目视确认 |
|---|---|---|---|---|
| **316** | **0.608** | ±0.0005 – 0.011 | 11 条 | 黄线精确落在**左侧白墙与右侧黑色玻璃幕墙的分界线**上 ✅ |
| **323** | **0.457** | ±0.0003 – 0.0022 | 13 条 | 黄线落在**玻璃门/隔断**处，左右两侧红/蓝框**姿态严格镜像**（同步弯腰、方向相反）✅ |

**★ `u_axis` 的时间稳定性是排除假阳性的决定性判据**：若两条轨迹是"两个真人反向行走"（v2 审计记载的假阳性机制），其中点必然漂移；而实测 `std` 低到 10⁻³ 量级 → **必然是固定镜面**。

证据图：`analysis/gil/wallmirror_evidence_{316,323}.png`（红=候选倒影、蓝=源、黄=自监督镜面）。

## 4. 与掩膜的正面对比（回答 §3.5 的验收问题）

### 4.1 316：掩膜**位置对**，但**剔得过多**

| 项 | 数值 |
|---|---|
| 自监督镜面 / 掩膜区 | 0.608 / 掩膜区 u ≥ 0.62 —— **一致** ✅ |
| 掩膜剔除 | 62 条 |
| 几何确认为真镜像 | **11 条（18%）**，且**全部是 `masked ← keep`**（镜像 vs 真人，完全符合物理） |
| 几何无法解释 | **51 条** |
| ★ 关键差异 | masked 轨迹**帧数中位仅 5**（28/62 条 <5 帧、48/62 <10 帧）；而 keep 中位 **17 帧**（p90=59） |

**解读**：掩膜**逐帧删框**，把一个真人穿过玻璃区的轨迹切成若干 1–4 帧的碎片；这些碎片被 ByteTrack 单独立轨，就形成了 51 条"无法解释"的短命轨迹。**这正是"掩膜打断轨迹"（历史实测缺嵌入 1181 条）的机制**。

### 4.2 323：掩膜**位置错**

| 项 | 数值 |
|---|---|
| 自监督镜面 | **0.457** |
| 掩膜区 | **u ∈ [0.54, 0.63]** |
| 重叠 | **无** |
| 掩膜剔除 | 72 条 → 几何确认真镜像 **0 条** |
| 几何发现但掩膜漏网 | **13 条**（其中 11 条在 clean2 中存活） |

**解读**：323 手工掩膜覆盖的是另一处区域（u 0.54–0.63），而**真正的玻璃镜面在 u=0.457**。因此**323 的墙镜倒影从未被处理过**，一直以 `track_status='keep'`（"真人"）的身份留在下游。

### 4.3 汇总（§3.5 的两项验收指标）

| 指标 | 掩膜 | S6 几何 |
|---|---|---|
| 剔除/标记数（316+323） | 134 | 24 |
| 其中经确认的真倒影 | 11（precision **0.08**） | 24（**目视确认**） |
| 疑似误伤/碎片 | **123** | 0（打 flag 不删框） |
| 位置依赖 | 手工标定（323 错位） | **自监督** |

**结论**：几何判据**可以在"误删率不升"的前提下替代掩膜**，而且能发现掩膜**漏掉**的真倒影 —— 满足 §3.5 的验收目标。

## 6. 边界与负结果（如实）

- **`hr` 上下界是必要的**：不加尺度门时，`323#115→111`(hr=2.40)、`305#12→22`(hr=2.61) 这类"倒影比源大 1.4–1.6 倍"的伪对会混入。hr∈[0.70,1.45] 是本次的工作点。
- **`dv_corr ≥ 0.3` 与 `|Δv| ≤ 0.15` 不可省**：只靠 `du_corr ≤ −0.5` 时粗筛出 31 条（316），其中含"两人同高度反向行走"的假阳性；加上 v 同相约束后收敛到 16 条，再经 `u_axis` 主聚类得到 11 条。
- **316 的 11 条全部已被掩膜剔除**（不在 clean2），故 316 的污染为 0 —— **不是因为没有倒影，而是因为它们已经被（粗暴地）删掉了**。
- **未做**：`clean3` 未真正生成（改视图会破坏 `splits_v5` 冻结的 md5 与 relay/C0 口径）；本报告的替代做法是**只写 `annotation`（视图无关）+ `obs.flags`**，把判定变成可复用的真相层。
- **未做**：段级切分 —— `194` 这类"倒影 + 后续真人"拼接轨迹仍只打整条 flag。
