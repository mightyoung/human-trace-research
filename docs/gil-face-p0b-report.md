## 1. A. 关联 v2.1（修复「脸伸出人体框」）

**问题**（P0 遗留）：305/318 等俯视机位，GroundingDINO 人体框常不含头部 → 脸中心落框外 → 不可关联。

**v2.1 规则**（`tools/gil_face_capture.py::associate_track`，经验初值）：
1. `in_exact`：中心落原框内 → 最小面积（v1 旧规则，不回退）；
2. `in_head`：落头部扩展框（侧 12% / 上 35% / 下 8%）+ **不跨框顶**（脸底边须低于框顶 ≥1.0×脸高）→ 取头锚点距离最近；
3. `nearest`：兜底——x 落框横向范围（±12%）+ 不跨框顶 + 归一距离 ≤0.50 + 歧义守卫（次近 ≥1.35×最近）。

**审计驱动的两轮修正**（`tools/gil_face_reassoc.py` 离线重跑，不重检测）：
- 首版（无守卫）新增 1125 处关联；抽样目检发现**两类误配**：316 前景无框行人的脸被 nearest 分给后景轨迹（6 例，q≈0.93 大脸）、343 后景人脸被 in_head 分给前景框（1 例）→ 加 x 范围与「不跨框顶」两道守卫；
- 守卫剔除 12 条可疑增益（含全部已确认 FP），**保留 149 条可用增益**（305×146 + 320×3）。

**结果（可用脸关联）**：

|---|---|---|---|
| 305 | 257/405 (63.5%) | **403/405 (99.5%)** | 俯视坐姿，脸在框边缘/头部区 |
| 316 | 192/243 | 192/243 | v2 增益均为 FP，守卫后归零（覆盖不变） |
| 318 | 69/71 | 69/71 | — |

**污染修复**：3 个 tid 的 crop 被 FP 污染（316|28 / 316|63 / 343|28）→ 重关联后自动刷新为本人脸；1 个孤儿 crop 与 2 个孤儿 ent/gp 副本已清理。产物：`face_shot_p0b.json` / `face_best_p0b.json` / `face_reassoc_audit_p0b.json` + `debug_assoc/` 目检图。

## 2. B. 多帧合成清晰化（新工具 `tools/gil_face_fusion.py`）

**管线**：同 tid 可用脸按 q 排序 → **时间窗 ±1s**（防跨时姿态漂移）→ 5 关键点对齐（规范模板 256×256）→ **ECC 亚像素精对齐**（cc<0.85 拒帧）→ NCC≥0.80 拒外 → **清晰度 × 结构一致度掩膜加权融合** → 复过质量门（fused_lap ≥ 0.55×single_lap）→ 轻量 unsharp。

**★ 技术演进（含两条重要教训）**：
1. **简单加权平均**：fused lap 仅为 single 的 0.22~0.44 → 过糊（平均=低通）；
2. **锐度加权（无掩膜）**：出现 lap 比 **3~4× 的「假提升」**——逐帧栈诊断（f10510→f10490 蒙太奇）证实是**转头瞬间的结构位移被"锐帧选择"拼成嵌合体**（d 实例：316-88）；
3. **定稿：结构一致度掩膜**——与参考帧结构不一致处（|diff| 超过 AGREE_T 尺度）权重→0，输出跟随参考帧 → 比值回落至 **0.65~1.24 的忠实区间**，嵌合体消除。

**结果**：71 tid → **24 接受**（305×6 / 316×11 / 318×1 / 320×1 / 323×2 / 343×3）；跳过 47（16 时间隔离 / 16 对齐失败 / 15 一致性拒外——均为诚实负结果）；**19 个 gperson 升级为融合图**；抽样目检 10/24 **零伪影**。产物：`fused/` + `ab_fused/`（24 张 A/B 拼图）+ `face_fusion_p0b.json`。

**定位说明**：本项目数据下多帧合成的真实收益 = **降噪与细节稳定的忠实版本**，不是超分式夸大；大脸机位（316/343）本来清晰、收益温和；与「生成式修复」的区别是零幻觉风险（未用任何生成模型）。

## 3. C. 人脸嵌入 × gperson 聚类可行性（新工具 `tools/gil_face_embed.py`）

**模型**：`models/face/w600k_mbf.onnx`（13.6MB，InsightFace buffalo_sc 识别模块，112×112，ONNX CPU）。

**结果**：71 tid 嵌入（每 tid top-3 帧平均）→ 同 gperson 对 26 对（余弦 mean 0.40 / max 0.71）vs 跨 gperson 对 2459（mean 0.28 / p95 0.50 / max 0.88）。

**候选合并清单（top，已按当前 gperson 空间重链接）**：

| A | B | cos | gperson |
|---|---|---|---|
| 305\|29 | 305\|42 | **0.88** | g0006 ↔ g0020 |
| 305\|2 | 320\|1 | **0.82** | g0014 ↔ g0016（跨机位） |
| 305\|84 | 305\|94 | **0.81** | g0009 ↔ g0047 |
| 305\|12 | 305\|94 | 0.81 | g0019 ↔ g0047 |
| 305\|12 | 305\|84 | 0.79 | g0019 ↔ g0009 |
| 320\|25 | 320\|26 | 0.79 | g0187 ↔ g0188 |
| 323\|149 | 323\|151 | 0.76 | g0214* ↔ g0167* |

（*旧空间标签，重链接后以 `face_embed_p0c.json` 为准；完整 28 条见产物）

**目检结论**：305 的 0.8+ 对（29↔42、84↔94↔12 三连）视觉高度一致 → 强合并候选；**警示**：低 cos 的"同 gperson 拆并信号"受**口罩/低清**混淆（316\|62↔323\|122 双方戴口罩，cos 0.09 不能直接判异人）。**结论：相对排序可用、绝对阈值不可用；候选须人工审计，未做任何 GIL 变更**。

**★ 附带发现**：越界样本（316|62↔323|122 = 旧 g0109 桥接、323|151↔323|154 = 旧 g0167 桥接）恰是 S6-b 待裁决项——人脸证据与倒影桥接怀疑**方向一致**；且新 GIL 重建已把 101 张倒影脸移出人层（见 §5）。
