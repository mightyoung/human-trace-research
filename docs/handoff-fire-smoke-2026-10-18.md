## 2. 任务与场景

### 2.1 原始需求（用户原话，勿改写）

> 使用场景为两种：1. 园区内全部摄像头轮询跑火焰烟雾算法，发现即报警；2. 在机器狗上搭载火焰烟雾算法，发现即报警。

补充口径（用户后续明确）：**更多关注技术路径、准确性和困难点**，部署与商务不是重点。

### 2.2 两个场景的边界

| 项 | 场景 A：园区轮询 | 场景 B：机器狗 |
|---|---|---|
| 载体 | 存量安防摄像头（枪机/球机/半球） | 四足机器人 |
| 规模 | **未知**，文档按 200 路示例（25–500 可算） | 1–2 台 |
| 接入 | 假设 ONVIF/ISAPI 抓图，RTSP 兜底 | 机载相机 |
| 运行 | 7×24 | 每班约 4 h |
| 报警要求 | "发现即报警" | "发现即报警" |
| 现有资产 | 无（无模型、无数据、无平台） | 无 |

### 2.3 两个尚未决定的产品决策（会改变全部指标）

1. **定位**：辅助预警（不接消防联动、只推值班）还是法定探测（接联动、需 CCC/FM 认证）？本文档全部按"辅助预警"设计；若走认证，技术路线要加多光谱/IR，指标改按型式试验。
2. **"发现即报警"的落点**：`candidate`（单帧，≤1 s，但 200 路约 345 条/天）还是 `confirmed`（3–8 s，约 11.5 条/天）？文档推荐后者，但**用户尚未拍板**。这是下一任首先要确认的事。

### 2.4 不在范围

认证产品开发、消防联动设计、摄像头/机器人采购、施工与运维排班、商务报价。

## 4. 结论基线（有证据，别从头重做）

### 4.1 技术路径

- 已收敛为三段式：**单帧检测 → 时序证据 → 决策**。单帧检测在 D-Fire 上 mAP50 约 79%，YOLOv4→v8 只涨 2.4 点，**换骨干已进入平台期**。
- 时序的价值不在涨点（SmokeyNet 1 帧→3 帧仅 +1.1 点），而在**改变误报结构**。
- 采样率决定可用线索：火焰闪烁 5–15 Hz 需 ≥15–30 fps；**园区 0.2 fps 轮询等于放弃闪烁**，退化为"外观 + 面积增长"；机器狗 15 fps 保住闪烁，但运动模糊抵消一部分。

### 4.2 准确性（最硬的六组数字）

| 结论 | 数值 | 来源 |
|---|---|---|
| D-Fire 官方测试集近重复 | **46.0%** | Drones 2026, 10(8):635 |
| FASDD_UAV 测试集近重复 | **90.7%** | 同上 |
| 剔除后 mAP50 下降 | **−2.8 / −12.4** | 同上 |
| 冻结权重跨语料，比本地训练低 | **38 / 65 点** | 同上 |
| 修正污染后仍低 | **26 / 62 点** | 同上 |
| 跨语料退化：火焰 vs 烟雾 | 火焰约 **2×** | 同上 |
| 分割无负样本时 FPR | **30.31%–77.45%** | WACV 2026 |
| VLM 零样本 FIgLib（7B 微调） | P 98.6 / R 57.2 / F1 72.4 | Drones 2025, 9(5):347 |
| VLM 单张延迟 | 1.1–2.0 s（4090）/ **23 s（Orin NX）** | 同上 |
| 人类基线（FIgLib） | Acc 78.5 / R 74.4 / F1 82.8 | Remote Sensing 2022 |

### 4.3 困难点（按"卡脖子"排序）

1. **烟雾无形状**：边界是密度梯度；mAP50 78.5 vs mAP50-95 46.6 的 30 点差距是任务性质，不是模型缺陷。
2. **负样本缺失 → 到处是烟**：只喂正样本，FPR 30–77%，IoU 仍"正常"。
3. **小目标光学硬下限**：1920 px / 60° 视场，5 km 外 10 m 烟羽仅 3.7 px；换网络救不回来。
4. **域偏移**：室内↔室外 DANN 89.44 / 79.10；火焰类 F1 78.04；烟雾分割跨域 mIoU −20。
5. **VLM 高精确低召回**：只能复核，不能检测。

### 4.4 有效手段排序（证据强度）

硬负样本 > 时序持续性 + 面积增长 > 几何掩膜 > 多机共识 > 高分辨率/切片 > 不确定性拒识 > 教师-学生蒸馏 > 换更大骨干。

### 4.5 已排除的做法（不要重做）

| 做法 | 为什么排除 | 证据 |
|---|---|---|
| 单帧即响铃 | 200 路、p=1e-4 时 345.6 条/天，值班 17 h/天 | 计算器 + 算术 |
| 用公开 mAP 直接选型 | 污染 + 跨域，不可横比 | Drones 2026 |
| VLM 进实时回路 | 1.1–23 s/张，召回 19.5–57.2% | Drones 2025 |
| 只收正样本训分割 | FPR 30–77% | WACV 2026 |
| 假设"火焰比烟雾好做" | 跨域退化火焰约为烟雾 2× | Drones 2026 |
| 把 FASDD 92.71% 当难度基准 | 90.7% 近重复，修正后 −12.4 | 同上 |

## 6. 关键假设与参数（下一任必须替换成实测）

| 参数 | 当前取值 | 含义 | 替换方式 |
|---|---|---|---|
| 园区路数 | 200（示例） | 容量与误报的分母 | 用户确认 |
| 抽帧间隔 | 5 s | 聚合帧率 = N/5 | 按场景定 |
| 单帧延迟（GPU） | 8 ms | 规划值，未实测火情模型 | 实测 YOLO-n 640 |
| 单帧延迟（CPU） | 110 ms | 由本项目 YOLO@1280 350 ms 外推 | 实测 |
| **单帧误报率** | **1e-4** | **最关键，决定一切** | S1 实测（见 R3） |
| 确认削减倍数 | 30×（园区）/ 200×（狗） | 时序+几何+多机的等效削减 | S2/S4 实测 |
| 抓图大小 | 250 KB | 带宽计算 | 实测 |
| 事件 clip | 8 MB | 存储计算 | 实测 |
| 复核时间 | 3 min/条 | 值班负担 | 实测 |
| 机器狗功耗 | 18 W / 4 h | 续航影响 | 实测 |

**计算器复核命令**（应得 200 路 @5 s → 11.5 条/天、35 min、80 Mbps）：

```bash
python tools/fire_capacity_calc.py campus --cameras 200 --interval 5
python tools/fire_capacity_calc.py campus --sweep
python tools/fire_capacity_calc.py robot --fps 15 --hours 4
python tools/fire_capacity_calc.py capture --table   # 采样覆盖 P=min(1,D/T)
```

**关于 `--confirm-factor`（重要）**：30× / 200× 是**等效值，不是独立性假设**。误报在时间与空间上相关时，实际削减会明显偏离；外部研究稿对此提出了正确批评。必须用连续录像回放实测，不能把该系数当成"单帧误报率除以 30 就是告警率"。

## 8. 下一步建议（照做即可）

### 第一步：确认两个产品决策（0.5 天，必须先做）

- 辅助预警 vs 法定探测；
- "发现即报警"取 `candidate` 还是 `confirmed`。

判据：若选法定探测，停止当前 RGB 路线，转 R9；若选辅助预警，继续。

### 第二步：现场盘点（3–5 天，R4）

产出：摄像头清单（品牌/型号/分辨率/GOP/补光/是否 PTZ/是否开放抓图），至少 20 路可用于试点。

### 第三步：采数据，建最小测试集（1–2 周）

- 正样本 ≥60 段：早期淡烟 / 中期浓烟 / 明火 / 遮挡 / 逆光；
- 负样本 ≥140 段：云 / 雾 / 蒸汽 / 反光 / 夕阳 / 红色物体 / 屏幕 / 焊接；
- 事件级标注：首次可见烟 → 消散/扑灭；双人复核，记一致性。

### 第四步：两个关键实验（R1 + R2，2–3 周）

判据（事先写定，避免事后找理由）：

- **R1**：若 95% CI 上限 >3e-4，200 路 @5 s 的误报 >50 条/天 → 必须降采样率或加规则，不能按原方案上线；
- **R2**：若 0.2 fps 的事件召回 <70%，园区轮询方案不成立，需改为"重点区域 1–2 fps"或"事件触发 + 常开低帧"。

### 第五步：跨域微调曲线（R3，2 周）

判据：500 张本地数据能否把事件召回补到 ≥85%；若不能，说明场景与公开数据差异过大，需要重新评估数据采集量。

### 第六步（可选）：机器狗 R5、VLM R7、合规 R9

按产品节奏排；R5 决定狗能否在行走中报警，R7 决定值班成本，R9 决定能否接联动。

## 9. 不要重做的事

1. **不要再用 mAP 作为选型依据**，除非测试集做过 pHash 去重并按事件切分。
2. **不要试图用单帧达到零误报**；这是算术问题，不是模型问题。
3. **不要把 VLM 放进实时回路**；它只能异步复核。
4. **不要只收正样本**；负样本是上线前提。
5. **不要假设"火焰比烟雾好做"**；跨域退化火焰约为烟雾 2 倍。
6. **不要引用 FASDD 92.71% 作为难度基准**；90.7% 近重复，修正后 −12.4。
7. **不要把 30×/200× 当成独立削减系数**；误报时空相关，必须回放实测。
8. **不要把良性火源（蜡烛/壁炉/燃气火盆/LED）当负样本**；它们是第三类（benign flame），混进负样本会教会模型"所有火都假"。
9. **不要照搬本项目的 relay/选择器设计**；火情是"同时刻多视角"，不是"跨时接力"。
