# TOP-3：门户-边置信化（zone-pair 置信分）报告

日期：2026-10-14 ｜ 性质：真实计算（新增产物 + 回放评测；含一个如实记录的负结果）

## 0. 结论速览

1. **完成"硬留一条 → 排序 + 多候选"升级**：产出 `portal_graph_v2.json`——197 个 zone-pair（出口门×入口门），双排序（置信分 / 朴素 mean_sim）+ 每出口门完整排序。
2. **命中率不降（相对基线）**：基线"每出口只留最佳一条"（top1）覆盖 pos 判对 **0/11**、v2 active 边 **14/47**；**top-7 保留：pos 11/11、4/4 组裁决 winner、v2 active 47/47、audit 99/100**（k=8 时 100%）。
3. **负结果（如实）**：文献式复合分 `conf = z(mean_sim)+z(log1p(N))+z(−log1p(Var_dt))` **未优于**朴素 mean_sim 排序（pos 平均排名 3.64 vs **2.91**；k=5 覆盖 7/11 vs 11/11）→ 结论：**召回优先用 mean_sim 排序；复合分降级为诊断量**（N 提示"忙方向"、Var_dt 提示"抖动方向"，供人工复核优先级）。
4. **对 v2 已判边无冲突**：两种排序都不排斥任何 active 边（k=7 全含）；196 边逐条保留、零改动（纯对照）。

## 1. 方法与参数

- 归组：候选对 (a→b) 的 a_end 归入 cam_a 出画门、b_start 归入 cam_b 入画门（C0 v7 门坐标，半径 0.25，超限记 `g?`）；
- 统计：N（支持数）、mean_sim、Var(dt)（通行时间方差）；
- 置信分：三统计量标准化后**等权**相加（α=β=γ=1，**无任何真值调参**）；
- 对照排序：同出口门内按 mean_sim 排序。
