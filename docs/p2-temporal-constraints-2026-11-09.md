# P2：同帧互斥作为硬约束——三层合法性、真实收益，以及一次自我否证（2026-11-09）

> 目标：把「同一时刻同框 ⇒ 必不同人」从一句显然的常识做成可用的约束：有多少产量、错杀多少、真跑起来赚不赚。
>
> 脚本：`tmp/p2/{chirla_sameframe,chirla_topology,e21_topology,topology_stats,p2_ablation,p2_ablation_merged,map_tracks,encode_gpu}.py`
> 结果：`tmp/p2/*.json`｜算力机作业：`/share/data4/yhh/human-count/p2/`
>
> **本文档记录两次自我修正。** 第一版把「同帧同人 3.5%」判为检测层的嵌套双框，第二版实测否定；第一版消融把未标注轨迹当成「不同人」，修正后数字差一个量级。两处都在 §1.2 / §3.1 留了痕迹。

---

## 0 结论先行

**同帧互斥在标注层是恒真的，在本项目的实际数据上没有收益空间——它拦不到任何真实错误。**

| 层级 | 命题 | 合法性 | 实测 |
|---|---|---|---|
| **L1 机位内** | 同机位同帧两条轨迹必是两人 | **物理恒真**（CHIRLA 标注 0 例重复 id） | 但在 average 臂上，**同帧 × 不同人且被误合并的对 = 0**（干净真值），同帧 × 同人 = 16 |
| **L2 跨机位·不共视** | 同帧跨机位必是两人 | **成立**（视野不重叠是物理事实） | CHIRLA 23 对不共视，同 id 率 **0.03–0.25%** |
| **L3 跨机位·共视** | 同上 | **不成立** | CHIRLA 14 对共视，同 id 率 **1.14–33.1%**；盲目施加错杀 **8.10%**（51,332/633,796） |

**三个判断**

1. **产量不是问题，命中率是。** CHIRLA 三段仅靠标注就产出 **234,106** 条机位内 must-not-link；跨机位同帧对 **633,796** 个。但在本项目的 1012 图库上，**约束的作用对象为 0**——同帧同时在场的人，外观上本来就不会被并。
2. **它只可能误伤。** 干净真值 + 生产同族的 average 臂：误合并 **7 → 7（一个没拦住）**，正确重连 **633 → 503（−20.5%）**。complete 臂同向（5→5 / −8.4%）。
3. **因此不必为它重跑检测。** 即便检测层完美，约束的收益空间仍是 0——真实误合并全部发生在**异时**（7/7），那是约束够不到的地方。

**拓扑自动推断（P2 原设的新意）也只到「有信号、未校准」**：`ov_frac` 在 CHIRLA seq_000 完美，在 E21 完全失效；可迁移的 `e0.85` 两数据集阈值差一个数量级。→ 跨机位约束的授权仍应走 D1 的几何标定。

## 1 L1 机位内：产量巨大，但作用对象为零

### 1.1 公开集：标注层恒真，产量 234,106 条

CHIRLA 七路同步、逐帧 bbox、跨机位全局 id（`{帧号: [{"id", "BboxP"}]}`）。

| seq | 有标注机位 | 约束量 Σ_f C(n_f,2) | 同帧同 id 重复框 |
|---|---:|---:|---:|
| seq_000 | 7 / 7 | 56,624 | 0 |
| seq_001 | 5 / 7 | 96,134 | 0 |
| seq_002 | 4 / 7 | 81,348 | 0 |
| **合计** | — | **234,106** | **0** |

★ **重复 id 为 0** 是标注自洽性的硬证据：同一个人不会在同一帧被标两次。所以「同帧 ⇒ 不同人」在**标注层面**恒真。

### 1.2 ★ 本项目里那 3.5% 的「同帧同人」是什么（第一版判断错了）

1012 四机位图库 579 轨里，同帧对 **2,791** 个，其中同人 **98（3.5%）**。

第一版据此判定：这是检测器的多尺度重复框（身框+头框），去重按 IoU≥0.5 判重而嵌套框 IoU 仅 0.19 全漏。**这个解释被实测否掉了。** 逐对量它们的形态（81 对可判）：

| 指标 | 结果 |
|---|---|
| 共同帧占较短轨迹的比例 | **中位 0.02**；`≥0.5` 的 **0 对**；分桶 <0.05 有 59 对、0.05–0.2 有 22 对 |
| 持续嵌套（嵌套帧 ≥80%） | 25 / 81 |
| 框型组合 | head×head **45**、partial×partial 12、body×head 9、head×partial 8、body×body 7 |
| 含 `id_switch=1` 轨迹 | **39 / 81 = 48.1%** |

结论完全变了：**这些不是「同一人被持续检出两个框」，而是两条长轨迹短暂交错**（重叠不到较短轨迹的 20%），其中近一半涉及真值自己标了串人的轨迹。→ **不能被"检测层嵌套去重"修掉**：去重只删重叠那几帧的框，两条轨迹依然各自存在。

对应的操作后果：按「帧内框完全包含」判嵌套并合并（`fix_nested_tracks.py` 规则：共同帧 ≥较短 50% 且嵌套帧 ≥80%），四机位**命中 0 对**。

### 1.3 例外判据也没用

「帧内一框完全包含另一框」作为无标签例外信号，在同帧对上：嵌套 100 对里同人 **49** → 精确率 0.49、对同帧同人的召回 0.50（P1 在另两个口径上是 98%/98%，因为那两个分母是「共现≥5 帧」的稳定对，不是「任意一帧重叠」）。

## 2 L2/L3 跨机位：错杀率是双峰的

### 2.1 盲目施加会错杀 8.10%

| seq | 跨机位同帧对 | 其中同 id | 错杀率 |
|---|---:|---:|---:|
| seq_000 | 255,609 | 22,119 | 8.65% |
| seq_001 | 204,122 | 15,560 | 7.62% |
| seq_002 | 174,065 | 13,653 | 7.84% |
| **合计** | **633,796** | **51,332** | **8.10%** |

**不看机位拓扑就施加跨机位同帧互斥，每 12 个约束就有 1 个是错的。**

### 2.2 但错杀率按机位对强双峰

37 个机位对（三段合计，有共同帧的）：

- **不共视群 23 对**：同 id 率 **0.0003–0.0025**（0.03%–0.25%）
- **共视群 14 对**：同 id 率 **0.0114–0.3310**（1.14%–33.1%）
- 两群之间 **4.5 倍空隙**（0.25% → 1.14%），中间无样本

阈值取 **0.5% 或 1.0% 都是 37/37 全对**；放到 2% 会漏 3 对（`seq_002 1-2` 1.14%／`seq_002 3-4` 1.86%／`seq_000 1-5` 1.91%）。**判据对阈值不敏感是这组数据最好的性质。**

典型例（seq_000）：`3-4` 有 5,989 个同帧对、同 id 率**精确 0.00%**（同室不同视野的「接力」），而 `2-3` 有 40,110 个同帧对、**23.16%**。

### 2.3 与 D1 的几何判定互相独立、方向一致

D1（`docs/d1-covis-model-2026-11-09.md`）用 SIFT+灰度相关判出「E21 九对里只有 1 对共视」；CHIRLA 的 id 法在另一个数据集上给出同一形态：**多数机位对不共视，少数共视，且不共视的一侧极干净**。

## 3 真实收益：1012 图库消融（含一次口径修正）

只改约束、不改其它。三个臂：单连接（MST 保留 ≤`thr_in`=0.15 的边）、complete（生产阶段二同族）、**average + cannot-link（生产阶段一同族）**。禁止边 = 同帧且非嵌套。

### 3.1 ★ 第一版口径错了

第一版把「被合并的对里不同人」直接算成误合并，但 579 轨里只有 **257 轨有 `person_id`**——其余 322 轨（56%）未标注，被当成了「不同人」。修正为**只在双方都有真值的对上统计**后：

| 臂 | 第一版（错） | 修正后 |
|---|---|---|
| 单连接 误合并 | 3,431 → 2,489 | **378 → 331** |
| complete 误合并 | 196 → 177 | **20 → 18** |

方向没变，量级完全不同。以下全部用修正口径。

### 3.2 修正后的结果

| 臂 | 误合并（baseline→constrained） | 正确重连（baseline→constrained） | 判断 |
|---|---|---|---|
| 单连接 | 378 → 331（−47，−12.4%） | 1,064 → 1,062（−2，−0.2%） | 表面为正 |
| complete | 20 → 18（−2，−10.0%） | 470 → 379（**−91，−19.4%**） | 为负 |
| **average（生产同族）** | 38 → 23（−15，−39.5%） | 1,018 → 640（**−378，−37.1%**） | **显著为负** |

再剔掉真值自己标了 `id_switch=1` 的轨迹（这些轨的 `person_id` 不可信）：

| 臂（干净真值） | 误合并 | 正确重连 |
|---|---|---|
| 单连接 | 181 → 177（−4，−2.2%） | 668 → 666（−2，−0.3%） |
| complete | 5 → 5（**0**） | 332 → 304（−28，−8.4%） |
| **average（生产同族）** | 7 → 7（**0**） | 633 → 503（**−130，−20.5%**） |

去掉嵌套例外（禁止边 = 纯同帧）也不改变：average 臂仍是 **7 → 7 / 633 → 491**。

### 3.3 为什么拦不到：把作用对象拆开看

干净真值、average 臂 baseline 的全部被合并对：

| | 同人 | 不同人 |
|---|---:|---:|
| **同帧** | 16 | **0** |
| **异时** | 617 | **7** |

**约束的作用对象是「同帧 × 不同人」——这一格是 0。** 真实的误合并全部落在「异时 × 不同人」（7 对），那是外观唯一可用信息、也最容易出错的地方；而**同帧同时在场恰恰是最容易区分的情形**：两个人在同一画面里、位置不同、外观不同，聚类本来就不会把它们并到一起。

所以约束不是「免费」，也不是「检出了检测缺陷」，而是**在解一个不存在的问题**。

## 4 拓扑自动推断：只到「有信号、未校准」

原设想（用共现/外观统计推断哪些机位对可能重叠）试了两个统计量。

### 4.1 `ov_frac`：CHIRLA 成功，E21 失效

定义：两机位轨迹的嵌入**互为最佳匹配**时，其时间区间**重叠**的比例。

| 数据集 | 共视 | 不共视 | 结论 |
|---|---|---|---|
| CHIRLA seq_000（21 对） | 0.11 / 0.20 / 0.27 / 0.30 / 0.67 / 1.00 (+1 个 0.00) | **14 对全为 0.00** | **AUC 0.857；>0 的 6 对全对** |
| CHIRLA seq_001（6 对）/ seq_002（6 对） | — | — | **失效**：每机位仅 2–8 段，互匹配的 `id 一致` 掉到 0.00–0.50 |
| E21 三天（24 对） | 0.263 / 0.412 / 0.100 | 0.000–**0.538** | **失效**：不共视对也普遍 >0 |

E21 失效的机制已查明：**最佳匹配多对一坍缩**。10-22 的 `办公区1×办公区2` 上，一条 B 轨被 **25 条 A 轨**同时选为最佳匹配，一对一比例仅 **0.47**（同一对里 `茶水间×行政走廊通道` 也只有 0.71）。每机位 130–220 条轨迹、每帧 20–30 人时，单点最佳匹配不可信。

### 4.2 `e0.85`：可迁移，但阈值不校准

定义：`P(cos>0.85 | 两轨时间重叠) − P(cos>0.85 | 全部)`。

| 数据集 | 共视取值 | 不共视取值 | AUC | 最优单阈值 / 准确率 |
|---|---|---|---|---|
| CHIRLA seq_000 | +0.000 … +0.116 | −0.064 … +0.000 | **0.980** | 0.000 / **0.952**（1 FP） |
| E21 三天 | +0.002 / +0.010 / +0.010 | −0.004 … +0.009 | **0.952** | 0.010 / 0.958（0 FP，1 FN） |

**是唯一在两个数据集上都排得上序的量**，但绝对效应量只有 **0.1–1.2 个百分点**，最优阈值一个 0.000 一个 0.010（差一个数量级，因为一侧是 GT 框裁片、另一侧是检测框裁片），E21 只有 3 个正样本。

**判断**：不够格当部署判据。跨机位约束的授权继续走 **D1 的 SIFT+灰度相关**。

## 6 对 P2 立题的修订

| 原设 | 实测后 |
|---|---|
| 「同帧互斥是免费的」 | 在**标注层**免费（CHIRLA 234k 条、0 违约）；在**本项目的聚类任务上**收益为 0 |
| 「把它做进聚类，顺带把拓扑也推断出来」 | 拓扑**不能**靠外观推断（E21 失效）；靠 **D1 几何标定** |
| 「阈值按机位对自适应」（自称新意） | 该新意**没有证据支撑**：约束的收益在干净真值下是 0，不是「按对调阈值」能救的 |

**建议：P2 不作为主立题。** 它的有效成分（跨机位非共视 ⇒ 同场必不同人）已被 D1+D4 覆盖，而机位内那一半被本文否定。

若要以它写一篇方法学短文，唯一站得住的题目是：

> **「同帧互斥在何时无收益」**——给出一个可先验判断的条件：约束的作用对象 = 「同帧 × 不同人 × 被误合并」，
> 在密集单人级跟踪里这一格恒为 0（同帧同场是最易区分的情形），因此该约束应先测量再决定是否启用，
> 而不是因为它「物理正确」就默认免费。
