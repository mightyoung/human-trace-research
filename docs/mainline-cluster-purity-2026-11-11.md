# 簇纯度判读结果（33 簇 / 557 轨，2026-11-11）

**三行结论：**

1. **7 卷生产配置的簇有 9/33 = 27.3% 至少含两个人**（Wilson 95% **15%–44%**）。
   按簇大小后分层加权 **21.4%**；按轨加权 **34.5%**（192/557 条轨落在混人簇里）。
   → 这是第一份**既不依赖真值、也不依赖人脸**的精度估计，回答的是"这个系统交付的身份到底有多纯"。
2. **混人集中在"中大簇 + 跨卷簇"，2–3 轨的小簇 8/8 全纯**：
   S(2–3 轨) 0/8 ｜ M(4–8) 3/9 ｜ L(9–19) 3/8 ｜ XL(20–49) 2/6 ｜ XXL(≥50) 1/2；
   单卷簇 20.8% vs **跨卷簇 44.4%**。主卷为 v2534 / v2559 的簇各 36.4%，
   主卷为 v2518 / v2526 / v2540 的 **0%**。
3. **它和对级 P .9931 不矛盾，因为两者分母不同**：9 个混人簇里 **7 个不含任何真值轨**
   → 拖进来的陌生人没有 GT 标签，永远不会变成 FP。P 只衡量 GT×GT 对（308 对），
   看不见"簇里混进了一个没有标签的人"。

## 1. 判读口径（先看这条再解读数字）

| 项 | 值 |
|---|---|
| 抽样域 | 7 卷生产配置（裸 .78 + 人脸锚点）的**全部 136 簇 / 1823 轨** |
| 抽样方式 | 按簇大小**分层随机**（S 8 / M 9 / L 7 / XL 4 / XXL 2 + 弱卷加厚），种子 20261111 |
| 实抽 | **33 簇 / 557 轨**（30.6% 的轨）；6 个有簇的卷全覆盖 |
| 展示量 | 小簇全展示、大簇 12 条；每轨 2 帧；**按卷轮转选轨** |
| 判定项 | 1 全是一个人 / 2 至少两个人（点出不合群的轨）/ 3 看不清 |
| 结果 | 24 纯 / **9 混人** / 0 看不清 |

★ 分层抽样是**故意过抽大簇**的（大簇才是混人的风险面），所以：

- **原始比例 27.3%** 高估全局；
- **后分层加权 21.4%**（层权重 = 该层在全量里的簇数 S 56 / M 29 / L 28 / XL 15 / XXL 8）是更接近全局的数；
- **轨加权 34.5%** 回答另一个问题："随机抓一条轨，它所在的簇有多大概率混了人"。

三个数都报，因为它们回答的不是同一个问题。

## 2. 混人的结构性特征

| XL（20–49） | 6 | 2 | 33.3% | 81 |

这符合"每个错对会累积"的预期：一个簇有 C(n,2) 个对，n 越大越容易至少混进一个错连接。
**小簇干净不是判读偏差**——2 轨簇只要两人不同就一眼能看出来。

## 3. 为什么"簇纯度 27%"和"对级 P .9931"能同时成立

| | 分母 | 混人簇是否可见 |
|---|---|---|
| 对级 P（7 卷） | 70 条 GT 轨的 **308 个 GT×GT 对** | **不可见**：混进来的陌生人没有 GT 标签，不产生对 |
| 簇纯度（本批） | 33 簇 / 557 轨（含 34/70 条 GT 轨） | 可见 |

实测：**9 个混人簇里 7 个不含任何真值轨**（C-02/03/05/11/13/18/22），
含真值轨的簇（6 个）混人率 33.3%、不含的（27 个）25.9%——**两类簇一样脏**，
差别只在"脏的部分有没有标签"。

→ 结论：**对级 P/R 不能当成交付精度的全部**。要把"簇里混进无名者"算进去，
只有簇级判读这一条路。这也解释了为什么 GT 上的 P .9931 和现场观感（大簇里明显不止一人）能长期对不上。

## 4. 三条混入的重判项

### 4.1 `C-01`（142 轨）= `ax-07` + `ax-10` 合并后的整簇 → **纯**

- 12 条展示里含**全部 3 条 v2534 轨**（T4/T6/T9，就是 `ax-10` 那次合并的三条），按卷轮转取到 5 v2518 / 3 v2534 / 4 v2540。
- 盲判（页面上没有来源、没有 GT、没有人脸分），判**一个人**。
- 意义：`ax-10` 现在有**第三次、且是盲的**证据，方向与复核一致。
- **但不能据此单条归因**：判的是"这个 142 轨簇像一个人"，不是"那 3 条轨一定属于 female5"。
  7 卷仍按 §6 双报 **R .9383 / .7338**，直到有更强证据（例如把 T4/T6/T9 单独与新抽样再判一次）。

### 4.2 `P-01` = `ax-16`（118×3）→ **同人**

- A 侧 12 条（v2526/v2559 各 6，俯视工位）、B 侧 3 条（v2534/v2545 走廊）。
- 补抽前 A 侧只展示 4 条且全是头顶 → 记"证据不足"。补抽后仍判**同人**。
- 影响：`ax-16` 从"证据不足"转为"可判同人"。负对照口径变为
  **9 条：同人 2（`ax-08`、`ax-16`）/ 不同人 5 / 混人 2，可判 8 条 → 同人率 25%**。
- 仍需注意：A 侧全是俯视头顶，判"同人"主要靠发型/肩线，**不是强证据**，只是比 4 条时强。

### 4.3 `P-02` = `neg-09`（20×6，外观 .984 / 人脸 .368）→ **B 侧混人**

- 两侧都在 v2534，装束极其相似（深色上衣），这正是外观余弦冲到 **.984** 的原因。
- 判读：**B 侧 6 条里至少有两个人**（T4 那几条走廊帧里根本没有对应的人）。
- 意义：**外观 .984 不等于同一个人**——高外观相似度在本素材里可以由"同款工装/同色衣服"造成。
  → 仍有理由**不**按"外观高 + 人脸接近"设放行规则；这条不是正例，也不是干净的反例，
  它连"是不是同一个人"都问不出来（B 侧不纯）。

## 5. 对主线结论的影响

| 结论 | 现状 |
|---|---|
| 7 卷人脸锚点 +20.45（R .9383） | **维持双报**；新增支持：`C-01` 盲判纯。争议仍在（无法单条归因） |
| 「人脸精度 ≈.99」 | 不变（仍是弱证据：组口径 8/9） |
| 对级 P .9931 代表交付精度 | **不能单独成立**：它看不见"混进无名者"；簇级纯度的点估计是 **21%–27% 的簇不纯**、34.5% 的轨所在簇不纯 |
| 阈值 .45 偏紧 | 证据仍只有 `ax-08` 一条；`neg-09` 判为 B 侧混人，不能当反例也不能当正例 |
| 锚点使用前提 | **加强**：簇本身 27% 不纯 → 桥接整簇前必须先确认簇纯 |
| 位置合并的否决 | 不受影响（那批是"合并动作"的判读，这批是"合并前的基础簇"） |

## 6. 下一步：放宽人脸规则之前必须先处理混人

按事先约定的停止线（"混人簇比例明显高于 5% 就先解决桥接放大问题"），**27% 远超 5%，放宽规则暂缓**。

三条可选路径，按我的推荐排序：

1. **（推荐）先做"簇内拆解"小实验**：拿本批 24 条被点名的轨当"簇内异己"的种子，
   检查这些混人簇的外观嵌入是否**本来就双峰**（如果分得开，说明是 average 链接把两团粘在一起，
   拆簇就能解决；如果分不开，说明需要人脸/姿态这类更强的特征）。
   成本小、判据清晰，且直接决定后面是"改聚类"还是"加特征"。
2. **只桥接小簇**：S 层 8/8 全纯、M 层 33% 混人 → 若一定要现在放宽人脸规则，
   限定"两侧都 ≤3 轨"才桥接；代价是覆盖面很小（S 层占 41% 的簇，但只有 **7.4% 的轨 / 135 轨**）。
3. **先给簇查纯、再桥接**：对每次 anchor 合并，先在两侧抽 4 条轨快速判纯，
   纯才桥。等于把人工判读变成常规工序，成本高、但最稳。
