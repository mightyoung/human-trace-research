# 镜像 / 反光处理调研：近邻领域惯例与本项目可借鉴清单

**背景**：2026-10-12 在 316↔323 观察中发现——检测/跟踪会把**玻璃反光中的镜像**当作人（用户指正），
已落地"手工掩膜 + 落脚点过滤"（`tools/glass_mask.py`，316 剔除 25.3%、323 剔除 14.9%）。
本文调研"图像识别领域通常怎么处理镜像/倒影"，筛选可借鉴项。
**调研时间**：2026-10-12 下午；网络可达性为当日实测。

---

## 结论先行

1. **学术界已把"镜子/玻璃"变成可分割目标**（MirrorNet/GDNet/EBLNet/SATNet/MG-VMD/MirrorMamba…，
   配有 MSD（4018 图）/GDD 等数据集）——最成熟的借鉴点是**自动镜面/玻璃分割**，可辅助/复核手工掩膜。
2. **监控工程界（含安防专利、行业实践）主流 = ROI 掩膜 + 上下文/语义校验**；
   一篇健身馆监控论文证明"语义×实例融合"过滤可把精度 **71%→83%、假阳减半**——与我们的掩膜同源、可升级为"似然打分"。
3. **与我们多机 + 深度管线天然契合的三招（建议优先实验）**：
   - **跨机一致性镜像判定**（镜像对 = 近同步 dt<~2s + 一侧在玻璃区 + 高外观相似；我们自己已在数据里无意验证）；
   - **运动不一致线索**（CVPR 2024：镜像内的运动比镜外"更小"，光流可测）；
   - **深度不一致校验**（2025 的 MirrorMamba 就用 MiDaS；我们已装好 MiDaS 管线）。
4. **不建议**：偏振/ToF/闪光多帧（无硬件）；**全图反光去除（SIRR）**——它面向"看穿玻璃"，会破坏非玻璃区，
   对监控计数无益（GDNet 论文也明确指出直接套用 SIRR 会损伤非玻璃区域）。

---

## 一、为什么难（问题本质）

- 镜面内的内容 ≈ **其周围内容的镜像**（MirrorNet, ICCV 2019）：与"显著物体"不同，镜像不"显眼"，
  只能靠**边界处的上下文对比**识别；
- 玻璃内容 ≈ **背后场景**（GDNet, CVPR 2020）：透明的极致伪装，任意物体都可能出现在玻璃后；
- 后果（两篇论文都在讲）：**深度预测错**、**实例分割错**（把镜内/玻璃后的实例当真实）→
  对我们是：**重复计数 + 跨机假匹配 + 外观匹配污染**。

## 二、处理手段六层地图

| 层 | 代表工作 | 核心思路 | 对我们（现有录像、固定机位、无新硬件） |
|---|---|---|---|
| L1 硬件/成像 | 偏振相机、ToF、Flash/No-flash 对（arXiv 2511.16887） | 物理分离反射/透射 | ✗ 不适用（已有录像） |
| L2 反光层分解（SIRR） | ERRNet 等；2025 综述 arXiv:2502.08836 | 单图分解反射层 R 与透射层 T | △ 不做全图去除；**只借"反射层估计"当似然图** |
| L3 镜面/玻璃分割 | **MirrorNet**(ICCV19) / **GDNet**(CVPR20) / GSDNet(CVPR21) / **EBLNet**(ICCV21) / GhostingNet(TPAMI25) / SATNet(对称性) / HetNet(实时) / RGB-D GSD(AAAI25 深度缺失线索) | 把镜子/玻璃**当目标分割**，供下游屏蔽或还原 | ★★ 自动掩膜草稿与复核（替代/补充手工） |
| L4 检测级过滤（监控实践） | 健身馆监控论文（语义×实例融合）；安防专利 WO2025168547A1（照明反射率判据） | 对每个人框算"上下文/语义分数"，低于阈值判为反光 | ★★★ 升级我们掩膜为**似然打分**（见 A2） |
| L5 运动/时序 | VMD-Net（首个视频镜面检测）/ **MG-VMD**(CVPR24) / MirrorMamba(2025) | 镜内与镜外**运动不一致**（镜像运动更小、光流可测）；时序对应 | ★★★ 镜像对检测 + 跨机一致性（见 A1/B3） |
| L6 3D/几何 | NeRF 光度不一致 + RANSAC 镜面拟合(2025)；镜像对称配准 MSR(2016) | 多视几何约束 | △ 中长期（与我们的 3D/BEV 路线合并考虑） |
| 附：手性线索 | Visual Chirality（CVPR20 最佳论文提名） | 自监督判断"图像是否被镜像"（文字反写、衣扣方向等） | △ 强手性目标（玻璃上的告示文字）可做轻量线索 |

## 三、可借鉴清单（按落地优先级）

### ★★★ A1 跨机一致性镜像判定器（零新依赖，用现有工具）

**思想来源**：MG-VMD 的"镜内外运动不一致"+ 我们的多机结构。镜像与其真身**天然同步、天然同外观**，
而我们已有很多跨机匹配工具——把判据反过来用即可：

```
候选对 (track_a, track_b)：
  若 dt < 2s（近同步） 且（a 或 b 的落脚点位于玻璃掩膜区/疑似玻璃区） 且 外观余弦 ≥ 0.6
  → 判"镜像对"（真身在两路之一的画面里；镜像侧不计入人数）
  若 dt ≥ 3s（含步行时间） 且 位置序列物理可行
  → 才允许进入"真实转移"流程
```

- **实证支撑（今日数据）**：旧 Top10 转移候选的 dt 全部 0.6~1.4s、双侧均为镜像；掩膜后残留
  `323#138→316#77`（dt=0.6s）等对同样"过快"，用本判据可复核是否有未掩膜玻璃区参与。
- **价值**：可发现**未画入掩膜**的玻璃反光（对 343/305/318/320 尤其有用——它们还没有掩膜）。

### ★★★ A2 反光似然打分（检测级，"掩膜"的软版本）

借鉴健身馆监控论文（gym：语义分数阈值过滤，FP 减半）与我们 318×320 的 ReID 经验，两条路线：
- **a) 启发式（快）**：反光区裁剪的常见特征——对比度/饱和度下降、边缘重影（双边缘）、
  清晰度略低、且**位置贴玻璃区**；给每个检测一个 0~1 分，作为第二道过滤（0.5 阈值先试）；
- **b) 学习式（小样本）**：以"已证 6 个镜像点"为正样本、真人裁剪为负样本，用 **DINOv2 特征 + 线性分类头**
  （几十个样本即可试），仍不足再考虑微调。

### ★★ B1 深度不一致校验（MiDaS 已在手，半小时级实验）

- **假设**：镜像"人"的 MiDaS 深度表现为**反射内容层**（常偏"远"、与玻璃面/地板先验矛盾），
  而真人落脚点贴合地板深度先验；
- **依据**：MirrorMamba（2025）用 perceived depth 做镜面检测；RGB-D GSD（AAAI25）用"深度缺失"找玻璃；
- **协议**：6 个镜像点 vs 30+ 真人采样点，比较 foot-depth 与局部地面先验的残差 → 报 AUC；
  工具可扩展 `tools/crosscam_depth.py`（帧级深度已可 0.1s/帧离线计算）。

### ★★ B2 玻璃/镜面分割网络试用（需一次环境搭建）

- **优先 EBLNet**（46.2M 参数、24ms/帧、GDD 上 88.7 IoU 级；边界学习路线，对"玻璃门/隔断"对口）；
  GDNet / MirrorNet 备选；**MirrorMamba 与 MG-VMD 为视频版（时序），可作为升级路径**；
- **用途**：对 6 路参考帧输出玻璃掩膜 → 与手工草稿**对照/合并**（发现遗漏区，例如 343 的疑似玻璃墙）；
- **风险**：域偏移（数据集偏店窗/镜面实景 vs 我们室内办公玻璃）+ **鱼眼畸变**（316/320）→ 必须实测；
- **可达性（当日验证）**：
  - `github.com/hehao13/EBLNet` ✓（权重：**百度网盘** + Google Drive）
  - `github.com/Mhaiyang/CVPR2020_GDNet` ✓、`github.com/Mhaiyang/ICCV2019_MirrorNet` ✓
  - `github.com/AlexAnthonyWarren1/MG-VMD` ✓（CVPR24 视频镜面检测）
  - `github.com/linzhiqiu/digital_chirality` ✓（Visual Chirality）

### ★ B3 同画面"真人-镜像"配对检测（光流）

- 镜像运动 = 真身运动的**镜像 + 深度缩放**（"更小的运动"）；用光流互相关做配对，配对成功后**剔除镜像保留真身**；
- **局限**：真身不在本画面时失效（我们许多镜像的真身恰在另一路）→ 与 A1 互补而非替代。

### △ C1 本楼玻璃分割小模型（中期）

MSD/GDD 预训练 + 本楼 20~50 帧人工标注微调 → 掩膜自动化（数据已由本次掩膜工作积累）。

### ✗ D 不建议

偏振/ToF/闪光多帧（无硬件）；全图 SIRR（损伤非玻璃区）；NeRF 重建（性价比低，除非升 3D 路线）。

## 四、与现有系统的衔接

我们已实现的是 **L4 的"手工版本"**（ROI 掩膜+落脚点过滤），且具备两个多数监控部署没有的条件：
**多机互证**（A1）与**在线深度模型**（B1）。推荐流水线位置：

```
检测 → 反光过滤（掩膜 + [B1 深度] + [A2 似然]）→ 跟踪 → 跨机层（A1 复核）→ 计数/流转
```

（当前掩膜在"检测后、下游分析前"；若接入实时链路，应移到"检测后、**跟踪前**"。）

## 五、可执行实验协议（P1/P2/P4 已执行；结果详见 `output_crosscam/analysis/reflection_experiments.md`）

- **P1（B1 深度校验）✅ 已完成**：地板曲线残差 **AUC=0.931**（镜像 1.223 vs 真人 LOO 0.293）→ 达标；
  工具 `tools/reflection_depth_test.py`
- **P2（A1 判定器）✅ 已完成**：dt+cos 规则标记镜像嫌疑（用户确认的 10 对 10/10 命中）+
  `--spread` 产出 111 个慢速转移候选（待深度复核）；工具 `tools/crosscam_mirror_rule.py`
- **P4（VLM 判官）✗ 0.5B 失败**：LLaVA-OneVision 0.5B 对 6 张镜像图全答"真人"（三种提示词）→ 需 ≥7B 或微调
