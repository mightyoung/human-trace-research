## 0. 结论速览

1. **"评估 → 动作"闭环建成（规则版）**：对每个候选接续/合并决策，输出六层指标 + 动作（keep 保留 / reject 隔离 / defer 暂缓；簇域另有 split 拆分 / merge 合并 / quarantine 隔离）。
2. **验收（对 55 判 + 4 组裁决回放）**：
   - 同人集（21 条）：**0 误拒**（8 keep + 11 defer + 2 缺候选）；
   - 异人集（16 条）：**0 误收**（13 reject + 2 defer + 1 缺候选）；
   - 歧义集（12 条探到者）：defer 4 / reject 7（低于声称阈值）/ keep 1；
   - **"暂缓"使用正确性**：defer 集中于中等证据（sim 0.943–0.95 或长 dt 低 w_dt）与"碎片归属待 S2"场景——与 ADJUDICATION 的裁决学说（"与代表不重叠者交由 S2"）一致。
3. **与 relay_states 四态对账：0 硬冲突**；13 条软冲突（registry=隔离 vs state=candidate，均 sim<0.943）——语义差异（候选态宽容待证 vs 规则库要求过声称阈值），建议将这批并入人工复核。
4. **额外发现（给上游）**：74 个受判对里 **24 个不在候选池（32%）**——候选生成层缺口（已知 E010↔E014 运动学漏、E009↔E024 外观不足），规则库无法评估未提案的边。
5. **gperson 五动作建议清单**（60 个 ≥3 成员簇）：quarantine 1 / split 5 / merge 37 / defer 4 / keep 13。其中 **g0206（5/8 成员为倒影）与 S6"幽灵人"审计逐字吻合**；merge 37 簇暴露 **101 条 S3 已采纳碎片链未传导到当前身份层（版本错位）**——建议列入修复。
   - 长间隔链接 63 条按 S3 结论（P 0.071 不可解）**剔除、不入建议**。

## 1. 六层定义（边域）

| 层 | 指标 | 判定 |
|---|---|---|
| ① 数据质量 | 框高 a_h/b_h、GIL 实体可查、sim 存在 | 越界/缺失 → fail（reject） |
| ② 几何结构 | a_end 到出画门、b_start 到入画门距离（C0 v7 门，r=0.15） | 超限 → 软告警（不单独否决） |
| ③ 证据强度 | sim / w_dt / dt / 同源竞争者 margin | 强：sim≥0.95 ∧ w_dt≥0.3；中：sim≥0.943 |
| ④ 约束冲突 | dt≥−1；**实体时间区间相交>1s**（318×320 豁免） | 违例 → reject（硬） |
| ⑤ 跨机位支持 | 方向候选数、时段分箱覆盖 | <3 → fail |
| ⑥ 身份/下游 | gperson 同簇、relay 状态、四态 E | 供动作微调与对账 |

**动作规则**（原则性取值，未对真值做网格搜索）：硬约束违例 / 数据质量失败 / sim<0.943 → reject；强证据且几何非告警 → keep；其余 → defer。

## 5. 使用与边界

- 输入可替换：`--cand <任意候选 json>` —— 未来 gperson/selector/边集的新版本可直接过本库出动作建议；
- 本工具是 **EVAL-2（学习式评审器）的确定性基线**；规则先于学习模型（GPT 提议纪律）；
- 已知局限：① 门几何用 C0 v7 门 vs relay 事件存在口径偏差（软告警处理）；② 区间相交只用 GIL 实体区间（±1s 容差），未含"同机位同帧互斥"的逐帧级判定；③ 缺候选的边（32%）无法评估——上游候选生成修复后本库自动覆盖。
