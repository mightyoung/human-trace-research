## 1. L0：轨迹级活体/证据质量规则（零模型）

**规则**（`gil_face_liveness.py`，40px 网格 + bin 级判定 + 通过者归并，避免链式传染）：

| 规则 | 条件（经验初值） | 语义 |
|---|---|---|
| R1 `static_unaccompanied` | n≥20 ∧ span≥180s ∧ std_r≤10px ∧ 无伴检率≥35% | 静态且多数时刻无轨迹关联 → 海报/屏幕/静物（强） |
| R2 `static_lowq` | n≥15 ∧ span≥120s ∧ std_r≤16px ∧ 可用率=0 ∧ q_max<0.70 | 静态低质 → 待审计对象（弱） |
| R3 `assoc_gap` | 可用脸 ∧ 无轨迹 | 证据完整性问题（非活体，如实区分） |
| R4 `reflection_linked` | obs 命中 S5/S6 倒影标注 | 空间复制证据（与活体互补） |

**结果**（4491 shot 全量扫描）：

- **4 个静态簇**（全部人工目检定性，证据卡见 `debug_assoc/liveness/`）：

| 簇 | 规则 | 统计 | 人工定性 | L1 spoof |
|---|---|---|---|---|
| **318 c0** | R1 | n=254 / span 576s / std 3.6px / **无伴检 95%** / 可用 0 | **窗框+玻璃边缘纹理误报**（精确框放大无明确人脸） | 0.006~0.24 部分 |
| **305 c0** | R2 | n=21 / span 341s / std 11.6px / q≤0.64 | **墙面/家具平坦纹理误报**（放大=纯色平面） | 0.03~0.62 部分 |
| **305 c1** | R2 | n=33 / span 143s / std 11.7px | **平面纹理+边缘误报** | 0.07~0.90 部分 |
| **323 c0** | R2 | n=165（合并 338）/ span 352s / std 15.1px | **门区真人头背/背影检测簇**（后脑勺类） | 0.001~0.04 未检出 |

- **R3**：65 张可用脸无轨迹（316×51 / 323×8 / 305×2 / 318×2 / 320×1 / 343×1）——316 的 51 张为「无框行人」（真人、无 GroundingDINO 框），**非活体问题**，归入证据完整性清单。
- **R4**：**101 张脸命中倒影标注（44 可用）**——与 p0c 重链接的「101 张倒影脸移出人层」**逐数吻合**（交集 5），证明 S5/S6 标注层与人脸管线可稳定对账。
- **负结果（如实）**：肤色占比特征不成立——后脑勺 0.72（被颈部皮肤污染）vs 343 暗光正常脸 0.00（光照破坏 YCrCb 范围）→ 弃用。

**已知误检命中表**：

| 样本 | L0 | L1 | 结论 |
|---|---|---|---|
| 318 窗框纹理 | ✅ R1 | 部分（≤0.24） | L0 主责 |
| 305 平面纹理 ×2 | ✅ R2 | 部分（达 0.90） | L0 主责 |
| 323 头背簇 | ✅ R2 | ✗（≤0.04） | L0 主责 |
| **323\|2 可用后脑勺**（f560, q=0.56，**池内污染实体**） | ✗（随人移动） | ✗（0.026 live） | **两层均漏 → 仅人工审计兜底** |
| 原判『58所海报』 | ✗→**翻案** | — | **非海报**（见 §4） |

**池污染实况**：323|2 全轨迹 197 帧仅 **1 张可用**（f560 后脑勺）；即当前质量门下"非人脸可用脸"的污染面很小（1 张），但确实存在且两层模型都抓不住——这是检测器姿态误差的固有盲区。

## 2. L1：MiniFASNet-V2 RGB 纹理旁路

**模型**：`models/face/minifasnet_v2.onnx`（1.74MB，Silent-Face-Anti-Spoofing `2.7_80x80_MiniFASNetV2` 的 ONNX 导出；参考文件存 `models/face/minifas_reference/`）。

**★ 校准过程（三处口径坑，逐级实测排除——工程产出本身有复用价值）**：

1. **归一化坑**：按 HF README 的 `pixel/255` 输入 → 输出**恒定 replay≈0.993**（随机噪声/纯灰/Lena/真脸无差别，logits 近乎常数）→ 网络饱和。
2. **正确口径**：**raw float [0,255]** 输入 → 立即恢复输入敏感性（Lena→live 0.998、噪声/灰块→fake）。（用官方 `.pth` 经 torch 复核，与 ONNX 输出一致 → **导出无误、README 有误**。）
3. **类序坑**：HF README 称 `[live,print,replay]`；官方 `test.py` 判据为 **`argmax==1 → Real Face`** → 正确映射 **class1=live**、spoof = p0+p2（README 类序同样有误）。

**验证校准**（同源测试）：噪声=fake / 纯灰=fake / 纯白=混合 / Lena=live 0.998 / 本地高质量脸=live。

**全量打分**（139 项 + 43 fused）：

| 集合 | n | spoof 中位 | >0.5 | 说明 |
|---|---|---|---|---|
| N 正常脸（per-tid 最优，剔除 2 例已知） | 116 | **0.0086** | **8（6.9%）** | p90=0.41；尾部为劣质姿态（见审计） |
| FP 非人/困难样本 | 17 | 0.033 | 4（23.5%） | 后脑勺 f1720=0.98、平面纹理 0.90/0.62 被抓住 |
| 倒影（R4 抽样） | 4 | **0.006** | 0 | **倒影=live ✓ 正交性成立**（光学复制不触发纹理报警） |
| fused（注记：不可比） | 43 | 0.171 | 14 | 融合画布非 2.7× 规范取样 → 读数整体偏高（系**方法差异与底层样本差异叠加**），不作证据 |

**N 尾部 8 例人工审计**：7/8 为**背影/低头/侧后/模糊**等劣质证据（323\|155、305\|4、305\|71、343\|13、323\|76、305\|27、316\|37），1 例为部分遮挡——**L1 在本地数据上的实际行为 ≈ "非正脸证据质量 flag"**。与质量分相关性弱（corr≈-0.04）——它捕捉的是 q 之外的纹理/姿态线索。

**结论与建议**：
- **可用作"软 flag + 人审排序"**（如：新增人脸证据按 spoof 降序抽审），**不得作门禁/硬阈值**；后脑勺类漏检明确存在（f560 live）。
- 若需转正：自建小型攻击集（打印照片/手机回放 20~50 张，需知情同意）做本地分布校准；当前无攻击样本 → 跨域结论仅限"代理验证"。
- ★ 该模型的 (`raw [0,255]`, `class1=live`) 口径修正对任何后续集成生效（含 Rust tract 路线）。

## 3. L2：rPPG SNR 可行性评估（负结果）

**方法**：面框中心 60% ROI（shot 间线性插值）→ G / (2G-R-B) 均值序列 → 去 1s 趋势 → Hann+补零 FFT → SNR=10log10(P[0.7-3.0Hz]/P[0.1-0.6∪3.2-8Hz])；含合成正弦自校验与**同时段空间对照**。

**结果**：

| 案例 | 时长 | 脸宽 | 运动 | G SNR | 备注 |
|---|---|---|---|---|---|
| 343\|44 / 13 / 14 / 50 / 55（大脸） | 3.4~4.8s | 116~153px | 9~31px | +3.4 / +5.2 / +8.9 / -4.9 / -2.9 dB | **全部 <5s，不满足 rPPG 时长要求** |
| 316\|32 / 127 | 2.0~2.8s | ~100px | 11~19px | -9.4 / -8.0 dB | 远低于要求 |
| 305\|2 坐姿（时长充足、脸小） | 15s×3窗 | 50px | **0.25~0.56px** | +0.3 / +8.5 / +4.7 dB | 见下 **✓ 但被共模伪影主导** |
| 323\|2 后脑勺（负对照） | 15s×3窗 | 41px | 1~4px | +5.8 / **+14.0** / +3.0 dB | **无皮肤区域"测出心跳" → 指标被伪影污染** |
| 背景块对照 | 15s | — | — | -12.6 ~ +2.0 dB | 基线 |
| 合成 1.2Hz 正弦+噪声 | 15s | — | — | +2.5dB（峰值恢复 1.208Hz） | 指标方向正确（窄带偏保守） |

**★★ 决定性空间对照**（305|2 窗口 2375-2750）：正脸 ROI +8.5dB@70bpm 的**同一时刻**——左移 250px 的背景块 **+13.0dB@同 70bpm**、上方背景 +10.5dB@66bpm → **整片区域存在 ~1.1Hz（≈66-70bpm）共模振荡（疑相机微振/环境光照），人脸并不高于环境** → 无法解释为脉搏。

**结论（负结果，如实记录）**：
1. **时长条件不满足**：316/343 大脸人群=行人路过（中位 1.2s、最长 4.8s）；305 坐姿者的脸又太小（50px）。
2. **信号可信度不成立**：高分案例均与大面积同频背景干扰共存；跨窗口峰值不稳（54/70/53bpm）；后脑勺（无皮肤）也能"测出" +14dB。
3. **判定层不推进**；工具保留。复评条件：① 出现长驻足（≥30s）+ 大脸（≥100px）场景；② 先排除 ~1.1Hz 环境伪影（此伪影本身是本次附带的环境发现，值得后续机位选型时关注）。

## 4. 已知误检修正（重要更正）

- **『58所/50所海报』翻案**：原 P0 报告称人脸墙含海报误检。复核（实帧放大）确认：所谓"海报"是 **343 视频 OSD 台标『58所-成都-14楼-电梯间』文字叠入脸 crop**（g0121 = 走近镜头的真人女性，因运动模糊+OSD 文字形似海报）。**该条应从误检清单撤回**。
- **『门饰』未单独证实**：全量静态扫描仅发现 §1 表中的 4 簇；原"门饰"可能指向 305 平面纹理簇或 318 窗框簇，未再单列。
- 静态扫描**新增**了此前未记录的对象类误检（318 窗框 254 次）；它们**全部 usable=0**（未污染质量池），但属检测器可优化点。

```
# L0（~2min）：静态簇 + 关联缺口 + 倒影交叉引用 → liveness_rule_v0.json + 证据卡

python tools/gil_face_liveness_l1.py --tag p0c --out-tag v0

python tools/gil_face_rppg.py
```

产物目录：`output_crosscam/analysis/face/`（3 个 JSON + `debug_assoc/liveness/` 证据卡与拼图）；模型与参考文件：`models/face/minifasnet_v2.onnx` + `models/face/minifas_reference/`。**全程只读 GIL；无任何主链改动。**

## 6. 结论与下一步

- **L0 立即可用**（零成本、幂等、只读）：静态对象簇 + 关联缺口 + 倒影对账三张清单；建议作为人脸管线定期体检项。
- **L1 定位=软 flag**：本地分布已验证（真脸稳定 live、倒影 live、劣质姿态进尾部）；转正需攻击样本。
- **L2=负结果归档**：不推进判定；待场景条件变化（长驻足+大脸）复评；已知 ~1.1Hz 环境伪影必须先排除。
- **下一步候选**：① flag 清单接入控制台人脸页（与并行线协调 dist 部署时机）；② 攻击样本采集合规设计；③ 检测器端减少静态纹理误报（318 窗框类，254 次/片）。
