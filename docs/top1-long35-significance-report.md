## 1. 数据与方法

**数据（全部为既有产物，本次仅补齐本地化与清洗）**：
- long35 六路检测：316/318/320 于 10-13 完成；**305/323/343 的 rest 补跑实际已于 10-14 00:24 完成**（本次发现，此前"缺三路检测"的认知已过时）；
- 清洗 keep 集（口径与 10min 一致）：316=masked_cleaned_v2(150 轨) / 323=运动学清洗(508，剔 66 倒影，已知验证 16/16) / 343=运动学清洗(100，剔 5) / 318=既有 cleaned(478) / 320=既有 cleaned(181) / 305=raw(367)；
- 10min 基准 = 交接包 `data/`（splits_v4 keep 集）。

**方法**：碎片级事件（移动轨迹首尾，span≥0.05 & dur≥1s）+ 环形移位置换（1000-2000 次）+ **全 30 对最大 z 族校正**。修正口径 v2 来自外部评审（`02-topology-retest`）：**起作用的是窗口宽度**（≤5/≤10s），门过滤为锦上添花。

**口径验证（先做后跑）**：碎片级在 10min 上复现评审实体级结论——3 条边均显著（≤5s：5.63/4.77/4.48 vs 实体级 6.45/4.90/4.71，同序同向，z 略低）。**故 35min 主口径用碎片级**（无需重建实体，等价性已在 10min 上验证）。

**非独立性披露**：10min-316 是 long35-316 的**逐行完全前缀**（2985 行 = 前 9.9min，1440 帧签名全同）→ 35min 检验为"同录像延长窗确认"（71% 为新素材），非独立测试集；外部评审知情并推荐此设定。

**判读**：① 不同对偏爱不同偏移（316→305 耐 + 不耐 −；305→318 偏爱 −7.5；305→323 偏 +）→ **不能用单一全局偏移同时解释**，此前"305 偏移 −7.5~−15 换 +2 边"的推测不成立（那会牺牲 316→305 等）；② δ=0 下双向信号已过 3σ；③ 对照平移（318=+5）显示 zmax 对任意平移不敏感（≈5），说明**族级 zmax 稳健**、配对结构才是指标——本报告结论都建立在"跨窗一致对"上，不依赖单次 zmax。→ **TIME_OFFS 维持不变**。

## 4. 局限与待办

1. **碎片级 vs 实体级**：主口径用碎片级（10min 等价性已验证）；实体级在 35min 未建（需为 305/323/343 生成嵌入 + 重建 net_tracks，本次判定为边际收益、列入可选）。
2. **非独立性**：前 9.9min 与 10min 共享（已知情）；"确认"强度应理解为"延长窗 + 3.5× 样本再检验"。
3. **[-30,-10] 边缘信号**（zmax 3.21，族校正未过线，0.053）：如实记录，不解读为物理结论。
4. **343→323 物理路径**：统计已双口径确认；"必经 316"矛盾需要抽帧目视（约 3-5 个 dt 峰样本）——列入待办。
5. 负窗/正窗未做门过滤版对照（35min 版）；10min 时结论"门过滤锦上添花"，低风险。
