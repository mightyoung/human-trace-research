# 意图预测 v2：社交邻域 + 行为聚类条件化（实验报告，2026-10-14）

前置：v1 意图模型（`docs/selector-intent-report.md`）与摄像头分组研究（`docs/intent-camgroup-study.md`，结论：不坚持分组；建议按优先级试"①社交邻域上下文 → ②行为聚类条件化"）。
本报告：两方向均**直接实验验证**（参考 Social LSTM 邻域交互 / BP-SGCN 行为伪标签）。

## 结论摘要

| # | 结论 |
|---|---|
| 1 | **两个方向均无系统增益**（同 seed 配对对比：中性至微负，Δacc −1.2~0pp / ΔmF1 −1.2~+2.5pp 且依赖一个崩溃 run）→ **维持现有全局模型** |
| 2 | 社交邻域：**per-neighbor 分层无增益证据**（有邻居样本上 social 0.674 vs base 0.686）——邻域信息未转化为预测力 |
| 3 | 行为条件化：局部线索——320 摄像头 +1.8pp、行为簇 bc4 上 +4~9pp（base 0.630 → behavior 0.667 / both 0.720）；整体被平均掉 |
| 4 | 解释：1s 尺度意图主要由**自身运动学**决定（v1 已证折返/转向不可预判）；行为类型信息与输入序列**重叠**（模型可自推）→ 条件化无增量 |
| 5 | 资产保留复用：邻域数据集构建（K=5 社交张量）、行为聚类、双开关模型代码 |

## 一、数据与方法

**数据 v2**（`tools/intent_dataset_v2.py`，样本与 v1 **逐位对齐**：train 6690 / val 1079 / test 1294，y 与 X 全等）：

- **社交邻域 `Nc [N,5,6]` + `Nmask`**：检查帧 ±1 检测间隔内活跃的最近 5 个他人；特征 [Δu, Δv, Δ(du), Δ(dv), v_mag, 共现率]（尺度=目标身高，跨机位可比）。93% 样本有 ≥1 邻居（均值 3.5 个）。无邻居样本全零 + mask。
- **行为特征 `bfeat [N,6]` + 簇标签 `bc`**：历史窗自算 [v_mean, v_std, |Δθ|_mean, Δθ_std, 直线度, 加加速度]；K-means（K=6）**train 上 fit**、val/test transform（防泄漏）。

**模型**（`tools/intent_model_social.py`，BERT 基座不变，d256/4L/4H）：
- `--social`：邻居 MLP + 可学习 query 注意力 → 上下文 token 插入序列；
- `--behavior`：bc 的 embedding token 插入序列。

**矩阵**：{base, social, behavior, both} × {42, 43, 44} = 12 模型，同超参（40 epochs、patience=8、类别权重、cosine）。远程 GPU（rfdetr 环境，~30s/模型）。

## 二、主结果（test）

| 模型 | acc | macro-F1 | 备注 |
|---|---|---|---|
| base_s42 / s43 / s44 | 0.6847 / 0.6808 / 0.6917 | 0.4636 / 0.4859 / **0.3773** | **s44 为崩溃 run**（best_ep=3；backward F1 0.03） |
| social_s42 / s43 / s44 | 0.6406 / 0.6955 / 0.6855 | 0.4644 / 0.4611 / 0.4768 | |
| behavior_s42 / s43 / s44 | 0.6793 / 0.6669 / 0.6770 | 0.4727 / 0.4667 / 0.4554 | |
| both_s42 / s43 / s44 | 0.6631 / 0.6986 / 0.6971 | 0.4547 / 0.4771 / 0.4511 | |

**同 seed 配对（Δ = cfg − base）**——主口径（消除初始化噪声）：

| cfg | Δacc（s42/s43/s44） | ΔmF1（s42/s43/s44） |
|---|---|---|
| social | −0.044 / +0.015 / −0.006 | +0.001 / −0.025 / +0.100 |
| behavior | −0.005 / −0.014 / −0.015 | +0.009 / −0.019 / +0.078 |
| both | −0.022 / +0.018 / +0.005 | −0.009 / −0.009 / +0.074 |

**读法**：s44 上的"提升"来自 base_s44 崩溃（0.377），非配置本身；剔除后（s42+s43）三个配置 acc 均 ≤base，mF1 亦 ≤base（唯 behavior_s42 +0.9pp）。**结论：无系统增益**。

对照 v1 基准：`model_1012` test acc 0.6677（v1 全量 60ep）；v2 base（同口径 40ep）0.686——基线口径一致，可用作实验内对照。

## 三、分层诊断

**per-camera acc（3-seed 均值）**：

| cfg | 305 | 318 | 320 | 323 |
|---|---|---|---|---|
| base | 0.628 | 0.617 | 0.587 | 0.756 |
| social | 0.650 (+2.3) | 0.641 (+2.4) | 0.544 (−4.4) | 0.718 (−3.8) |
| behavior | 0.635 | 0.632 (+1.5) | **0.605 (+1.8)** | 0.720 |
| both | 0.624 | 0.640 | 0.565 | 0.749 |

**per-neighbor 分层（关键否证）**：social 在"有邻居样本"上 0.674 vs base 0.686——若邻域有效，增益应在此分层出现，实测无。

**per-behavior 分层**：bc4（占 test ~6%）：base 0.630 → behavior 0.667 / both 0.720（+4~9pp）；其余簇持平或微降。

## 四、为什么没有增益（解释框架）

1. **时域尺度**：1s 未来运动由"自身惯性 + 自身决策"主导；他人的运动只在**强交互**（让路、并肩、跟随）时改变目标轨迹，而办公/茶水间场景大多数人是独立路过（邻域均值 3.5 个但多为静态或无关者）。
2. **信息冗余**：行为聚类标签（速度/转向统计的聚类）与输入 token（2.4s 运动学序列）**高度重叠**——Transformer 可从序列自推行为类型，条件化没提供新信息；聚类边界噪声反而引入轻微扰动（soft 分配）。
3. **与 v1 结论一致**：v1 已证折返/转向是"运动学不可预判"（样本自身历史无区分信号）——社交/行为信息也不改变这一上限。
4. 320 与 bc4 的局部增益说明**"特定场景/特定行为模式"存在条件化收益**，但被整体平均抵消。

## 五、建议与遗留

1. **维持全局意图模型**（现有 `model_1012` 不动）；
2. 有依据的后续方向（若继续投入）：**更长时域意图（3s+，社会信息价值随时域增长）**、**交互事件专项**（对闯入/对向/让路场景切片后单独建模），而非全局条件化；
3. 资产（可复用）：`tools/intent_dataset_v2.py`（邻域张量构建，参数化 K/尺度）、`tools/intent_model_social.py`（`--social/--behavior` 双开关）、12 模型结果 `output_crosscam/analysis/intent/v2/`（summary_v2.json + 两图）；远程训练目录 `~/human-count/intent_v2/`。

**复现**：本地构建 `python tools/intent_dataset_v2.py --split {train,val,test}`；远程 `bash run_intent_v2_matrix.sh`（约 7 分钟）；汇总 `python tools/intent_v2_summarize.py`。
