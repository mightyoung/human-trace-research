## 结论先行（TL;DR）

1. **先把三件事拆开**：火焰检测、烟雾检测、火情事件确认，是三套不同的难度与指标。火焰是强先验的"已起火"信号（秒级、可见光即可、认证产品成熟）；烟雾是唯一能争取到分钟级提前量的信号，也是误报主战场；事件确认（多帧 / 多机 / 人工）决定系统可不可用。**工业价值与工程难度都集中在后两者。**
2. **学术指标已饱和，运营指标远未解决。** D-Fire 上 YOLO 系列 mAP50 约 76–80%；综述汇总的论文准确率 79.66%–98.72%，但同一批综述给出的真实系统误报率是 **3.4%–29.49%**。公开可查的运营级基线是 **0.66 次误报/路/天**（65 路 × 9 天实测）与 **0.2 次/路/天**（100 路长期运营）。**验收必须用"每路每天误报次数 + 发现时延"，mAP 只能用于选型初筛。**
3. **公开数据集够"预训练"，不够"上线"。** D-Fire（21,527 张）、FASDD（10 万级）、FIgLib（24,800 张 / 315 场火）覆盖"有没有火"，不覆盖你的机位、你的干扰源、你的昼夜与镜头状态。**纯公开数据训练→自有场景必然翻车**；正确姿势是"公开预训练 + 本地硬负样本闭环"。
4. **方法已收敛为四层，单帧检测器只是第一层。** 单帧检测（YOLO / DETR）→ 时序证据（持续性 / 面积增长 / 光流）→ 区域分割（定位与面积量化）→ 决策层（多帧投票、多机共识、人工复核）。文献里所有"高精度"结果，几乎都隐含了后三层的贡献。
5. **"早期"有物理下限。** 烟羽在图像上只有 1–2 像素时，RGB 单帧不可能稳定识别。可复现的"早期"是**点火后 5–15 分钟**（Govil 2020：通常 15 min 内；Pano AI 宣称 3 min，含人工复核且为近场）。宣称"秒级发现火情"的，多数检测的是已成型火焰。
6. **降误报的第一杠杆不是更大的模型，而是三类工程约束**：几何掩膜（天空 / 地平线 / 水面 / 道路）、时序持续性 + 面积增长、硬负样本闭环。HPWREN 用地平线掩膜 + 4 邻域位移复核 + 时序拼接，把误报压到 **1 次/路/5 天**。这些手段与模型无关，迁移成本最低。
7. **基础模型（GroundingDINO / SAM / VLM）适合做冷启动与标注加速，不适合做最终判别器。** 2025 年 QUT 的做法有代表性：GroundingDINO few-shot 当教师生成伪标签，蒸馏到 YOLO-nano，学生 mAP50 0.721；并把"烟羽（plume）"单列一类，雾/火混合场景 F1 从 70% 提到 76.1–85.7%。**教师负责便宜地造数据，学生负责便宜地跑。**
8. **合规是分水岭。** 国内"图像型火灾探测器"是 CCC 强制认证产品；强制性国标《图像型火灾探测器》2025 年 6 月已报批，按火灾特征响应分 **烟气型 / 火焰型 / 热源型 / 复合型**，替代 GB 15631-2008 的对应部分。国外对应 FM 3232（全尺度油/气/固体火试验、4 台样机重复性、false-stimuli 与环境试验）与 NFPA 72 的 17.7.7 / 17.8.5。**"辅助预警"与"法定探测"是两条产品线，指标、责任、成本都不同，不能混着卖。**
9. **本项目有 5 条可直接搬的结论**（§3.4）：排他一对一匹配在多视角场景是结构性错误；固定时间窗应换成分布；量化/换运行时要按"检出集合一致率"验收而非逐元素数值；"看不清"必须是第三态；证据分级与影子模式必须前置。
10. **推荐路线**：先做**辅助预警 + 人机复核**（不接消防联动），指标定在 **≤1 次误报/路/天、事件召回 ≥85%、近场 P50 ≤3–5 min**；影子运行 3–6 个月后再决定是否走认证线。

## 一、问题坐标与术语对齐

### 1.1 三个被混称的任务

| 维度 | 火焰检测（flame） | 烟雾检测（smoke） | 火情事件确认（incident） |
|---|---|---|---|
| 物理信号 | 高温辐射、~5–15 Hz 闪烁、高饱和色 | 颗粒散射、半透明、缓慢形变与上升 | 多帧 / 多机 / 多传感器证据汇聚 |
| 典型时延 | 秒级 | 分钟级（5–15 min） | 与人工复核流程同量级 |
| 主要难点 | 焊接弧、夕阳、红色物体、镜面反光 | 雾 / 云 / 蒸汽 / 扬尘、边界模糊 | 误报成本、责任归属、重复告警 |
| 成熟度 | 高（有认证产品） | 中（学术热、工程难） | 低（各家做法不一） |
| 主指标 | 响应时间、探测距离、最小火焰尺寸 | 误报/路/天、发现时延、召回 | 确认率、复核时长、重复抑制 |

> 判断：把三者合成一个"烟火识别"任务去招标，是多数项目失败的起点。火焰与烟雾应用两套数据、两套阈值、两套指标。

### 1.2 术语对照

| 我们的说法 | 文献术语 | 代表工作 |
|---|---|---|
| 烟火识别 | fire and smoke detection | 通用 |
| 早期发现 | early detection / time-to-detection | FIgLib + SmokeyNet；Govil 2020 |
| 误报 | false alarm / nuisance alarm | 综述统计；FM 3232 的 false-stimuli 试验 |
| 干扰源 | fire-like / smoke-like distractors | BoWFire、D-Fire 负样本、FESB MLID |
| 持续确认 | temporal persistence / persistence filter | Venâncio 等；HPWREN 运营实践 |
| 面积增长 | area variation / growth rate | Venâncio 等 |
| 多机确认 | multi-camera consensus / triangulation | HPWREN 方位角楔形求交；Pano AI |
| 拒识 | abstention / open-set rejection | 不确定性建模（TP-UAST 2025） |
| 视频级弱标签 | weakly supervised / MIL | UMIL（CVPR 2023） |

### 1.3 场景分层（决定选型，不是同一套方案）

| 场景 | 主模态 | 典型目标 | 主导难点 | 主要指标 |
|---|---|---|---|---|
| 室内大空间（商场/仓库/场馆） | 可见光 ± 红外 | 数米级火焰、烟层 | 灯光、反光、水汽、遮挡 | 火焰响应 ≤20 s；误报/路/天 |
| 隧道 / 管廊 | 可见光 + 红外 | 近场 | 车灯、尾气、粉尘、高湿 | 响应时间；可用率 |
| 工业厂区 | 多光谱（IR/UV）+ 可见光 | 0.25 m × 0.25 m @150 m | 焊接弧、蒸汽、工艺明火 | 抗干扰；探测距离 |
| 森林草原（塔基/山顶） | 长焦可见光 + 红外 | 远场，烟羽数十像素 | 云、雾、霾、逆光、地形遮挡 | 误报/路/天；发现时延 |
| 卫星遥感 | 多光谱 / 热红外 | 像素级（数百米~5 m） | 重访周期、云遮挡 | 重访；最小火线长度 |

## 二、近邻研究工作梳理

> 阅读深度标注：**【正文】**= 已读正文/公式/官方文件；**【摘要】**= 仅摘要或提纲；**【二手】**= 经权威二手来源转述；**【待核查】**= 未读原文。

### 2.1 数据集与基准

| 数据集 | 规模 | 标注 | 场景 | 用途与局限 |
|---|---|---|---|---|
| **D-Fire** | 21,527 图（仅火 1,164 / 仅烟 5,867 / 烟火共存 4,658 / 无 9,838） | 框 | 网络采集，室内外混合 | 最常用的检测基线；场景杂、无时序、许可需核 |
| **FASDD** | 10 万级 | 框（4 种格式） | 监控 / 无人机 / 卫星 | 覆盖最广，YOLOv5x 约 80% mAP@0.5；预印本被撤，使用前核对最终版本与许可 |
| **FIgLib** | 24,800 图 / 315 场火 / 101 机位 / 30 站点 | 图像级烟/无烟；144 场有框+掩膜 | 山顶固定机位，点火前后各 40 min，约 60 s 间隔 | 早期烟羽与**运营指标**的最佳公开基准；仅 wildfire |
| **VisiFire** | 13 火 / 21 烟 / 21 林烟 / 2 其他（视频） | 视频级 | 户外、森林、室内 | 经典小基准；规模小、场景重复 |
| **FIRESENSE** | 11 火 / 13 烟 / 25 非火（视频） | 视频级 | 文化遗产 / 室外 | 负样本质量较好；规模小 |
| **MIVIA** | 31 视频（17 火 / 14 非） | 视频级（部分框） | 真实环境 + 干扰 | 经典；需申请 |
| **BoWFire** | 226 图（119 火 / 107 非） | 像素级 | 含大量火色干扰（夕阳、红衣、灯光） | 专测误报；太小，只能做测试集 |
| **Corsican Fire DB** | 1,135 RGB + 掩膜；100 组 RGB-NIR；5 段序列 | 像素级 | 野外 | 分割与多光谱；需申请 |
| **FESB MLID** | 400 图 / 11 类 | 语义分割 | 地中海景观 | 烟 / 云 / 雾 / 阳光同框，适合做干扰分类 |
| **Smoke100k** | 约 10 万合成图（33k/36k/33k） | 框 + 掩膜 | 合成烟 + 真实背景 | 补数据；合成-真实域差需实测 |
| **FLAME / FLAME2** | 无人机 RGB + 热红外 | 框 / 分割 | 计划烧除 | 空中视角，与塔基分布不同 |
| **DSDF** | 规模【待核查】 | — | 雾、运动模糊、烟样纹理 | 难例评测集 |

三条判断：

1. **不存在"通用烟火数据集"。** 场景分布决定可用性：FIgLib 的价值不在图片数量，而在它同时提供了**序列级切分**与**可对齐的运营指标**（误报/路/天、发现时延）。
2. **负样本比正样本重要。** BoWFire、FESB MLID、D-Fire 的"无火无烟"类，是降误报的核心资源；只收集火情正样本的系统，上线后必然被云和蒸汽打穿。
3. **许可是硬约束。** Corsican、MIVIA 需申请；FIgLib 要求署名；FASDD 需核对版本；商用前必须逐数据集过许可，不能默认"公开=可商用"。

### 2.2 方法谱系

| 代际 | 代表方法 | 强项 | 硬伤 | 在本任务中的位置 |
|---|---|---|---|---|
| 传统特征 | 颜色空间阈值 + 小波/纹理 + 光流 | 可解释、算力极低 | 阈值随光照漂移，误报高 | 基本淘汰，仅作兜底 |
| 图像分类 CNN | InceptionV3 / ResNet 滑窗 | 简单、易训练 | 无定位、滑窗成本高 | 固定机位粗筛 |
| 单阶段检测 | YOLOv5 → v11、SSD、EfficientDet | 实时、易部署、生态好 | 小目标弱、无时序 | **L1 主力** |
| 两阶段 / Transformer 检测 | Faster R-CNN、DETR、Deformable DETR | 小目标与复杂背景更好 | 慢、标注要求高 | 高价值点位 |
| 时空模型 | 3D CNN、ConvLSTM、TSM、SmokeyNet | 用运动区分烟与云 | 需序列、成本高 | **L2** |
| 分割 | U-Net、DeepLab、YOLO-seg、SAM | 边界与面积量化 | 标注贵、实时性差 | 面积增长 / 定位 |
| 弱监督 / 异常检测 | MIL、UMIL、背景建模 | 只要视频级标签 | 定位粗、上下文偏置 | 冷启动 |
| 基础模型 | GroundingDINO、SAM、VLM | 零样本、造标签快 | 语义边界不稳、贵、慢 | **教师 / 标注** |

关键量化锚点：

- D-Fire 上：Tiny YOLOv4 63.34 / YOLOv4 76.56 / YOLOv5s 78.30 / YOLOv5l 79.46（mAP50）；剪枝 YOLOv4 在保持 73.98 的同时降 83.6% 计算量——**轻量化不是免费午餐，但代价可控**。
- CCi-YOLOv8n：D-Fire 78.5 mAP50 / 46.6 mAP50-95；Web-Fire 72.0 / 41.0。**mAP50 与 mAP50-95 差 30+ 个点，说明框的贴合度很差**——烟雾边界本身就是模糊的。
- YOLOv11 + 直方图均衡：D-Fire mAP50 0.771。**预处理（HE/CLAHE）能带来 1–3 个点，成本几乎为零，应作为默认项。**

### 2.3 时序与早期检测

- **SmokeyNet（FIgLib，Remote Sensing 2022）**：以序列而非单帧为输入，利用时空信息，论文称其精度接近人工分类。**方法本身不新，价值在于它把"序列级切分 + 运营指标"一起定义了**，后续工作有了可比基线。
- **光流 + 不确定性（TP-UAST，arXiv 2025）**：用光流编码运动、位移窗 Transformer 建模，并显式区分 **aleatoric / epistemic 不确定性**，输出校准后的置信度。对工程的含义：**"不确定"可以作为一个可训练的输出**，直接对接人工复核队列。
- **持续性 + 面积增长（Venâncio 等）**：连续 N 帧命中 + 面积扩张系数超阈值才报警。原理是"干扰源通常静止或不增长"。这是**性价比最高的两条规则**，十行代码，通常能砍掉一半以上的瞬时误报。
- **早期检测的物理边界**：烟羽在 1–2 像素宽时，单帧 RGB 无稳定可分特征。提高早期召回的正确手段是**更高分辨率 / 更长焦 / 更近机位 / 更长观察窗**，不是更深的网络。

### 2.4 误报抑制：四条主线

| 主线 | 具体做法 | 公开证据 |
|---|---|---|
| **几何先验** | 地平线以上掩膜去掉云；ROI 排除水面、道路、屏幕、反光面 | HPWREN：掩膜同时提速并去掉云触发 |
| **时序证据** | 连续 N 帧 + 面积增长 + 质心向上漂移 | Venâncio：persistence + area variation |
| **多机共识** | 同一火点多机可见 → 方位角楔形求交，交集才升级 | HPWREN：楔形相交提升置信并定位 |
| **硬负样本** | 每日误报回流为负样本，显式构造"像烟不是烟" | UMIL 反例：MIL 会学成"烟=异常"，对烟囱/蒸汽误报 |

**UMIL（CVPR 2023）的教训值得单独记**：弱监督模型会走捷径，把"烟"当成"异常"的上下文线索，于是烟囱、工业蒸汽、雾都被判成事件。解法不是加数据，而是**显式构造"同上下文、不同标签"的样本**，迫使模型学事件本身而非背景。

### 2.5 评估与合规：mAP 为什么会骗人

三个失效点：

1. **IoU 对烟雾无意义**：烟没有确定边界，标注本身带主观性；mAP50 高不代表告警可用。
2. **帧级随机切分泄漏**：同一场火的相邻帧分到训练与测试，指标虚高。应按**火情事件 / 机位**切分（FIgLib 即按序列切分，并剔除了夜间、黑白、烟存疑的样本）。
3. **单帧指标不含决策**：真实系统是"多帧 + 多机 + 人工"的串联，任何一环的延迟与拒识都不在 mAP 里。

运营指标（建议口径）：

| 指标 | 定义 | 备注 |
|---|---|---|
| 误报强度 | FP / 路 / 天 | 运维唯一能感知的量 |
| 事件召回 | 被系统首次发现的真火情 / 全部真火情 | 需与 911 / 值班记录对齐 |
| 发现时延 | 点火 → 告警，P50 / P90 | 点火时刻需人工回溯标定 |
| 定位误差 | 告警位置与真实火点距离 | 单机方位角 vs 多机三角 |
| 复核负担 | 每日告警数 / 值班员 | 决定系统会不会被关掉 |
| 可用率 | 在线率、镜头污染可检出率 | 长期运营的隐形杀手 |

合规体系（两条完全不同的线）：

- **国际**：FM 3232（2020 版）对视频图像火灾探测器做**全尺度油/气/固体火试验**，要求 4 台生产样机证明重复性，并做 false-stimuli 与环境（湿度、温度、电压、振动）试验；NFPA 72 将视频图像烟雾/火焰探测列为 listed 类别（17.7.7 / 17.8.5），要求工程勘察确定覆盖、防拆与故障信号、按厂商文件维护。**认证测的是"起火后的响应"，不是"早期发现"。**
- **国内**：图像型火灾探测器属 CCC 强制认证；强制性国标《图像型火灾探测器》2025 年 6 月报批，按响应能力分**烟气型/火焰型/热源型/复合型**，按组成分独立型/分布型，按环境分室内/室外，并新增镜头污染与视场变化监测、抗灯光/日光干扰、火灾定位报警等要求；GB 50116-2013 第 5.2.7/5.2.8 条给出适用与不宜适用条件（强火焰辐射、需快速响应宜用；浓烟先行、镜头易污、视线易被油雾/水雾遮挡、可燃物为金属无机物、易受阳光/白炽灯直射不宜用）。
- **工程指标参考**：《先进安全应急装备推广目录（工业领域 2024 版）》对图像型火灾探测器给出"多光谱采集、可见光 2592×1944、最远火焰 150 m、最小火焰 0.25 m×0.25 m、响应 ≤20 s"的条目。**这是"火焰型"的口径，不能拿来要求烟雾早期发现。**

### 2.6 工程与商业化现状

|---|---|---|---|

### 3.1 方法维度

| # | 文献 / 工程方法 | 可迁移性 | 迁移形态 | 风险 |
|---|---|---|---|---|
| ① | 教师-学生蒸馏（GroundingDINO → YOLO-n） | **直接（P0）** | 零样本教师造 1–2 万伪标签，人审 5–10% 后训学生 | 伪标签错误固化；教师对"烟/雾"边界不稳 |

| ③ | 几何掩膜 + 多机楔形求交 | **直接（P0）** | L0 掩膜 + L3 共识 | 掩膜需随云台/季节/施工更新 |
| ④ | 不确定性校准 / 拒识 | **修改后（P1）** | 三态输出 + 复核队列 | 需标注"看不清"样本，成本高 |

### 3.2 指标维度

| 学术指标 | 运营对应 | 建议动作 |
|---|---|---|
| mAP50 / mAP50-95 | 无直接对应 | 只用于模型选型与回归，不进验收 |
| Precision / Recall（帧级） | 事件召回、误报/路/天 | 必须重算为事件级 |
| F1 | 告警质量 | 用"每日告警预算下的召回"替代 |
| 分割 IoU | 面积增长率的输入 | 仅作中间量，不作验收 |
| 推理 FPS | 单路成本、抽帧上限 | 换算成"每路每月算力成本" |
| — | 发现时延 P50/P90 | **新增，且作为一级指标** |
| — | 复核负担（告警/人/天） | **新增，决定系统能否活下来** |

### 3.3 实验设定维度

1. **按事件切分**，不按帧切分；训练/验证/测试的火情事件互不重叠。
2. **时间外推**：用去年数据训练，今年数据测试；季节性变化是最容易被忽略的分布漂移。
3. **跨场景零样本**：留一个完全未参与的机位做 zero-shot，量化"换机位要补多少数据"。
4. **固定告警预算下的召回最大化**：与"误接约束下漏接最小化"同构——先定每天可承受的告警数，再谈召回。
5. **影子模式**：上线前只记录不推送，用真实值班记录对齐；离线指标不作为验收依据。

### 3.4 从本项目成果看五条可迁移结论

> 以下证据来自本项目已交付产物（README / docs / relay_v2 统计），属**实测**；迁移到火情是**推断**，需在新场景验证。

**① 排他一对一匹配，在多视角场景是结构性错误。**
本项目实测：2,618 个接力候选中 179 个高相似（sim≥0.943），其中 **132 个（74%）被 mutual-best 排他约束淘汰**；53 个出口存在多候选竞争；单个事件 `343:E042` 有 7 个高分候选、人工确认至少 2 对同人。
迁移：一个火点可被多机同时看到，一个机位也可能同时看到两处火。**多机确认不能用匈牙利一对一**，必须用"事件聚类 + 共识"（时间窗 + 方位角楔形 + 地貌掩膜）。排他约束会系统性丢掉告警，且丢的是"最该报的那一路"。

**② 固定时间窗应换成分布。**
本项目实测：确认接力的时间差 p25=1.2 s / 中位 4.8 s / p75=15.5 s / max=59 s，是"秒级主峰 + 长尾"的双模态，而旧管线用全局硬窗 [-1, 60] s。
迁移：火情的"连续 N 帧""冷却期 T 分钟"同理——N 与 T 应随距离、风速、燃料、机位俯仰变化，用分位数设窗、样本少时回退宽窗。**固定常数在单场景能调好，换场景必崩。**

**③ 量化 / 换运行时，按"检出集合一致率"验收，不按逐元素数值。**
本项目实测：GroundingDINO 导出 ONNX 后，低分背景 query 的 logits 偏差约 20%（最大 3.6），但在 `box_threshold=0.25` 下**检出集合一致率 100%**；因此验收标准定为"检出结果等价"，而非逐元素比对。
迁移：火情模型上 INT8 / NPU 时，mAP 掉 0.3 个点不是生死线；要看**同一批真实告警是否还在、误报是否变多**。用固定回放集做集合级比对，比看总体指标可靠。

**④ "看不清"必须是第三态。**
本项目做法：人脸库三态（真人 / 非人 / 看不清）+ 候选对三态裁决（确认 / 否决 / 存疑），"存疑"进入延迟提交而非硬判。
迁移：火情告警同样应有"真火 / 干扰 / 不确定"。**二分类系统会把"不确定"随机推向两边**——推向真火则误报爆炸，推向干扰则漏报。第三态是人机协作的接口。

**⑤ 证据分级与影子模式必须前置。**
本项目纪律：区分计划 / 执行 / 完成 / 验收；静态检查不算实际使用验收；产物标注"实测 / 推断 / 预期"。
迁移：火情系统上线前至少 3 个月影子运行，按"每日告警预算"考核；所有对外数字标注口径（是否含人工复核、分母是什么）。**这条比任何模型技巧都更能避免项目烂尾。**

## 四、方案设计建议

### 4.1 四层架构

```
L0 采集与几何     RTSP/录像 → 抽帧(1–2 fps) → ROI/地平线掩膜 → 云台角度/标定(可选)
                        │
L1 单帧检测       YOLO-n 类（fire / smoke / plume 三类）→ 框 + 分数
                        │
L2 时序证据       8–16 帧滑窗 → 持续性 / 面积增长 / 质心漂移 / 光流散度
                        │
L3 事件决策       分数校准 → 多帧投票 → 多机共识 + 方位角定位 → 三态(真火/干扰/看不清)
                        │
L4 人机回环       复核队列 → 硬负样本库 → 再训练（训练/验证数据隔离）
```

各层要点：

- **L0**：抽帧 1–2 fps 足够（烟演化慢），25 fps 是浪费；掩膜先于模型，成本最低、收益最高。
- **L1**：三类输出优于两类。QUT 2025 的"plume"类把"烟羽"与"烟"分开，雾场景 F1 提升 6–15 个点；对小目标用切片推理（SAHI 类）或 1280 输入。
- **L2**：优先用"检测框轨迹"做规则，其次才上 3D CNN；规则可解释、可回退，是产线的骨架。
- **L3**：三态 + 分数校准（温度缩放或不确定性头）；单机高置信可出"single-view"告警，双机交集才升级为"confirmed"。
- **L4**：每日误报自动进负样本库；只标注"模型不确定 + 值班员争议"的样本（主动学习）。

### 4.2 冷启动路径

1. **公开预训练**：D-Fire + FASDD，训 fire / smoke / plume 三类基线，复现 mAP50 75–80%。
2. **目标场景采集**：2–4 周，覆盖昼夜、晴/雾/雨、镜头脏污、已知干扰源（焊接、蒸汽、反光、夕阳）。
3. **教师造标签**：GroundingDINO / SAM 零样本出框与掩膜 → 人审 5–10% → 训学生模型（QUT 路线）。
4. **硬负样本库**：云、雾、蒸汽、水面反光、玻璃幕墙、焊接弧、夕阳、红色物体、屏幕火焰。**目标 ≥5,000 张，且按干扰源分桶。**
5. **主动学习**：每轮只标 200–500 张高价值样本，两周一迭代。

### 4.3 误报抑制三件套（规则层，按顺序生效）

| 顺序 | 规则 | 参数建议 | 作用 |
|---|---|---|---|
| 1 | 几何掩膜 | 地平线以上、水面、道路、屏幕区域置黑 | 去掉云与结构性干扰 |
| 2 | 持续性 | 同一网格连续 k 帧命中；k 由场景分布定（冷启动 k=5） | 去掉瞬时噪声 |
| 3 | 面积增长 | 30 s 内面积比 >1.2，且质心向上 | 去掉静止的"像烟"物体 |
| 4 | 多机共识 | 两路以上方位角楔形相交 → 升级 confirmed | 去掉单机局部干扰 |
| 5 | 冷却合并 | 同点位 T 分钟内合并为一条事件 | 去掉重复告警 |

### 4.4 多机融合：共识，不是接力

本项目的 relay 解决的是"人从 A 门走到 B 门"的**跨时关联**；火情解决的是"同一时刻多视角看同一事件"的**同时关联**。两者形态不同，**不要照搬 relay 的状态机**。

- 以"事件"为单位聚类：时间窗（±2 min）+ 方位角楔形相交 + 地貌掩膜。
- 单机告警标记 `single-view`；双机以上标记 `confirmed`；三机以上可直接推送。
- 定位用楔形交集，不用单目测距；误差量级 100 m 内即为可用（森林场景可放宽）。

### 4.5 算力与部署

| 方案 | 形态 | 适用 | 备注 |
|---|---|---|---|
| 边缘盒（Jetson 类） | 8–16 路 @1 fps，YOLO-n | 存量相机改造、无云 | 成本固定，运维简单；算力需实测 |
| 云端级联 | 轻模型全量筛 → 重模型只跑候选 | 城市级 / 多站点 | 带宽与隐私需评估；成本可降一个量级 |
| 全云端 | 全帧上传 | 不推荐 | 带宽与费用不可持续 |

延迟预算（近场）：采集 1 s + 推理 0.5 s + 聚合 30 s + 复核 60 s ≈ **1.5–2 min**，与 Pano 的案例量级一致。

### 4.6 验收指标（三级，建议值）

| 级别 | 定位 | 误报/路/天 | 事件召回 | 发现时延 | 其他 |
|---|---|---|---|---|---|
| **A 辅助预警** | 不接消防联动，只推值班 | ≤1.0 | ≥85% | P50 ≤5 min（近场） | 复核负担 ≤50 条/人/天 |
| **B 值班级** | 接入值班流程，可派车 | ≤0.2 | ≥90% | P90 ≤5 min（近场） | 定位误差 ≤100 m（多机） |
| **C 认证级** | 法定探测 / 联动 | 按型式试验 | 按标准 | 火焰型 ≤20 s | FM 3232 / 新国标 / CCC |

> 说明：A/B 级为本文建议值，非标准值；C 级必须走型式试验，不能用户外测试替代。

## 五、实施路径与判定标准

| 阶段 | 内容 | 判定标准（完成=可验证） |
|---|---|---|
| **S1 基线**（约 2 周） | D-Fire + FASDD 训 YOLO-n；建立 200 段本地负样本 | 复现 mAP50 75–80%；在 20 段自有视频上跑通端到端 |
| **S2 场景适配**（3–4 周） | 目标机位采集；教师-学生蒸馏；事件级指标首测 | 事件召回 ≥80%；误报/路/天有基线数字（允许 ≤5） |
| **S3 时序与共识**（2–3 周） | persistence / growth / 多机共识 / 冷却合并 | 误报/路/天 ≤2；时延 P50 有实测值 |
| **S4 影子运行**（8–12 周） | 只记录不推送；两轮硬负样本回流 | 误报/路/天 ≤1；召回 ≥85%；值班员可用性访谈通过 |
| **S5 产品化决策** | 辅助预警 or 认证线 | 成本模型 + 合规路径 + 责任边界三份文档齐备 |

依赖与前置：目标场景的**点火真值**（消防/林业记录）是 S2 之后所有指标的前提；没有真值就只能做相对比较，不能对外报绝对数字。

## 六、证据与边界（诚实清单）

**证据强度**

- **正文/官方文件级**：Govil 2020（Remote Sensing 12:166，误报与延迟数据）；FIgLib + SmokeyNet（Remote Sensing 14:1007）；FM 3232 范围与试验要求；《图像型火灾探测器》报批稿编制说明（国家消防救援局，2025-06）；《先进安全应急装备推广目录（工业领域 2024 版）》相关条目；HPWREN 运营博客（2021-04-30）。
- **摘要/提纲级**：Gragnaniello 2024（ESWA 255:124783，153 篇 / 17 数据集 / 536 段视频标注）；Khan 2024（EAAI，误报 3.4%–29.49% 等汇总）；Applied Sciences 2025 综述（15:10255）；QUT 2025（Drones 9:827）；CCi-YOLOv8n（arXiv:2411.11011）；TP-UAST（arXiv:2508.14597）；UMIL（CVPR 2023，部分正文）。
- **二手**：NFPA 72 的 17.7.7 / 17.8.5 条款号；Pano AI / ALERTCalifornia / OroraTech / Dryad 的运营数字（厂商或媒体口径）；Hawaiian Electric 约 18 万美元/站的成本基准；GB 50116-2013 第 5.2.7/5.2.8 条条文（经消防产品技术网站转述）。
- **待核查**：FASDD 最终发表状态与许可（ESSD 预印本已 withdrawn）；D-Fire 原始论文出处与许可；DSDF、FLAME2 的规模；"333 FPS"的测试条件；各厂商误报率的分母定义。

**未解决的问题**

1. **场景未知**：本报告覆盖室内、隧道、工业、森林、卫星五类，但未锁定具体场景；选型需按 §1.3 收敛到一个主场景。
2. **无本地数据**：所有数字来自公开来源，未在本机复现；QUT 的 0.721、CCi 的 78.5 等均为他人报告值。
3. **成本未测算**：仅给出 Hawaiian Electric 的单站基准，未做本地方案（边缘 vs 云）的 TCO。
4. **认证路径未评估**：新国标尚未正式实施，过渡期与检测机构排期未知。
5. **"早期"口径未统一**：文献的 time-to-detection 起点多为"首帧可见烟"，不是"点火"，跨系统不可直接比较。

**与本项目的关系边界**

- 仅 §3.4 引用本项目实测数据；其余章节独立成立，不依赖该项目的代码、模型或数据。
- 不将本项目的 relay / 选择器 / 人脸库设计视为火情方案的一部分；只借用"排他匹配的缺陷""分布化时间窗""集合级验收""三态""证据分级"五条方法结论。

## 如果只记三件事

1. **验收看"每路每天误报几次、多久发现"，不看 mAP。**
2. **降误报靠掩膜、时序、多机共识、硬负样本，不靠换更大的模型。**
3. **先做辅助预警，再谈认证；把"看不清"留成第三态，系统才活得下去。**
