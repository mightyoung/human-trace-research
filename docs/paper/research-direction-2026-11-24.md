# 论文研究方向与路线（2026-11-24）

> 输入：① 项目实测（2026-10 至 11，long35 六机位 + E21 三采集日 19 段）；② 附件《多摄像头人员轨迹与跨天身份记忆》研究报告 2.0（2026-11-23，零实测规划版）；③ 已编译的 T-BIOM r2 稿（10 页，`docs/paper/tbiom-r2/`）。

## 0. 结论

**一句话**：报告给的是"把系统做对"的路线，我们已经用实测证明"在这个场景里，报告认为能做对的那几件事做不对"。所以论文不该走"提升跨机位 ReID 精度"，而应走**"给定相机网络与冻结编码器，哪些身份功能可以被合法承诺"**——这正是 r2 在做的事，报告的价值是**补它的外推性短板**。

三条判断：

1. **报告的五张实验卡里，三张（EXP-001/002/005）的目标已被我们的实测否证或大幅削弱**，照单执行会重复我们踩过的坑；只有 EXP-003（可信人脸锚定 → 无脸片段）与我们的主线同向，且我们有报告没有的关键数据：**真实可用脸只占 12.1%**。
2. **r2 的骨架（三探针 → 五档 → 跨采集验收）是对的，且已被数据支撑**，最大短板是**只有单站点**。报告最大的可借用价值不是它的方法路线，而是**公开数据的协议设计**（CHIRLA 的真实日期划分、WILDTRACK 的重叠区计数、DanceTrack 的交汇压测）。**但这两点已有一处被 11-24 的实测修正**：WILDTRACK 上「共视 → 外观可用」不成立（见 §2.5 与 `docs/wildtrack-p2-region-2026-11-24.md`），P2 的断言必须降级为"同时可见"，不能宣称"可匹配"。
3. **唯一有正收益的方法点是"形态条件化模板"**（不用人脸，同机位召回 56.4%→68.2%；叠真实池 69.8%）。它已经作为 L2+ 写进 r2，应该从"附带一档"升级为**有独立消融的方法贡献**。

## 1. 两份材料的对齐（逐条判定）

报告的技术栈假设是 YOLO26-seg + ByteTrack + OSNet，与本项目实际（YOLO8/RF-DETR + 自有跟踪 + OSNet/EmbeddingGemma）不同，且全部未实测。逐条对齐：

| 报告主张 | 我们的实测证据 | 判定 |
|---|---|---|
| 跨镜连续轨迹靠「时间同步 + 拓扑 + 出入口 + 转移时间 + 互斥约束」 | 19 段 / 14 492 轨：时间邻接的唯一候选率只比随机平移高 **+1.8 pt**（30 s 窗）；Δt 直方图无峰；把 A 的事件整体挪后 30 min，1.3 倍超额**不降反升**（人流失同步而非个体转移）；走廊/茶水间**贴边率 0%**，「离开」无法观测 | **否决**（该站点、该类机位） |
| 跨天身份桥 = 可信人脸 + 动态外观记忆 | 机制成立、覆盖不成立：12 min 库可绑率 **0.7%**、全天库 **8.0%**，两侧「有脸原型簇」都占 22% → 卡点是**人没入库**；可用脸仅 **12.1%**（9/48） | **修正**：桥本身对，但"可信脸"是稀缺资源，不能当默认前提 |
| 多外观原型（服装/姿态/机位）写入身份库 | 形态加权（`exp(-|log h比|/0.6)`，**不用人脸**）：同机位选择器召回 56.4%→**68.2%**；叠加真实池 **69.8**（理论上限 92.7） | **采纳并升格**为方法贡献 |
| 簇级人工纠错（must-link / cannot-link） | 人工修正 443→**450**：**只删边拆不开簇**；局部修复不组合（删掉已判错的边没拆开任何组，成对验证器反而删掉 3/5 个已知正确合并） | **修正**：需要"重分组"操作而非"删边" |
| 周期更新 OSNet（SpCL / Cluster Contrast / MMT） | 域内微调否决：机位去均值 .639→.750 但**留出身份 .595/.554**；扩量到 PA 8 万 + PETA 1.6 万，域内**净 ≈0** | **否决**（身份数不够，不是数据量问题） |
| 姿态/步态作为额外判据 | 步态否证：GEI .656、轮廓 .632 vs 外观 **.865**，融合**单调掉点**（λ=0.2 就掉到 .778）；GEI 跨机位 (.670) 反而高于同机位 (.575) → 学到的是**体型**不是步态相位 | **否决** |
| D–S 证据融合 | 未做。报告自己也警告"位置、速度、运动预测共享观测，不能当独立证据重复计数"，我们的位置先验实验正是这条的实证：8 段 ΔR +3.93，但 7 卷 26 组里 **13 同 / 13 异** | **暂缓**（性价比低） |
| 公开数据（CHIRLA / DanceTrack / WILDTRACK / LTCC / DeepChange） | **WILDTRACK 已跑（11-24）**：21 个视角对，共视 0–0.89，跨时刻 AUC 0.350–0.901；共视 vs AUC **r=+0.18/ρ=+0.16**，几何重叠 r=+0.05，区域级 ΔAUC 中位 **+0.04**（11/17 为正）→ **共视不预测可匹配性**。CHIRLA 本地有 3 个序列，但标注 `id` 是**每视角内轨迹号**（seq_001 七视角交集=1），不能做跨视角配对 → 该路线作废 | **部分完成（负结果）**；CHIRLA 需换评测方式 |
| 科研工作台 / RSI / 四道关口 | 未做 | **暂缓**（与论文主线正交，属工程治理） |

## 2. 已经可以写进论文的事实（按证据强度分层）

**第一层：可复现、有对照、能外推为"协议"的**

- 六个编码器/对齐配置下，**跨机位聚合外观全部处于随机水平**（AUC 0.450–0.622，所有置信区间覆盖 0.5）；而唯一**共享区域**的机位对达 **AUC 0.904**。
- ★★★ **归因必须收窄（11-24 修正）**：WILDTRACK 上 21 个视角对、共视 0–0.89，共视与 AUC **r=+0.18**、区域级 ΔAUC 中位 **+0.04** → **共视不预测可匹配性**。因此本站点 0.904 不能归因于共视，只能说"该对同时是几何最接近的一对，两者在本站点无法分离"。P2 只能承诺**同时可见**（时间锚 / 人工裁定入口），不能承诺外观可用。
- ★★★ **像素预算也不能解释跨站点差异（11-24 新增）**：在同一批 WILDTRACK 配对做降质扫描（320→16 px 人物高度），AUC 中位 **0.795→0.732（40 px）**，到 **16 px 才跌到 ~0.6**；40 px 仍远高于随机。**身体外观对像素预算不敏感**，所以本站点 0.45–0.62 的失败不能归因于"人太小"。
  → P1 只能约束**人脸通道**（本站点人脸中位 52 px，低于 60 px 经验分割），**不能**解释跨机位身体外观的失败；后者更可能来自 P3（衣着重复）与室内成像条件。此前"P1 地位上升"的说法作废。
- **P2 的单位是区域而不是机位对**（仍是 r2 的核心增量）：316↔343 与身份**反相关**，318↔320 强正相关，用"机位对"报 AUC 会得出相反结论。
- 属性一致性否决把**已判合并的精度 0.730 → 0.930**，而标注对上的召回**不变（5/34）** → 是"净化"不是"发现"。
- 局部修复不组合；无标签覆盖统计在换天时只动 **0.001**，而共现误合并估计**翻倍** → 验收统计必须带"对变化敏感"的那一个。

**第二层：方法有正收益，但幅度中等**

- 形态条件化模板：56.4%→68.2%（无人脸），叠真实池 69.8%。
- 运行时选择器（人脸触发 → 实时全身池，不进聚类）：因果 τ=.80 下覆盖 53%→73%、同人率 91.8%→94.0%。

**第三层：只能报负结论（但正是"边界"论文的价值）**

- 跨机位出入对产出率为零；跨机位时间/外观/人脸三条路全堵。
- 步态、域内微调、位置先验、单链聚类（8 段假象、7 卷否决）均不可用。
- 轨迹预测不能解交替（框距 0.07 身位；46.5% 失效在轨终点 1 s 内）。

## 3. 论文主线：测量协议（主线）+ 形态模板（方法增量）+ 公开数据（外推）

**主线不变**：r2 的"三探针 → 五档 → 跨采集验收"。它回答的是采购/集成方真正会问的问题，而不是排行榜问题。

**为什么不是另外两条路**：

- *纯方法线*（把跨机位精度做上去）：已被我们自己的六组配置 + 三个人脸/步态/微调实验否证，且报告承认"成熟组件集成通常不是独立算法创新"。
- *系统线*（全链路 + 复核队列）：工程价值高，但创新性弱，报告原文也这么判。**它应该作为产品的落地形态，而不是论文的主张**。

**三个贡献的分工**（改写 r2 的 Contributions）：

| # | 贡献 | 证据 | 现状 |
|---|---|---|---|
| C1 | **可测量性框架**：三个无标签站点探针（P1 人脸像素预算 / P2 区域共视 / P3 服装多样性）→ 五档交付（L0–L3+），每档带验收条件与已知失效模式 | 六配置 AUC 全随机、P2 区域化、换天验收统计不敏感 | r2 已写，10 页 |
| C2 | **形态条件化模板**（L2+）：不依赖人脸，用框高比做模板加权，同机位召回 +11.8 pt | 56.4→68.2、叠池 69.8、48 例留一 | r2 只有一段，需扩成独立消融 |
| C3 | **负结果的边界声明**：跨机位时间/外观/人脸、步态、微调、位置先验在什么条件下失效 | 见 §2 第三层 | 分散在各处，需集中成一节 |

## 4. 路线图

### 阶段 0（已完成，2026-11）

单站点协议成型：long35 六机位 + E21 三采集日 19 段（17 833 轨 / 74 机位小时）；r2 编译 10 页；19 段指标与卡片进控制台（3 849 簇，可标注）。

### 阶段 1（最高优先，1–2 周）：把"单站点"变成"可外推"

这是审稿人唯一会追打的点。做法不是重跑我们的系统，而是**用公开数据检验三个探针是否成立**：

| 探针 | 在哪验 | 具体做法 | 判据 |
|---|---|---|---|
| P1 人脸像素预算 | CHIRLA **不可用**（`id` 是视角内轨迹号）；改用 WILDTRACK 做**合成像素扫描** | 把人裁到 160/96/64/40 px 高再编码，看 AUC 跌破随机的拐点 | 拐点应与我们的 52 px 中位 / 80 px 需求同向 |
| P2 区域共视 | **WILDTRACK 已完成（11-24）** | 地面网格算共同可见区 + 落脚点反投影，区域内/外做 A/B | **已否证**：ΔAUC 中位 +0.04、共视 r=+0.18 → 探针降级为"同时可见" |
| P3 服装多样性 | LTCC / DeepChange（换装、跨月） | 统计同日同性别人群的衣着重复率，看它是否预测"外观簇的纯度上限" | 若能预测 → 探针有普适性 |

**产出**：r2 的 §Probes 增加一节 "External check on public data"，以及一个"哪些结论预期可迁移、哪些不可"的明确表格（r2 摘要已有这句，需要数据支撑）。**P2 的负结果本身要写进去**——它把"共视"从有效性条件改成可用性条件，是审稿人会认的那种收紧。

### 阶段 2（2–3 周）：把 C2 做成方法贡献

- 扩展形态加权的消融：框高比的函数形式（线性 / log / 指数衰减常数）、与姿态（坐/站）的交互、与池规模的交互。
- 与近邻工作对比：在线 ReID 的 gallery 更新、换装 ReID 的服装不变特征。**注意不要碰"跨机位外观"**，那是已被证伪的战场。
- 明确失败边界：可用脸 12.1% 时，端到端只能到 61.5%（不是 79.3%），这个"覆盖率折损"本身是结果。

### 阶段 3（可选，取决于能否拿到第二站点）

跨采集验收：换一栋楼/一个班次，重复三探针，报告"哪些档位仍然成立"。**拿不到就明说**——r2 摘要已经写了 "All boundaries are calibrated on a single site"，把这句话变成经过尝试后的结论，比含糊其辞强。

### 不做（明确划掉，避免反复摇摆）

- 不做跨机位外观/阈值的继续调优（六配置已证随机）
- 不做步态、不做姿态融合
- 不做域内微调 / 周期训练（身份数不够，留出集 .595）
- 不做 D–S 融合（证据不独立，且我们连加权基线都还没赢）
- 不做 RSI/工作台（与论文正交）

## 5. 与报告五张实验卡的映射

| 报告卡片 | 与我们主线的对应 | 建议 |
|---|---|---|
| EXP-001 交汇后接回原身份 | 我们的 ITS 结论：轨迹预测不能解交替；同段 5.5 轨/人、63% 断口 >10 s | **不做**，直接引用我们的负结论作为"为什么这条路难" |
| EXP-002 跨镜连续轨迹 + 聚集去重 | 出入对产出率为零；只有区域共视可用（P2） | **改做**：只做"重叠区同时刻计数"（WILDTRACK 协议），放弃"盲区交接" |
| EXP-003 可信人脸锚定 → 无脸片段 | 与我们 L2+/人脸桥完全同向 | **优先做**，但先报覆盖率现实：可用脸 12.1%、可绑率 0.7–8% |
| EXP-004 相同人工时间的纠错效率 | 443→450、复核队列、按可疑度排序（18 簇 / 0.5%） | **可做**：按风险排序 vs 随机 的等人工分钟对照 |
| EXP-005 周期更新 OSNet | 域内微调否决 | **不做**，作为"为什么不做"的边界写进 C3 |

## 6. 风险与红线

1. **外推性**仍是最大风险，且只能靠阶段 1 缓解。若公开数据上三探针不成立，那 r2 的定位要退到"单站点案例研究"，投刊档次需下调。
2. **人脸合规**：报告强调生物特征用途/授权/存储。r2 已用"人脸只做锚点、不做库"的表述，继续保持；不要新增人脸图库。
3. **误合并污染**：这是我们反复踩的坑（大簇 27.3% 混人）。任何"自动写池"都必须保持关闭（实测上限只 +0.2 pt）。
4. **不要把"复核队列"写成创新**：它是产品形态，不是方法贡献。审稿人会问"这跟主动学习有什么区别"。

## 7. 一句话路线

> 用报告的实验纪律（冻结、对照、独立评测、等预算）来补 r2 的外推性；用 r2 的探针框架去**否证**报告里那些看起来合理但实测不成立的关联手段；把唯一有正收益的"形态模板"做成方法增量。
