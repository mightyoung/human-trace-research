**三条结论及其证据**

1. **覆盖率对换天几乎不敏感，误合翻倍**：22→22 vs 22→23 的 coverage 差 **0.001**，fm 5.2%→10.7%；θ 从 .90 到 2.50 每一档 fm 差都为正。
2. **越贴合自家那天的图库，跨天越崩（单调）**：日内 coverage 0.491 / 0.580 / 0.650 对应跨天衰减 0.001+0.124 / 0.134+0.213 / 0.254+0.267；fm 5.2→10.7+9.8 / 8.8→20.0+36.4 / 7.2→30.0+41.2。
3. **时间间隔不是变量**：22→23（1 天）fm 10.7% 与 22→26（4 天）9.8% 接近，而 26→22（4 天反向）30.0%。

**两处必须先修的口径**

- 共现负例被重复框污染 **6.6–11.1%**（两框 IoU ≥ .3 = 同一人被检测两次）→ 不去掉会让 fm 机械性偏高。
- `2026-10-23_办公区2_te` **不是难例是坏数据**：一条轨 9,510 帧框停在 (896,249)–(973,344) 不动，另一组框位置反复 → 静态假框。该段 cov **1.000** / same **1.000** / fm **100%**，**面板上最健康、图里最坏**。已从 Table 11/12 剔除。

**簇集中度能抓到、但不能全抓**

- 以各图库自家日内为基线：**归一化熵 6/6 跨天全降**；**最大簇占比 5/6 上升**（+3.1 到 +24.9 点）。
