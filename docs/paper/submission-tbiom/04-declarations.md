## 3. Ethics — human subjects data

**Form item:** *Does the study involve human subjects? Provide approval details.*

**Answer:** Yes — video recordings of people in a workplace.

**填写内容：**

- Approval body: [Institution ethics committee / IRB name]
- Approval reference: [Number]
- Date: [YYYY-MM-DD]
- Basis: recordings were made on a client site under a written authorisation covering research use; on-site signage informs individuals of camera operation; no intervention, no physiological measurement, no attempt to identify individuals outside the authorised research team; all reported identities are hypothesis labels assigned by the pipeline, not named persons.
- If no formal ethics approval was required under the institution's policy, state that explicitly and give the policy basis (this is common for workplace CCTV analysis in some jurisdictions, but must be stated, not omitted).

> 这一项如果不填清楚，编辑通常会在初审退回。IEEE 要求遵循《赫尔辛基宣言》相关原则。

## 4. Data availability

**Form item:** *Is the data available? If not, justify.*

**Answer:** Partially — analysis artefacts released, raw media withheld.

**Justification（与 cover letter §4 一致）：**

The raw video, track tables and crops record identifiable individuals on a client site under an authorisation that prohibits redistribution, so they cannot be released. Released with the article as separate supplementary material: the protocol specification, the three probe thresholds and their calibration, the structure and sampling mechanism of both truth sets, the adjudication rules, every result file cited in the article, and the scripts that generate them. Reviewers requiring the underlying media for independent verification may request access under a data-use agreement.

> T-BIOM 的原文要求这句 justification 同时出现在**稿件**与**cover letter**里。两处已写，措辞保持同一套。

---

## 5. Code availability

**Form item:** *Is code available?*

**Answer:** Yes, as documented entry points (Supplementary Appendix S1).

Every experiment is deterministic given the track tables and embeddings; no training is involved. Appendix S1 lists, per experiment, the script path, the configuration, and the result file it produces, together with a mapping file (`EVIDENCE.md`) that ties each number in the article to its source file and command.

> 官方原文接受"不能公开仓库时给完整脚本/伪代码"这一形式。若要更好，可在接收后放一个匿名化的代码仓库（IEEE DataPort 或 figshare）并给 DOI。
