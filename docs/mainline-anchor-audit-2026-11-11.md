## 3. 停止线（判读完成后按此裁决）

**新增口径：侧内混人（`4`/`5`/`6`）**。判读人指出某一侧内部就存在两个不同个体时，
按 4（A 侧）/ 5（B 侧）/ 6（两侧）标记。这类条目从「A vs B 同人率」的**分母里剔除**，
单独报「侧内混人比例」——它衡量的是**簇本身的纯度**，不是人脸匹配的精度。

★ 判 4/5/6 的门槛：能指出具体的两个人（衣着、发型、体型明显不同）。
只是姿态/距离/朝向差异大、拿不准 → 按 `3` 看不清，不要记成混人
（否则会把「同一人换姿势」误记成「簇不纯」，而这恰好是本项目主线论点里的主要现象）。

**簇内纯度的独立证据**（`tmp/full/cluster_purity.py`，9 次合并涉及的 14 个簇、9368 个轨对）：

| 指标 | 值 |
|---|---|
| 簇内 cos 中位范围 | 0.79 – 0.95 |
| 簇内 cos 最小值 | **0.45**（簇 9，41 轨） |
| cos < 0.35 的轨对 | **0 / 9368 = 0%** |

→ 这 14 个簇**没有外观链式塌陷**。若判读仍出现 4/5/6，优先怀疑「同人不同姿态」被看成两个人，
其次才是 average-linkage 把不同人链在一起（当前数据不支持后者）。

- 6 条目标里 0 条异人 → 同人 6/6，通过；
- 1 条异人 → 5/6 = 83%，样本太小，与第 2 步（放宽规则后的新增合并）合并后再定；
- ≥2 条异人 → 停止，先查原因，不进入放宽步骤。
- 正对照若出现「不同人」，先怀疑判读口径（不是算法）。
- 负对照里若 ≥2 条被判同人，说明阈值 0.45 偏紧，这本身要写进结论。
