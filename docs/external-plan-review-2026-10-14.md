## 一、结论先行

1. **文献可信度：通过。** 载重条目（R02 C-RADIOv4、R07 ICSM、R08 Cho 2017、R09 Self-MVA、R11/R12 DeepStream AMC·MV3DT、R14 Dream-RSI、R15 Laya）**全部真实存在，且计划对它们的描述准确、没有把"借鉴"说成"复现"**。这是本项目收到的三份外部意见中**方法学最扎实的一份**（明确区分 `[U]用户意图 / [F]附件自述 / [R]外部来源 / 无标记=建议`，并反复声明"未运行代码、未复验"）。

2. **★ 但它漏掉一个更致命的先例：H2 已经被 2017 年覆盖。** R08（Cho et al., ICCVW 2017）不仅做了"ReID ↔ 拓扑联合迭代 + 在线更新"，其 **§3.2.2 就是 Zone-to-Zone 拓扑**——先自动学出每个相机的 entry/exit zone，再只连 **exit-zone → entry-zone** 并估计转移分布。也就是说计划的 **H2「门户级/出入口级转移优于相机级」在 2017 年已有直接先例**。计划只标了 H1 的先例，**漏标 H2**。→ H2 必须改写为"在**无标签、开放集、强反光/不重叠**条件下"，否则不能作为贡献主张。

3. **计划的基线已过期 1 天。** WP0 要闭环的"字段错配 / 清洗版本 / 图引用"问题，我们 **10-14 已完成**（clean2 重建：实体悬空 88→0、接力缺嵌入 1181→0、C0 0.301/0.286 同口径最高）。因此 **WP0 从"最高优先级"降级为"消费端切换 + splits 重建"的收尾**。

4. **计划自己承认却没解决的那个问题，恰好是本项目主目标的命门。** 它说"本地无独立身份真值，用公开基准做隔离评测"——但公开基准（Market/Duke/WILDTRACK/MVOR/SOLDIERS）**没有玻璃反光、鱼眼、不重叠接力**这些条件，**测不出本项目的价值主张**。所以"在独立真值上证明更少误接/漏接"这条主线，**仍缺可执行方案，需要我们自补**。

5. **已有资产比计划假设的多。** 项目并非从零开始：`docs/selector-intent-report.md` 显示**身份选择器（轨迹级嵌入→无监督聚类→原型库→unknown 拒判）与轨迹意图预测（BERT）两条实验线已在跑**，且已建立"共现负对 F1"这一自监督评价口径（与计划 WP4 的"同帧互斥约束"同源）。计划的 WP3-S0 我们**已推进过半**。

## 四、采纳建议

### 4.1 总体：**采纳**，但改三处

计划的**主课题收敛方向与项目资产顺接**（轨迹级嵌入 + 原型库 + 共现负对 + 接力图 = H1 的直接地基），不是推倒重来。建议采纳，但修订三点：

**(a) H2 重写** — 从"门户级优于相机级"改为：
> 在**无人工标签、开放集、强反光与不重叠**条件下，门户级冷启动相比纯相机级图，能**减少达到固定误接下所需的通行事件数**。

理由：Cho 2017 已做 Zone-to-Zone 且有监督外观（random forest），差异只能来自"无标签 + 开放集 + 我们的困难条件"。

**(b) 把"独立真值最小闭环"前置到 C 之前** — 否则 H1/H2 都不可评价。最小可行方案（成本可控、可先做）：
- 在既有 `candidates_review.csv` 的 318×320 人工 GT 之外，**新增"短窗出入口事件"人工审计**（如 343 电梯间 5–10 分钟连续片段，逐事件标"人/无人 + 跨机位对应"），形成**小而硬**的真值；
- 阈值仍走 val 校准，test 冻结哈希不动。

**(c) 公开基准降级** — 明确写为"**特征空间健全性检查**（编码器有没有崩）"，**不作为价值主张证据**。理由见 §1.4。

### 4.2 取舍

| 方案 | 收益 | 代价 | 建议 |
|---|---|---|---|
| 全盘按计划原文执行（A→B→C→D） | 结构完整、防"多模块同换归因混乱" | WP0 已做仍在做；C 阶段缺真值不可评价 | ❌ 需修订 |
| **采纳框架 + 上述三点修订** | 顺接已有资产、每步可验证 | 需先补真值闭环 | ✅ **推荐** |
| 只做门户发现（WP2），身份主线搁置 | 成本最低、可并行 | 偏离"主目标=更少误接/漏接" | ⚠️ 可作并行支线 |
| 放弃外部计划，沿 clean2 报告既有顺序走 | 最省沟通 | 丢掉计划的文献目录与对照矩阵（这部分质量高） | ❌ 浪费 |

## 五、我建议的下一步（与已有进度条对齐）

1. **WP0 收尾（~1 天）**：5 个消费端切 `stitch_clean2` → 重建 `splits`（键带相机命名空间）并冻结新哈希。**这是后续一切实验的前提。**
