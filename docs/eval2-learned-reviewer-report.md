# EVAL-2：学习式小评审器对照（紧凑版）报告

日期：2026-10-14 ｜ 性质：真实计算（对照实验，**触发预注册失败条件 → 不引入**）｜ 工具：`tools/eval2_learned_reviewer.py`

## 0. 结论

**按预注册失败条件判定为"不引入"。**

| 指标 | 规则基线（EVAL-1） | 学习器（softmax，19×扰动训练） |
|---|---|---|
| 扰动留出集规则复现率 | — | **0.968**（学到规则） |
| 同人集（11）keep | 5 | 6 |
| 同人集 **误拒** | **0** | **2（增加）** |
| 异人集（11）拒绝 | 10 | 10 |
| 异人集误收 | 0 | 0 |
| AUC(P_keep, pos vs neg) | — | 0.793（参考） |

**判定链**：学习器"只复现规则（96.8%）**且**增加误拒（0→2）" → 恰好命中预设失败条件 → **不引入**（保持规则版为唯一评审器；GPT 提议的"先规则、后小模型"在此场景未通过第一轮对照）。

## 1. 方法

- 特征：12 维（sim / w_dt / dt / margin / 门距×2 / overlap / l4_fail / l1_fail / gate_warn / 框高×2，取自 EVAL-1 候选六层快照）；
- 训练样本：2618×20 受控扰动（连续量高斯噪声、类别位 5% 翻转），标签由规则函数自动生成（**不读身份真值**）；
- 真值（55 判）仅用于隔离评测；训练与评测完全分离。

## 2. 局限与下一步

- 样本极小（同人 11/异人 11），结论按此口径成立；学习器以逼近规则为目标，本轮相当于"规则蒸馏"测试——蒸馏失败（增误拒）说明当前特征/容量下无增益空间；
- 若未来升级：先补大样本判读（≥300 对），再试"证据向量 + 校准置信"路线；仍以"不增误拒"为引入门槛。
