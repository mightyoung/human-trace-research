# EVAL-3：门控自训练环（H1 首个可执行实验）报告

日期：2026-10-14 ｜ 性质：真实计算（三臂对照，单次运行）｜ 工具：`tools/eval3_gated_selftrain.py`
产物：`output_crosscam/analysis/eval3/self_train_arms.json`

## 0. 结论速览

| 臂 | 覆盖率(1−unknown) | 分片一致率 | 跨段保持 | 误接代理 | 更新量 |
|---|---|---|---|---|---|
| **A1 冻结检索**（现状） | 52.01% | 0.8971 | 69/107 | 0 | — |
| **A2 朴素更新**（val sim≥0.95 → 每簇均值原型） | 52.59% | **0.8841（↓1.3pp）** | 69/107 | 0 | 111 成员/16 簇 |
| **A3 门控更新**（+margin prec +时间互斥） | 52.59% | **0.8986（最高）** | **70/107** | 0 | 73 成员/10 簇 |

**判定**：**A3 全面 ≥ A1 且 ≥ A2**——门控把朴素更新造成的**分片一致性退化扳回并反超基线**（0.8971→0.8841→0.8986），跨段保持 +1 对。但整体效应量微小（覆盖率 +0.6pp、保持 +0.9%），**不足以宣称系统增益**。
→ **H1 未被否定**：门槛机制的**保护作用（防退化）有首个数字证据**；增益结论需更长数据。

## 1. 实验设定

- 数据：1012 分时段——train（上午 4 段 1395 轨，建库源）→ **val（午间 4 段 238 轨，更新流）** → **test（下午 4 段 348 轨，评测）**；
- 选择器：`selector_v2.npz`（412 子原型/125 簇，per-cam 阈值 r80 margin：305 0.0039 / 318 0.0114 / 320 0.0228 / 323 0.0050）；
- 三臂：A1 不动 / A2 朴素（sim≥0.95） / A3 门控（sim≥0.95 ∧ margin="prec" 精度门 ∧ 同簇成员跨机位时间重叠>2s 整对剔除，318×320 豁免）；
- 更新方式：被接受成员按簇取均值原型入库（≥3 成员才更新；无新簇）；
- 评测（标签无关、跨臂固定对集）：① 覆盖率；② 分片一致率（同轨 a/b 半向量同簇）；③ 跨段保持（test↔train 互近邻 sim≥0.90，107 对）；④ 误接代理（同簇且时间不可共存的 test 轨对）；另报"公共子集"（三臂皆已分配的 181 轨）上的同覆盖对照。

## 2. 关键读数与解释

1. **门控的作用点 = "剔除有害更新"**：margin 精度门把 val 候选从 111 削到 73（−34%）、更新簇 16→10；被剔除的 38 个边缘成员正是朴素臂一致性退化的来源（0.8971→0.8841）。时间互斥过滤本轮裁掉 0 条（val 体量小、冲突稀有）。
2. **增益幅度**：覆盖率 +2 条 test 轨（348 中）；保持 +1 对（107 中）；一致率 A3 比 A2 +1.45pp。**单次实验、单场景**——量级小，需重复与更长 val 流验证。
3. **预注册失败条件**：为"同覆盖下误接代理不优于 A2 → H1 不成立"。本轮误接代理三臂全 0（含公共子集）→ 判据无法分辨（地板效应）；按二级指标（保持/一致率）A3 优于 A2 → **未触发失败条件**。
4. **与 10-12 历史实验（DINOv3 +0.048）的关系**：本实验在**生产选择器 v2** 与**无标签指标**上重做 H1 第一步，效应远小——说明历史增益可能依赖特定编码器/数据；建议以此设定为后续自训练的**标准试炼场**。

## 3. 建议

- **机制保留**：门控更新默认可开（或保守门槛），因其"防退化"证据（一致率）好于冻结与朴素；但**不建议**现在把"自训练增益"写入任何对外结论；
- **下一步增强（按性价比）**：① 更新流扩大到 val+test 相邻时段或 long35 段（更多成员、时间互斥过滤才有用武之地）；② 增加"忘记/漂移"监控（月度重算基线与历史保持率对比）；③ 对 margin 门做保留率扫描（r80 vs r90）看趋势。
- 纪律：本实验只读既有产物；若把门控更新接入生产身份层，需按发布门槛单独立项（评测协议 §6）。

## 4. 局限

- 单日三时段、单场景；retention 对集为伪 GT（互近邻协议）；误接代理只覆盖"时间不可共存"型错误（对 sim 型误合不敏感）；配对了 margin 的阈值来自既有 r80 校准，未做二次调参。
