## 2. 门户候选生成（WP2，**设计就绪，未运行**）

### 2.1 两条原料

| 原料 | 方法 | 现成路径 |
|---|---|---|
| **语义候选** | C-RADIOv4 替换 SAM3 vision encoder（`sam3-radio` 路径），或独立开放词表分割；提示词覆盖"门/门框/走廊开口/通道" | R01/R02；本地可先在少量关键帧试 |
| **轨迹候选** | 长窗轨迹**起终点**、稳定穿越、运动方向、暂时遮挡、画面边界 | `tools/portal_truth_candidates.py`（**已产出 316/343 事件表 + 缩略图**） |

### 2.2 关键区分（否则语义无用）

- **门板/门框** = 视觉物体；**走廊开口/通道/画面边缘** = 候选转换位置；**真实人员经常穿越的区域** = 功能性门户；
- 一个**没有实体门的走廊口**可能是重要门户；一扇**长期关闭的门**不形成通行关系；**遮挡边缘**造成的轨迹消失**不能**当出口（TG-01）。

### 2.3 四组对照（外部计划 WP2 第四步）

| 组 | 输入 | 回答 |
|---|---|---|
| G1 | 纯轨迹 | 只靠出入事件能定多少门户 |
| G2 | 纯语义 | 分割候选的召回/精确 |
| G3 | 融合 | 语义定位 + 轨迹验证是否优于任一单源 |
| G4 | 融合 + 几何 | 有可信几何时是否进一步降误报 |

★ 频率：**低频生成静态门户地图**，仅在机位移动/场景变化/证据矛盾时重算——**不每帧跑大分割网**。
★ 输出字段：`portal_id / 候选区域或跨越线 / 方向 / 置信度 / 支持事件 / 不可判原因 / 版本`。

## 4. 图边状态机（TG-10）

```
candidate ──留出时段支持──> active ──无明显流量──> dormant
    │                          │
    └──持续违例/冲突──────────> suspect ──证据确凿──> 移除(留审计)
```

| 状态 | 准入 | 退出 |
|---|---|---|
| `candidate` | 冷启动高可信证据（**不依赖已学拓扑**） | 留出验证通过 → active |
| `active` | 留出时段支持 + 有效样本 ≥ 阈 | 无流量 → dormant；违例 → suspect |
| `suspect` | 冲突证据 | 复验通过 → active；否则移除 |
| `dormant` | 旧边暂时无人通行 | **降置信/休眠，不立即判为不存在**（TG-06） |

每条边记录：**转移时间分布 / 有效样本量 / 置信度 / 证据窗口 / 状态**。

## 5. 更新规则（防"错误 ReID ↔ 错误拓扑"闭环）

| 规则 | 内容 |
|---|---|
| TG-05 留出验证 | 新边须在**未参与建图**的时段检验；**同批候选不能自证** |
| TG-08 防闭环 | 保留少量**未选边的独立探索/审计通道**，防止早期错误图永久屏蔽真通路 |
| TG-07 变化归因 | 机位移动 / 时钟变化 / 通行习惯变化**分别诊断**，不把一切异常当归拓扑漂移 |
| TG-04 统计 | 考虑重复检验、时间相关性、多重比较、事件覆盖；**更长录像不自动满足功效** |
| ★ 禁止 | **不能用同一批已接受的关联，同时训练模型、更新图、又证明二者正确** |

**更新调度**：周期评估（低频）＋ 变化触发（背景改变/轨迹分布变化/时钟异常/持续违例）。

## 6. H2 对照设计（**未做**）

**假设（改写后）**：
> 在**无人工标签、开放集、强反光与不重叠**条件下，门户级冷启动相比纯相机级图，能**减少达到固定误接下所需的通行事件数**。

**为什么必须改写**：Cho et al. 2017（R08）**已做** Zone-to-Zone 门户级转移 + 在线更新拓扑（且有监督外观 random forest）。差异只能来自"无标签 + 开放集 + 本场景困难条件"。

**对照**：纯边界 / 纯轨迹 / 纯语义 / 融合（+ 有条件几何）；**度量** = 达到固定误接约束所需的**有效通行事件数**、正确接续率、漏接、交接延迟。

**真值来源**：`analysis/truth/pair_candidates.csv`（跨机配对候选，时间门 + relay v5 证据）→ 人工判定"是否同一人"。
