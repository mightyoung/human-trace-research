## 二、规则卡：聚类 / 身份（CQ）

> 结构：`适用前提 → 观测输入 → 判定规则 → **禁止推断** → 缺数据状态 → 建议动作 → 宿主边界`。
> 阈值来源：项目 val 校准（**非**文献阈值直搬）。

| ID | 主题 | 适用前提 / 输入 | 判定规则 | **禁止推断** | 缺数据状态 | 建议动作 |
|---|---|---|---|---|---|---|
| **CQ-01** | 输入质量与同步 | 模糊/遮挡/碎片/同步误差/版本 | 质量分数低于阈 → 隔离 | 隔离 ≠ 不同人；质量差 ≠ 身份不同 | 无质量分 → 保守降权 | 隔离样本（**保留原始观测**，不删身份） |
| **CQ-02** | 几何分离/紧密度 | 嵌入 + 簇标签 | silhouette / CH / DB 比较表示与超参 | **分数高 ≠ 身份纯度高** | 单簇 → 不适用 | 仅用于超参比较，不作合并依据 |
| **CQ-03** | 密度结构/离群 | 嵌入 | DBCV；监控离群比例 | **不能靠丢难样本刷分** | — | 提名可疑簇 |
| **CQ-04** | 稳定性 | 重采样/扰动/跨窗重聚类 | 多次扰动后簇成员一致性 | **稳定 ≠ 正确** | — | 不稳定 → 延缓更新 |
| **CQ-05** | 跨相机多原型 | 嵌入 + 相机标签 | 识别"视角分裂/相机偏置" | **不强制每簇跨多机** | 单机簇 → 允许 | 补 hard 原型（PCLHD 式） |
| **CQ-06** | 真实同帧互斥 | 同一画面多目标 | 同帧已确认为两个真人 → cannot-link | ★ **跨机位同时出现不是互斥**；先排除重复框/反光伪目标 | 同帧身份未定 → 不用 | 拒绝不可能合并 |
| **CQ-07** | 可靠跨视共见 | 重叠机位 + 同步 | 独立几何支持的对应 → 候选正约束 | 错同步/遮挡会使约束失效 | 无重叠 → 不适用 | 形成候选正约束 |
| **CQ-08** | 跨版本簇谱系 | 历次聚类结果 | 记录 merge/split 与成员变化 | **簇编号变 ≠ 真人变** | — | 保留 lineage |
| **CQ-09** | 伪标签选择 | 高可靠片段内一致性 | 逐步纳入、显式处理未聚类实例 | **不把自训练输出当独立真值** | — | 分批纳伪标签 |
| **CQ-10** | 相机条件化校准 | 嵌入 + 相机 + 组内 pos_p5/cooc_p99 | **全局聚类 + per-camera thr**（本项目方案 F） | **分组/隔离 ≠ 更好**（已实测反证） | 组内样本少 → 回退全局 thr | 校准 thr，不分区 |
| **CQ-11** | 换装分裂 | 跨日同一人 | 长期身份单列难度检验 | 不能以同日成绩代替长期 | 无跨日数据 → 声明缺 | 单列评测集 |
| **CQ-12** | 编码版本兼容 | 模型/向量版本 | 受控重编码 / 验证对齐 / 双版本 | ★ **不直接比较不同特征空间的余弦** | 版本不明 → 拒判 | 原型库+索引随模型一起发布 |

**已实测支撑（CQ-10）**：全局聚类 + 按机 thr 校准 → 320 球机覆盖率 **0%→46.4%**、身份保持 **0.941 持平全局**（n=68）；物理隔离分组则 keep **0.875 < 0.931** 且跨机 ID 不可通约。见 `docs/camgroup-selector-study.md`。

## 三、规则卡：门户 / 拓扑（TG）

| ID | 主题 | 适用前提 | 判定规则 | **禁止推断** | 建议动作 |
|---|---|---|---|---|---|
| **TG-01** | 门户需行为支持 | 固定机位 | 语义提名（门/门框/开口）后，**以轨迹穿越确认** | **门板分割 ≠ 可通行**；遮挡边缘 ≠ 出口 | 语义仅定位/解释 |
| **TG-02** | 三类关系分开 | — | 视觉重叠图 / 门户转移图 / 物理可达图**独立维护** | 观测先后 ≠ 物理邻接 | 分别保留不确定度 |
| **TG-03** | 时间误差传播 | 各机位时钟模型 | 匹配时窗携带时钟不确定度 | 不把通行时长拿来强行校时 | 扩大不确定度而非编造对齐 |
| **TG-04** | 有效样本与统计 | 事件 + 有序机位对 | 置换检验 + 多重比较校正 + 时间相关性 | **数小时录像不自动满足功效** | 报告有效事件数 |
| **TG-05** | 留出验证 | 建图窗口 | 新边在**未参与建图**的时段检验 | 同批候选不能自证 | 未通过 → candidate |
| **TG-06** | 旧边无流量 | 现有图 | 先降置信/休眠 | **无观测 ≠ 断路** | dormant，不删 |
| **TG-07** | 变化归因 | 异常检测 | 分离机位移动 / 时钟变化 / 通行习惯 | 不把一切异常当归拓扑漂移 | 分类触发检查 |
| **TG-08** | 防闭环锁定 | 更新流程 | 保留少量**未选边的独立探索/审计通道** | 不能永远只查旧图允许的边 | 强制探索采样 |
| **TG-08b** | 选择性反馈偏差 | 预算内主动采样 | 只把打分器 Top-K 送人工/外部评估时，**必须并行保留随机 audit 抽样** | ★ **反馈是经选择获得的，不能证明未观测区域的可靠性**（R19 原文论点） | 未选样本按比例随机审计 |
| **TG-09** | 更新影响面 | 图版本 | 重放关联、计数、延迟、原型污染 | 图更稀疏 ≠ 更准 | 多指标联合评估 |
| **TG-10** | 分版本发布 | — | candidate→active→suspect→dormant 状态机；影子→发布/回滚 | **Agent 解释不是发布证据** | 程序化门控 |

**已实测支撑**：拓扑显著性（实体级 + ≤5~10s 窄窗 + 30 对族校正）→ 316→318 **z=6.45**、343→323 **z=4.90**、343→316 **z=4.71**（p=0.001）。★ 注意：`topology_signature.py` 默认 `--dmax 60` 会淹没秒级信号，**必须用窄窗**。

## 五、规则注入路径（防"把文献阈值当生产规则"）

```
原文摘取 → 保留前提的规则解释 → 可计算规范 → 反例测试 → 版本化登记 → 运行时检索 / 小模型训练
```

- 小模型学的是"**给定证据应采取哪个有限动作**"（retain / quarantine / propose_split / propose_merge / defer），**不是**从文字规则里凭空学会视觉身份真相；
- 先建**确定性规则基线**，再比树模型/MLP，最后才比 Laya 类小语言模型；若文本规则已可精确计算，**没有必要**训练模型重复近似它；
- 公开基准身份标签**仅用于隔离评测**，不得反向用于规则选择或模型训练。
