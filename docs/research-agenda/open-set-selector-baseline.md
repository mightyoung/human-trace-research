## 2. 数据单位（关键设计选择）

- 聚类对象 = **轨迹片段及其代表特征**，**不是所有视频帧**；
- ★ 避免"同一个久坐人员的大量近重复帧成为压倒他人的海量样本"；
- 每个身份保留**多视角/多时段/多质量**的**多个原型**，而非单一均值。

数据源（1012 全链）：12 段 6h → 检测（323 dualclean，其余 raw）→ a/b 分片独立编码 → `embed_server` 24 任务（28296 crops）→
`analysis/cradio_1012_emb/`（24 npz，键=轨迹数**零误差**）/ `analysis/1012_final/`（分片 jsonl）。

## 4. 相机条件化：正确用法 = 校准，不是隔离（【已完成】）

外部计划隐含"相机结构辅助而非空间隔离"。本项目用**两个独立实验**给出实测证据：

| 实验 | 结论 | 数字 |
|---|---|---|
| 选择器（`docs/camgroup-selector-study.md`） | 硬隔离分组**更差** | 公平子集 keep：全局 **0.931** vs 分组 **0.875**；跨机 ID **不可通约**（拼接后 keep=0） |
| 选择器（方案 F） | **全局聚类 + per-camera thr 校准零损失回收** | 320 覆盖率 **0%→46.4%**；身份保持 **0.941 = 全局**（n=68） |
| 意图（`docs/intent-camgroup-study.md`） | 分组**无系统收益** | 318/323 微胜(+0.03/+0.04)，305 败(-0.12)，320 崩溃(-0.32) |

**方案 F 阈值（val 校准，组内 pos_p5 与 cooc_p99 中点）**：
`305→0.9585 · 318→0.9608 · 320→0.9331 · 323→0.9751`（全局原阈值 **0.9651**）

★ 落地成本：`selector.npz` 增 `thr_unknown_per_cam` 字段 + `predict(v, cam)` 支持（半天内，可回归）。

**文献一致性**：CAP / CBN / Intra-Inter / MGH **无一**采用隔离空间，全部是"结构辅助统一空间"。

## 5. S1 受约束伪标签（部分完成）

外部计划的 S1 = "可靠片段内一致性 + 可证实的真实同帧互斥 + 独立重叠几何"筛选伪标签。本项目已有：

| 证据类型 | 现状 | 前提（必须成立，否则失效） |
|---|---|---|
| 可靠片段内一致性 | 已用"共现负对 F1"做自监督口径 | 跟踪器可能串号 |
| 真实同帧互斥（cannot-link） | 已有共现关系（同帧多人） | ★ **须先排除重复框/反光伪目标**；**跨机位共见不是互斥** |
| 独立重叠几何 | 318×320 真重叠 + shift=+20 帧 精对齐（r=0.788） | 错同步/遮挡会使约束失效 |

**S1 未做**：尚未把这些约束组装成"伪标签筛选器"并跑多轮。

## 7. 对照矩阵（H1）

| 实验 | 配置 | 回答 |
|---|---|---|
| **E0** | 固定输入/编码器，**不自训练** | 可复现基础效果与错误分布（≈本文件 S0） |
| **E1** | E0 + **原型库维护**（不更新编码器） | 身份选择器是否已带来收益 |
| **E2** | E1 + 伪标签自训练；**有/无证据门控成对** | 门控是否控制错误放大；参数训练是否必要 |
| **E6** | 多轮时间顺序回放：冻结 / 更新原型 / 更新模型 | 长期收益、遗忘、新人接纳、换装、恢复 |

★ **验收看的是"固定误接下的正确接续/漏接/拒判/延迟"，不是簇指标**（CQ-10 / 协议 §6）。
★ **禁止**把 E1/E2 的收益混成"一个大版本提升"，否则无法归因。
