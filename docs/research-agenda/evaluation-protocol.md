# 评测协议（Evaluation Protocol）

日期：2026-10-14 ｜ 配套：`research-charter.md` ｜ 性质：**冻结协议**（变更须记录版本与理由）

---

## 0. 目的

把"更少误接、更少漏接、且不误删真人"变成**可复算、可追溯、不可自证**的评测，防止：
① 用同一批数据既训练又验证；② 把内部一致性指标冒充真实身份准确率；③ 靠拒判一切刷高"准确率"。

---

## 1. 数据三线纪律（铁律）

| 项 | 规则 |
|---|---|
| 口径 | 实验一律 **`DET_VIEW=clean2`**（`tools/det_view.py` 为唯一入口）；实体图一律 `analysis/stitch_clean2/` |
| 划分 | `output_crosscam/analysis/splits_v5.json`（实体粒度三集划分） |
| 冻结 | test 轨冻结哈希 **`c5575282f4ed4b1b`**；`frozen_test_tracks_sha1_16=18088a2841fe2133`；`frozen_splits_sha1_16=20e0e23b24c6ee9f` |
| 绑定 | `splits_v5` 已显式绑 `det_view=clean2` + `net_dir=stitch_clean2` + 六路 `net_md5` |
| 阈值 | **一律 val 校准**；test 冻结不得触碰；新增数据须**重建**划分并重记哈希 |
| 声明 | 每个实验**先声明**用的是哪份 splits / 哪个 view / 哪个 tag |

**旧口径作废**：`splits_v3`（test 98 轨）与 `splits_v4` 自称 clean 实为 v1；凡引用 v3/v4 数字的结论**须重跑或标注为旧口径**。C0 的 v3=0.291/v4=0.261 因存在悬空引用，**主口径统一到 v5**。

## 2. 时间切分规则

- **按时间与源录像划分**，**禁止**随机分割相邻裁剪帧（近重复帧会泄漏）。
- **按时间顺序回放**：只允许"过去窗口训练 → 随后窗口验证 → 更后窗口评测"。
- **不独立的数据对**：
  - `long-35min` ⊇ `synced-10min` 前 1200 帧（**逐帧签名一致**）→ 二者**不得互当独立测试集**；
  - `1012` 工作日与 `multi-cemra` 的 323 是**同摄像头同视角** → 1012 是**同场景跨时段**（利于"跨时段冻结"），**不构成跨场地泛化证据**。
- 分段防泄漏（1012 口径）：12 段 6h = train 上午 4×60min / val 午间 4×15min / test 下午 4×15min（**段级**隔离）。
- 工作日数据缺机位（1012 缺 316/343）→ 比较须在**相同覆盖范围**内进行。

## 3. 独立真值（本项目的地基）

### 3.1 已存在的真值

| 真值 | 内容 | 规模 | 产物 |
|---|---|---|---|
| **318×320 重叠对 GT** | 人工确认的同人跨机对 | **8 对 CONF**（+1 MODERATE 待决 318#128↔320#21）+ 22 负对 | `analysis/candidates_review.csv` |
| **316/343 短窗出入口事件** | 事件级（entry/exit/at_start/at_end）+ 跨机配对候选 + 缩略图 | `events_316.csv` 27+ 事件、`events_343.csv`、`pair_candidates.csv` | `analysis/truth/`（**待人工判定**） |

### 3.2 判读规则（`analysis/truth/README.md`）

- 人工只需判定"**这两个事件是否同一人**"→ 直接得**误接（假阳）/漏接（假阴）**分子分母；
- `at_start` / `at_end`（贴窗口边界）**不计入分母**——不可判原因必须显式保留，不能静默丢弃。

### 3.3 真值隔离

- 公开基准（Market/Duke/WILDTRACK/MVOR/SOLDIERS）**不含**玻璃反光/鱼眼/不重叠接力 → 只能作**编码器健全性检查**（特征有没有崩），**不作为价值主张证据**；
- 公开基准标签**仅隔离评测，绝不入训练**；本地无标注运行保持，报告时**分别**给出"外部基准身份准确率"与"本地冲突/稳定性/覆盖代理量"。

## 4. 指标定义

| 指标 | 定义 | 说明 |
|---|---|---|
| **误接率 (FPR)** | 被判同人但实为异人 / 全部异人对 | 主约束指标，**优先控制** |
| **漏接率 (FNR)** | 被判异人/拒判但实为同人 / 全部同人对 | 与误接成对报告 |
| **拒判率** | 输出 unknown 的比例 | **不得靠拒判刷分**：覆盖率必须同列 |
| **覆盖率** | 有明确身份判定的比例 | 与误接/漏接联列 |
| **交接延迟** | 目标离场 → 新机位确认的 dt（秒） | 用于 H3 |
| **人数误差** | 区域在场人数估计 vs 真值 | 分层：①多画面去重可见人数 ②区域在场（含盲区）③时间窗累计独立访客 |
| **C0 覆盖率（无深度基线）** | 出门连续性 / 进门归属率 | v5：**0.301 / 0.286**（47 边/32 链，悬空 0） |
| 内部一致性（**代理量**） | 共现负对 F1、跨段保持率、AUC | **必须标注为代理量**，不得称真实准确率 |

**已知代理量基线（供对照，非真值）**：选择器 AUC 0.9942；test known-restricted same 0.857 / coll 0.033 / cov 0.503；跨段保持 89.0%；C0-A 重叠对复算 AUC **0.994318**（8 正/22 负）。

## 5. 样本量与统计

- ★ **同一真人不得因不同片段 ID 被算成独立样本**；置信区间与显著性**按访问事件/独立时段/场景成组**，不按近重复帧计算虚高 n。
- 拓扑类检验：置换检验（环形移位置换零模型，≥600 次）+ **多重比较校正**（30 有序机位对族）+ 时间相关性处理。
- 排队/吞吐类：与算法指标**分开报告**（容量 vs 泛化）。

## 6. 发布门槛与失败条件（预注册）

| 门槛 | 规则 |
|---|---|
| 主约束 | 在**固定误接容忍度**下比较正确接续/漏接/交接延迟；**误接上升即拒绝上线** |
| 拒判 | 覆盖率不得显著下降（仅靠拒判更多 → 不构成提升） |
| 冲突 | 检测到样本不足或指标冲突 → **保留旧版本**或进入受限影子运行 |
| 回滚 | 全流程可回滚；旧模型锚点 + 历史回放控制漂移，但不成为禁止适应的教条 |
| 不得设置 | 未经业务讨论的通用"0.9 相似度即可合并" |

**失败条件示例**：H1 若无门控 vs 有门控在**同覆盖率**下误接无改善 → H1 不成立；H3 若加预测后误接上升 → 拒绝上线。

## 8. 容量验收 vs 算法泛化（分开报告）

- **容量**：完整解码/检测/裁剪/编码/关联/发布链路的**尾延迟与吞吐**；测断流、重连、乱序、机位移动、局部故障。复制单路数据可做**容量压测**。
- **泛化**：**不得**据复制数据声称"16 个真实机位的拓扑与身份有效"；现有仅 6 路，**无 8 路数据** → 泛化结论只能靠公开基准（限健全性）或新场地。
