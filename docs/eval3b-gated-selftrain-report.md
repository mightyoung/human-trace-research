## 0. 结论速览

1. **复现校验 3/3 逐位一致**（A1/A2/A3 vs eval3 原产物，Δ=0）——实验口径可信。
2. **错误积累在流式场景首次显形（关键新结果）**：val 按时间四等分逐轮更新（轮内分类用**上一轮更新后的选择器**，真自训练环）——
   - 朴素流式：ab_same 0.8971 → 0.8986(r2) → **0.8768(r3, −2.0pp)** → 0.8768(r4)，**3 条 test 轨被换簇且不可逆**；
   - 门控流式（p30）：0.8971 → 0.8986 → **0.8986 → 0.8986（全程稳定）**，churn=0，保持 70/107。
3. **根因定位（诊断实锤）**：r3 时 2 个**低 margin 成员**（边界清晰度 m=0.00045 / 0.00161，低于 p10 阈值 0.00179）进入簇 55 → 簇 55 由于攒够 ≥3 成员被更新 → 新原型**劫持** 3 条本属簇 59/51 的 test 轨迹（`323_test_527#58/#87: 59→55`、`#120: 51→55`）。**更新只增不删 → 伤害不可自愈**（r4 保持）。
4. **margin 门扫描（流式）**：p30 / p20 / p15 / p10 四档**全部稳定**（0.8986、churn=0）——四档都能拦下元凶成员（其 margin 远低于任何档位阈值）。结论：**防退化对门档不敏感，维持生产 p30 即可**，无理由放松。
5. **遗忘监控**：出现的是「**身份换簇**」型恶化（naive 3 条），**没有**「已识别→unknown」型遗忘（ret_both_unknown 两臂均 15 不变）。漂移指标（新原型 vs 簇质心 cos 中位 0.986–0.992）**不区分**好坏更新——伤害机制是**对邻近簇的竞争**，不是原型大幅漂移。
6. **对 H1 的定位**：门控「抑制错误放大」获得**方向性支持 +首个不可逆伤害的实证案例**；但效应量仍小（3 条轨/348）、单日单场景 → **继续不得宣称系统增益**；建议：门控更新作默认可开（防退化证据 +），并**新增「坏原型退役/回滚」监控**（本实验证明系统无自愈）。

## 1. 实验设定

| 项 | 值 |
|---|---|
| 数据 | 1012 分时段：train（4 段 1395 轨，建库源）→ val（4 段 238 轨，更新流）→ test（4 段 348 轨，评测）；口径与 eval3 完全一致 |
| 选择器 | `selector_v2.npz`（412 子原型/125 簇） |
| 流式切分 | val 按帧中点四等分（跨机位同步）：每轮约 60–70 轨（实测 69/62/61/46） |
| 轮内分类器 | 第 r 轮用**第 r−1 轮更新后的**选择器（自训练环）；第 1 轮用冻结基线 |
| 接受规则 | 朴素：sim≥0.95；门控：sim≥0.95 ∧ margin(p30, per-cam) ∧ 时间互斥过滤（318×320 豁免）；簇 ≥3 成员才更新（追加均值子原型） |
| margin 扫描档 | p30(r70，生产) / p20(r80) / p15(r85) / p10(r90)——校准复刻自 build_selector_v2 同池同法（p30 与生产值逐位一致：305 0.003937 / 318 0.011351 / 320 0.022835 / 323 0.004953） |
| 评测 | test 上：unknown / ab_same / 跨段保持（107 对）/ 误接代理 viol + 公共子集（181 轨，各臂 viol 全 0） |

## 2. 结果

### 2.1 臂汇总（test 终态）

| 臂 | unknown | ab_same | 跨段保持 | viol |
|---|---|---|---|---|
| A1 冻结 | 0.4799 | 0.8971 | 69/107 | 0 |
| A2 朴素单次（=eval3） | 0.4741 | 0.8841 | 69/107 | 0 |
| A3 门控单次（=eval3） | 0.4741 | 0.8986 | 70/107 | 0 |
| **R2 朴素流式（4 轮）** | 0.4770 | **0.8768** | 69/107 | 0 |
| **R2 门控流式（p30）** | 0.4770 | **0.8986** | **70/107** | 0 |
| RR 门控流式（p20 / p15 / p10） | 0.4770 | 0.8986（三档同） | 70/107 | 0 |

读法：**流式把朴素单次的 −1.3pp 退化放大到 −2.0pp，并出现 3 条不可逆换簇**；门控在两对场景（单次/流式）× 四档全稳。

### 2.2 逐轮轨迹

| 轮 | 朴素：接受/更新簇 | 朴素 ab | 朴素 churn | 门控：接受/更新簇 | 门控 ab | 门控 churn |
|---|---|---|---|---|---|---|
| r1 | 33 / 4 | 0.8971 | 0 | 18 / 1 | 0.8971 | 0 |
| r2 | 28 / 6 | 0.8986 | +1 转已知 | 20 / 5 | 0.8986 | +1 转已知 |
| r3 | 32 / 3 | **0.8768** | **3 换簇** | 23 / 2 | 0.8986 | 0 |
| r4 | 25 / 2 | 0.8768 | 3 换簇（不恢复） | 19 / 1 | 0.8986 | 0 |

### 2.3 根因诊断（`323_test_527` 三条被劫持轨）

```
r3 朴素接受集 − p10 门控接受集 = 4 个成员（全为 323_val_538 低 margin）：
  #84  簇55 sim=0.9946 margin=0.00045（p10 阈值 0.00179）
  #90  簇55 sim=0.9939 margin=0.00161
  #69  簇61 sim=0.9849 margin=0.00092；#102 簇64 sim=0.9801 margin=0.00034
→ 簇55 凑到 3 成员被更新（p10 门控下只剩 1 个，不更新）
→ 更新后：323_test_527#58/#87  59 → 55；#120  51 → 55（3 条换簇，ab_same −2.0pp）
→ r4 保持（原型只增不删，无自愈）
```

### 2.4 margin 扫描（单次 vs 流式）

| 档 | 单次：接受/更新簇 | 单次 ab | 流式 ab |
|---|---|---|---|
| p30 | 73 / 10 | 0.8986 | 0.8986 |
| p20 | 89 / 12 | 0.8986 | 0.8986 |
| p15 | 95 / 13 | 0.8986 | 0.8986 |
| p10 | 101 / 14 | 0.8986 | 0.8986 |

→ **单次模式下所有档位无差异；流式模式下四档同样全稳**。更松的门（含 r90）也没有受害——但**没有证据支持放松**（成员更多 ≠ 更好），维持 p30。

## 3. 建议

1. **门控更新（p30）可作为默认安全档**——它是三组实验中唯一"从不劣于冻结"的更新策略（单次 +0.15pp、流式 0 退化、churn=0）；「防退化」证据已从单次扩展到流式 4 轮。
2. **新增坏原型退役/回滚监控**：本实验证明错误原型**不可自愈**——建议在更新的部署形态里加：更新入库后监测「被新原型抢走指派的既有轨迹」计数（本实验的 churn 指标），超阈值告警/回滚该原型（配合既有 shadow 影子发布机制）。
3. **下一级增强（未做，按性价比）**：更新流扩到 long35 段（跨 session）；margin 校准换成"更新候选同分布"（当前沿用建库池）；把 churn 阈值写进发布门槛。
4. **纪律**：只读实验；未接任何生产；若把门控更新接入生产身份层，按评测协议 §6 单独立项。

## 4. 局限

- 单日三时段、单场景；每轮 ~60 轨；效应量小（3 条换簇即 −2.0pp，属小样本敏感）；
- viol 指标两臂恒 0（该数据上无区分度，与 eval3 相同）；
- margin 扫描仅四档；漂移指标未区分伤害来源（用 churn 替代有效）。
