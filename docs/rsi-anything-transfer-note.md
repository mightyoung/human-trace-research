## 0. 一句话结论

**框架可借鉴、模型不可迁移。** 论文解决的是"**外部反馈昂贵时，如何用预测器决定把有限反馈花在哪个候选上**"——这与我们"**人工真值极贵、只能判少量配对**"的处境同构。其中**三条设计**（预算对齐对照、双组件+兼容性检查、选择性反馈偏差的自省）值得直接吸收；但它的"世界模型"在本项目**没有可用监督**，绝不能替代人工真值。

## 2. 机制：它在做什么

**循环**：`Propose → Predict → Select → Evaluate → Learn → Retain`

1. **预测式选择**：策略提出若干候选（代码修复=每轮 4 个补丁），世界模型预测每个候选的结果，**只把最可能成功的那个送去外部评估**。
2. **条件式世界模型适配**：只有当**可靠性检查**显示预测器已漂移、且数据与预算允许时才适配——不是每轮都改。
3. **★ 保留判据（核心创新）**：**组件检查**评判策略/模型各自是否合格；**兼容性检查**评判**装配后的策略—模型对**；两者都过才保留新对，否则**继续用当前对**。策略与模型可按**不同时间表**更新。
4. **版本控制式工程**：run 记录 `state.json/summary.json` + **每阶段输出哈希**；`resume` 要求**同 recipe + 同 source identity**；失败产物移入 `attempts/`；文件锁防止双 runner 抢占；SHA256 清单 + 校验脚本。

**关键消融（code repair，编码器固定）**：

| 设置 | 隐藏测试通过率 | 在线测试调用/任务 | 排序准确率 | Brier |
|---|---|---|---|---|
| 容量匹配的**静态验证器** | 26.3% | 3.72 | 66.5% | 0.488 |
| **固定世界模型**做选择 | **29.2%**（+2.83pp，95% CI [+0.17,+5.50]） | 3.71 | **72.8%** | **0.358** |
| 世界模型**再适配** | **31.2%** | 3.72 | — | — |

→ **同等反馈预算下**，"用学习的打分器排序"比"静态规则"好，"打分器自适应"再好一档。其他域：GUI 51%→79%→99%（动作数 −39.4%）；LabHorizon F200 五个版本 21.80%→46.01%；Suzuki 反应 40 次实验预算下 96.15% vs 贝叶斯 82.16%。

**它自己指出的两个要害**：
- 原文（二手转述）：*"由于反馈是**经选择获得**的，因此它**无法证明候选空间中未观测区域**的可靠性。"*
- 局限：*"仍需通过**联合多轮评估**，检验策略—模型能否**持续**改进。"*

## 4. ★ 三个不可照搬的差异（必须写进结论）

**(1) 它每个域都有廉价客观的外部反馈；我们没有。**
单测通过 / 浏览器任务成功 / 测得的产率——都是**环境自动给的**。身份匹配**没有**：这正是我们建 `analysis/truth/` 让人工判定的原因。**JEPA 世界模型预测"动作后果"，不能凭空产生身份真值。**

**(2) 因此只能"用预测器替代全量人工"，不能"用预测器替代人工"。**
RSI-Anything 用预测器省的是**自动反馈次数**；我们用预测器省的是**人工标注条数**——真值仍须人来给。任何"让预测器自证正确"的用法都直接违反我方红线（自训练输出 ≠ 独立真值）。

**(3) 它自认未做联合多轮评估。**
所以**不能**借"递归自改进"当卖点。我们只能主张单轮/少轮下"**同预算内更省人工、更少误接**"，并在多轮上如实报告。

## 5. 可落地清单

### P0（立即可做，成本最低，价值最高）— 把真值采集改成"预测式主动采样"

- **现状**：241 对全量人工（已判 19）。人工预算实际是瓶颈。
- **做法**：用现有证据（外观 cos + dt + relay + **per-camera 校准**）作为"打分器"，人工只判 **Top-K（K≈30）+ 随机 audit（≈20）**；已判结果用于**校准**（Brier、排序准确率），并与"静态规则排序"对照。
- **指标**（照抄论文口径，额外接我们的验收）：**同人工预算下**的 误接/漏接/拒判；排序准确率；Brier。
- **这条就是 H1 的"等价预算"版本**，且能立刻减少你后面要看的条数。

### P1 — 双组件 + 兼容性门（形式化 relay v2 已有雏形）

- 组件检查 = 选择器/图各自的单元 + 回归；
- **兼容性检查 = 装配后配对在留出时段的成对重放**，不合格 → **保留旧对**（= TG-10 的 candidate→active + 回滚）；
- 允许**异步更新**，但每次必须**成对验收**。

### P2 — 选择性反馈偏差防护（借其表述）

- 保留**未选边的独立探索/审计通道**（TG-08）；
- 报告中**显式声明**："反馈是经选择获得的，不能证明未观测区域的可靠性。"

### P3 — 工程化版本控制

- 每个 WP 产出 `state.json`/`summary.json` + **输出哈希**；失败产物进 `attempts/`；`resume` 要求 same recipe + source identity；仓库 SHA256 清单。
