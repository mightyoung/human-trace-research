日期：2026-11-10

### 1.3 四个缺口

**缺口 1：轨迹预测完全没有。**
全库只有一个 `intent_traj_viz.py`（意图分类可视化，5 类去向），没有「位置/运动预测」。
`crosscam_spatiotemporal.py` 做的是「同一时刻 A 的落脚点映射到 B，看与 B 的落脚点残差」——这是**同步配对判据**，不是预测。

**缺口 2：在线迭代没有闭环。**
有 `relay_triage` 的 pending 增量重算、有 `replay_eval` 的回放评估，但缺「**历史已确认身份 → 自动校准映射/阈值 → 未来视频受益**」这一环。现在换一段视频，θ 和映射都要重新扫。

**缺口 3：去重判据错。**
现行去重按 IoU≥0.5。实测（`docs/p2-joint-ablation-2026-11-10.md`）：对「同一人的全身框 + 上半身框」这类缺陷，**IoU≥0.5 召回 0**（IoU 中位仅 0.19–0.21）；换「小框被大框覆盖面积 ≥0.60」后**召回 78.7%、精确率 94.9%**（AUC 0.832，阈值 0.60–0.90 平坦）。

**缺口 4：没有单一入口。**
四个 pipeline 脚本各管一段，没有「多机位视频 → 全程身份」一条命令。

## 2. 推荐路径

排序原则：**不训练**、**不需要新采集**、每步都能用现有真值验收。

### 第 1 步：轨迹预测模块（用户明确要，且正好补最大的风险区）

**为什么是它**：实测误合并构成是「同机位异时 **69.1%** ｜ 跨机位 23.6% ｜ 同帧同时在场 7.3%」。异时匹配是主战场，而现在异时匹配只靠外观——外观在长间隔下最不可靠。位置/运动先验是唯一能补这一块的独立信号。

**设计**（全不训练）：

```
输入：某轨历史 {t_i, foot_i(x,y), h_i}（脚点 + 框高作深度代理）
模型：分段线性/二次外推 + 卡尔曼平滑，输出
      v̂(t) = 位置预测 + σ(t) 不确定度（随时距增长）
映射：A 机位预测点 →(二次多项式 M_AB)→ B 机位预测点
判据：候选对打分 = 外观余弦 × exp(-‖预测点 - 观测点‖² / 2σ²)
```

**三个立刻可用的用途**：
1. **跨时段重连**（补 69%）：同机位内轨迹断开后，按预测位置 + 外观找回来。
2. **跨机位接力**（补 24%）：预测「他会从哪个门出来、出现在 B 的哪里」，把候选从全画面缩到预测域。
3. **跟踪稳定性**：遮挡期间用预测位置维持框，减少 ByteTrack 开新轨。

**验收**（现有真值即可）：
- 1012 的 229 个身份上，`C/229` 从 **0.5109** 提升多少（主指标）
- `fm` 不升高（不得用召回换误合并）
- 同机位 ID switch 数（305 现有 221 断点）下降多少

**风险**：机位间映射的标定。D1 已实测「几何不能从标签估计」（留一身份 0/16），所以映射必须靠 SIFT 或人工同名点；对不共视的机位对，位置先验不可用，只能退回外观 + 时间门。

### 第 2 步：去重判据换成覆盖率

`--dedup-mask` 之外再补一条「同帧 + 小框被覆盖 ≥0.60 + 共现 ≥5 帧 ⇒ 同人」，直接压掉「一人两轨」。305_train 实测 47 对同人双框 → 预期消掉 37 对，轨迹数 443 → 约 410。这一步**同时**改善跟踪和聚类。

### 第 3 步：在线迭代闭环

用历史素材里已确认的身份（`relay_triage` 的 49 confirmed + 人工终审）作为**校准集**：
- 校准每对机位的映射残差分布 → 更新 `sp_threshold`
- 校准外观余弦的分布 → 更新 θ（`d7_sweep` 的 self-cal 逻辑已有，改成「读历史校准结果」而非「当天自扫」）
- `replay_eval` 做回归保护：任何参数更新先在历史上回放，不回退才生效

**这是「不训练但会变好」的机制**：模型不动，动的是阈值、映射和身份库。

### 第 4 步：端到端单入口

把 `long35_pipeline` 扩成 `--only det|dedup|encode|stitch|crosscam|entities|select`，一条命令从多机位视频出「全程身份 + 质量报告」。

## 3. 需要定的一件事

轨迹预测的两个用途（跨时段重连 / 跨机位接力）用的是**同一套模型**，但验收口径和风险不同：

- **A. 先做跨时段重连**：只动同机位，不需要机位间映射（避开 D1 的标定难题），立刻能用 1012 的 `C/229` 验收。**风险最低。**
- **B. 先做跨机位接力**：直接攻 24% 那块，但要先解决机位对共视/映射（8 个可用机位对里只有 1 对真共视，其余只能靠门的拓扑）。**收益大但依赖拓扑标定。**
- **C. 两条并行**：同一模型，两套评估。工作量约 1.5 倍。

推荐 **A**：它是 B 的前置（预测模块本身要先验证准不准），而且能在不碰几何标定的前提下直接动主指标。
