# A+C 验证：面积分位收紧 + 面积选样

日期：2026-10-18
目的：按"低成本、可立即验证"的方案，验证框收紧（A）与人占比选样（C）能否改善证据质量与身份判定。
口径：1012 时间隔离（train 上午建库 / test 下午评估），E2 判定管线（会话对齐 + 每身份 z 校准 + self-cal 定 θ，稳定率≥0.90）。

---

## 0. 结论

1. **A（面积分位收紧）按 p30 定义等于无效**：实测平均缩放 **0.979**，97.5% 的轨迹线性缩小不足 10%。这个幅度削不掉座椅靠背或显示器，因此**"椅子/显示器"问题没有被解决**。
2. **C（面积选样 top-K）是真实的调节旋钮，但方向是"安全换覆盖"**：top-4 把覆盖从 0.423 压到 0.364，误合并从 1.96% 降到 1.26%；top-3 进一步降到 **0.74%**（约为基线的 1/3）。
3. **A+C 组合 ≈ 纯 C**：A+C 为 0.364 / 0.900 / 1.84%，纯 top-4 为 0.364 / 0.912 / 1.26%，差异在噪声内。**A 中性、C 主导**。
4. **不建议把 A+C 设为默认**。若误合并代价高（例如以去重后人数为核心指标），可把 top-3 作为"安全档"；若要解决证据质量，必须上人体掩膜或更强的框精修。

---

## 1. 主对照

| 变体 | 覆盖 | 稳定 | 误合并 | 簇数 |
|---|---|---|---|---|
| 基线（8 张等权） | **0.423** | 0.903 | 1.96% | 132 |
| A+C（p30 收紧 + 面积 top-4） | 0.364 | 0.900 | 1.84% | 144 |

同覆盖率对照：

| 目标覆盖 | 基线 same / fm | A+C same / fm |
|---|---|---|
| ≥0.30 | 0.970 / 0.00% | 0.924 / 0.59% |
| ≥0.40 | 0.898 / 1.55% | 0.886 / 1.74% |
| ≥0.50 | 0.882 / 2.18% | 0.856 / 1.99% |

在任何可比工作点上，基线都不劣于 A+C。

---

## 2. 消融：只改选样张数（不收紧）

用已有逐裁特征直接重算（无需重编码）：

| 选样 | 覆盖 | 稳定 | 误合并 |
|---|---|---|---|
| top-8（基线） | **0.423** | 0.903 | 1.96% |
| top-6 | 0.418 | 0.902 | 2.43% |
| top-4 | 0.364 | 0.912 | 1.26% |
| top-3 | 0.364 | 0.900 | **0.74%** |

读法：

- **覆盖的下降完全由 C 造成**（0.423 → 0.364）；
- 稳定性基本不变（0.900–0.912）；
- 误合并随 K 减小单调下降，top-3 是基线的约 1/3。

机制：按面积选样等价于挑"离镜头最近、框最大"的帧。这些帧里人更完整，但数量少（4 张 vs 8 张）使轨迹均值更受单帧影响；同时"最大框"帧也常是贴边或正在遮挡他人的帧。

---

## 3. 为什么 A 没效果：幅度不够

题目假设是"框边缘混入座椅/显示器，收紧即可削掉"。实测截面：

| 指标 | 值 |
|---|---|
| 各段 mean_scale | 0.953 – 0.982 |
| 305_test 轨迹 scale 均值 | 0.979 |
| scale > 0.9 的轨迹占比 | **97.5%** |

`scale = sqrt(p30/median)` 的语义是"剔除面积分布中最大的 30% 部分"，在框面积稳定的工位场景里 p30≈median，缩放自然接近 1。

**要真正削掉座椅/显示器，需要 0.6–0.7 量级的收缩，而这会切掉人体的一部分**——这就不是"零成本收紧"了，必须配合人体位置信息（掩膜或关键点）才能做对。

---

## 4. 判定与建议

| 选项 | 结论 |
|---|---|
| A（p30 收紧） | **无效**（幅度 2%），不建议单独保留 |
| C（top-4） | 可选：覆盖 −5.9pp 换误合并 −0.7pp |
| C（top-3） | 可选的"安全档"：覆盖 0.364、误合并 0.74% |
| A+C 组合 | 无额外收益，不建议默认 |

**若目标仍是"证据图里不该出现椅子"**，可行路径只有两条：

1. **强收紧 + 人体验证**（低成本试探）：scale 取 0.65–0.7，但只在"框内人体占比高"的轨迹上使用；需先用少量样本目检确认不切人。
2. **人体掩膜**（B 方案）：SAM2 / 人体解析只保留人体像素。这是唯一能保证"框里只剩人"的做法，代价是逐帧分割与新增依赖，必须独立验证。
