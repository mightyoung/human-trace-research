## 口径备忘

- 共视率 = Σ_t 1[两视角均可见] / Σ_t 1[任一可见]，在 400 帧上算；
- 正对 = 同 personID 不同时刻；负对 = 等量随机异人对；AUC 用 Mann–Whitney，身份级 bootstrap 1,000 次；
- `auc_equal_k` = 每对等量抽 15 个身份、200 次；这是**敏感性检验**，不等于排除了身份构成；
- 区域 A/B 依赖脚点反投影与 `camera_mapping.csv`，**未评估替代映射**的下稳定性；
- 21 对共享 7 台相机与一个人群池，**不是 21 次独立场地实验**；
- 像素扫描的退化是合成的（面积平均降采样 + 双三次回放），不含传感器噪声、运动模糊与压缩，所以 16 px 的 0.671 是**上界**。
