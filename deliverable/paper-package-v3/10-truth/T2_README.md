# 时空矛盾复核（27 条）

**打开**：`spacetime_review_offline.html` —— 单个文件，双击即可，不需要服务器和网络。
手机上可以把这个文件发过去用浏览器打开；判读结果存在浏览器本地（localStorage），
换设备/清缓存会丢，所以**判完请立刻点「导出 → 复制 JSON」贴回来**。

## 这是什么东西

身份图（443 个身份，由外观聚类得到）里有 27 处**物理上不可能**的合并：
两台**不共视**的机位在同一时刻都拍到了「同一个人」。
每条一行 A、一行 B，各三帧，**三帧都是同一个绝对时刻**（OSD 时钟对齐后取的）。

判读只有一件事：**A 和 B 是不是同一个人**。看衣着、体型、发型、配饰。

## 三个按钮之外的标记（重要）

| 标记 | 什么时候点 | 为什么 |
|---|---|---|
| 疑似交界处走过 | 两人像同一个人，但明显是在两个相邻分区之间走动被同时拍到 | 305/318/320/323 是同一开放空间的相邻分区，走过交界处会被两侧同时拍十几秒 → 这种「同时在场」**不能当两个人的证据** |
| A 侧混人 | A 那三帧里的人自己就不是同一个（衣着变了） | 比较对象本身不纯，这条判读作废 |
| B 侧混人 | 同上，B 侧 | 同上 |

点了这三种标记的条目，**不会**进真值。

## 判读结果怎么用

- 只判 `same` / `diff` 且没有上面三种标记的，回写成跨机位真值
  （`python tools/ingest_spacetime_review.py <导出的json>`）。
- ★ **这批是「算法已经合并」的可疑样本，只能量合并精度，不能当 AUC/召回的抽样集**
  （严重偏负例）。所以单独存 `gt_spacetime_items.json`，不并进 `gt_long35.json`。
