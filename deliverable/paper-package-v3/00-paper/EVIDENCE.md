## 七、不可折叠（§7）

### 7.1 删边 → 连通分量不变

- 输入：443 组；确认异人边 15 条，位于 7 个组
- 结果：**连通分量一个都没变**（组内两端仍可经其他成员连通）
- 记录：该项目第 **3** 次复现「删边不保证减错」

### 7.2 图着色（`tools/apply_spacetime_truth.py`）

| 项 | 值 |
|---|---|
| 443 → | **450**（净 +7） |
| 切开的组 | 7 个；块大小如 32 → [31,1]、14 → [9,5]、13 → [11,2] |
| 验收 | 15/15 异人拆开、**12/12 同人保住**、旧 T1 不变（P 1.000 / R 0.147，5 TP / 0 FP） |
| 产物 | `tmp/full/long35_crosscam_attr8_v1.json` |

★ 解读（写进论文的措辞）：32 轨组只被 1 对约束 → 最小切分只能掉 1 轨 → **约束满足给的是修正下界，不是修正**。L3 的验收语句是「所有已判读关系被满足且未破坏任何已知正确合并」，不是「图被修好了」。
